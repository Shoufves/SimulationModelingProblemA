# 终端服务映射与按实际利用率估值的设备替代

2026-10-19。本轮把一个有真实终端能源输入的居民供热子账户接入年度主体、运行与替代队列，并新增可选择的设备利用率规则。它缩小服务/设备映射缺口；**不是全国居民设备初态、全国历史校准或 S0 预测**。全国四项历史失败与六组输入缺口继续保留。

## 已落地的改变

在 [annual.py](../../src/energy_model/q2/annual.py) 中，设备替代可显式选择 `device_utilisation_rule=replaced_device_observed`。每次估值从当年已结算的被替代设备输入量计算利用率，分母为同组件在运数量 × 单位输入容量 × 年度小时；加权能量不再乘一次时长。按同组件平均利用率分摊，不假设已识别每台设备的负荷。

被替代设备闲置、停运或数量为零时，不虚计可变能源费用节省；固定维护费按实际状态系数计算。缺失、重复时段和超容量记录被拒绝。所用规则和利用率写入行为账。未显式启用的新旧案例保持原有预设规则，便于复现和公平比较。

## 来源与条件映射

[IRENA 原件](../../data/raw/q2/irena_remap_china_2014.pdf)物理 101—103 页附录 A/B、20 页方法及 107 页应用范围已逐页渲染核对。[转录](../../data/catalog/q2_end_use_transcription.json)保留七项技术：[处理表](../../data/processed/q2/end_use_reference.csv)将热效率/COP 百分数除以 100，将 MJ/人公里按 `3600/强度` 转为人公里/MWh。COP 和交通能耗强度不能使用同一种变换。

这里的效率是 REmap 前瞻技术假设，未当作 2014 全国设备实测。热泵限于空间/低温热；附录中的成本、容量分母、价年及未来能源价格没有取得当前模型的经济用途准入。[用途复核](../../data/catalog/q2_end_use_review.json)保留这些限制，未通过更换哈希扩大原 Q1 契约。

APEC 中国 005 的 2014 表中，`16.2 Residential × 7. Petroleum products` 为 **26375 ktoe**。只使用这一明确居民子行，不把含农业等用途的 Other sector 总行当作建筑。按照已登记 `1 ktoe=11630 MWh_LHV` 换算。原料和其他用途仍留在原账户。

可用于低温供热的比例没有观测，本轮在运行前固定为居民石油输入的 **5%、10%、20%** 三个研究假设。假设油锅炉有效热效率 0.85、热泵 COP 3.5。服务需求取 `所划入燃料能量 × 0.85`，相应账面服务单价除以 0.85，保持分类前后的燃料和整体服务收入。原有备用容量按份额划分，**没有把这种重建容量称为观测锅炉存量**。

三条纯分类控制与原 v12 的八项物理代理指标一致。新增账户由建筑主体结算，原残余油账户主要归在交通主体；这次分类会改变主体之间的收入归属，不能声称各主体现金账与旧分类完全相同。

## 16 条路径与结果

设计见[冻结协议](../../workflow/q2_candidates/residential_heat_episode_v2.json)：原 v12 控制一条；每个可用比例包含纯分类控制一条，以及两种利用率规则 × 两档成本报价四条，共 16 条。无拟合、无选择，不增加 5995 次累计训练执行数。

设备寿命 20 年、折现率 5%、工期 1 年、年度安装量为初始额定热容量的 5%、新增运维/残值为零，均为诊断假设。电网接入按 `1/COP` MW 电/MW 热计；既有共同施工额度中 1 MW 热按一个施工单位计，属于尚未核验的工程能力代理。没有反推实际全国安装能力。

成本报价取初期“按实际利用率计算的盈亏平衡资本成本”的 0.5 倍或 1.5 倍，**不是市场成本或 IRENA 成本**。继承初态下的利用率仅 4.325%，对应盈亏平衡价约 0.014284 百万美元（2008 常价）/MW 热。原预设 100% 利用率会把可变费用节省放大约 23.1 倍。该结论是模型内估值差异，不是现实居民设备的利用率结论。

以 10% 可用比例为例，2024 年条件结果如下。各行供给同一热服务；表中的油、电仅为划出的居民子账户：

| 规则及报价 | 油输入 TWh_LHV | 电输入 TWh | 在运热泵 GW 热 |
|---|---:|---:|---:|
| 只分类，不替代 | 43.037 | 0 | 0 |
| 预设满负荷，0.5 倍报价 | 0 | 10.452 | 34.409 |
| 预设满负荷，1.5 倍报价 | 0 | 10.452 | 34.409 |
| 按旧设备实际利用率，0.5 倍报价 | 7.576 | 8.612 | 3.441 |
| 按旧设备实际利用率，1.5 倍报价 | 43.037 | 0 | 0 |

新规则在较低报价下发生替代，随后因剩余旧设备利用率下降而停止继续扩张；在较高报价下不投资。预设满负荷两档均继续扩张。这个对照说明年度运行反馈会改变投资及队列，不能据此推荐现实设备配置或认定真实市场成本符合任一档报价。

热泵从环境取得的热量按 `热服务 − 电输入` 单列，不计作一次能源来源或免费发电；电力排放仍在发电端计，设备端不重复加碳。既有排放仍是历史有效系数代理，不因这次替代获得全国碳核算准入。

## 验证与失败记录

[服务账户](../../outputs/q2/residential_heat_episode_final/service_accounts.csv)、[全部案例和参数索引](../../outputs/q2/residential_heat_episode_final/summary.json)及各案例完整账本已落盘。[独立检查](../../outputs/q2/device_mapping_checks.json)核对 165 个服务年度：实际热服务加缺供等于请求量、额定热服务能力在替代时守恒、投资当年不投运、整体现金守恒、在建余额与托管资金匹配。

原 v12 完整结果逐字段一致；新核验还重跑工程入口，19 个原科学产物字节一致。36 文件隔离副本在两个环境分别重跑 16 条路径，各 21/21 个输出字节一致，见[复现记录](../../outputs/q2/device_mapping_reproduction.json)。405 项完整测试通过，包括九项新增设备估值和来源单位检查。

首次运行遗漏了开启原模型中关闭的 replacement 开关，因零收益而失败。原[失败记录](../../outputs/q2/residential_heat_episode/attempt.json)和[初版协议](../../workflow/q2_candidates/residential_heat_episode.json)保留；v2 明确只在有替代报价的案例启用该机制。早期 v2 结果保留。最后还删除了未分账控制在居民子账户中的伪零行：没有该子账户不等于居民耗油为零。修改前结果及复现记录已[归档](../../archive/q2_review_history/device_mapping_before_scope_output_fix/relocation.json)，最终服务表仅包含实际分账的 165 个服务年度。

## 复现命令与下一步边界

在仓库根目录使用锁定依赖；指定尚不存在的输出目录：

```powershell
python -B -X utf8 scripts/prepare_q2_end_use.py
python -B -X utf8 scripts/run_q2_device_mapping.py --output-dir outputs/q2/replay_device_mapping
python -B -X utf8 run.py test
```

本轮形成了可运算的局部服务—设备关系和投资反馈。全国模型还需同口径设备容量/年龄、可替代用途比例、实际成本和政策等映射；历史油气响应、气电运行用途、风光部署以及 2024 全国状态不能由本试验替代。全国 S0、三因素灵敏度和完整验收目标保持不变。
