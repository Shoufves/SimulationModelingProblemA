# 联合投资审核：已复现的连带收缩问题

2026-10-20，独立子智能体使用真实 `operate_national` LP 在内存中复现。随后已在版本化`PortfolioNationalModel`修复并完成9项反例测试、完整联合训练和Q3衔接，见[本轮实测结果](q2_corrected_round_20261020.md)。旧冻结实验来源保持。

两个1小时时段负荷各5 MWh，电网100 MW，无储能、无补贴，风光可用率均1，电价100元/MWh。风电候选2 MW、光伏候选4 MW；两个项目单独投资均有正NPV。联合调度后风电NPV为+514427.98元/MW，光伏为−128607.24元/MW。现有审核将两项同时减半，批准风电1 MW与光伏2 MW。然而只缩减失败的光伏并重新联合运行同一LP，风电2 MW与光伏2 MW的NPV分别为+1028856.95和+128607.24元/MW，均为正。

因此，共享市场约束确实存在，但风电连带减半不是满足它的必要条件。`src/energy_model/q2_national.py` 的 `audit_renewable_portfolio` 使用全部通过判断后同时减半，并在有限搜索耗尽后全部归零；上游已经分别处理投资预算、融资、建设能力和补贴授权。

修正应只缩减当前失败技术，随后重新审核全部剩余组合；搜索耗尽时剔除失败项后仍要重新审核保留项，不能直接批准未检验的剩余组合。维持上游有限预算、融资、建设和补贴授权，不自动再分配释放额度。需要覆盖混合正负NPV、两项失败、移除后重审及无补贴部分不得破坏已验证受支持组合的反例。

当前联合训练获选案例的旧审核均通过，因此这不是该获选案例装机缺口的已证实原因。它可能限制其他候选的可行投资，应作为算法问题修复并重新比较，不能预先宣称能消除全国装机误差。
