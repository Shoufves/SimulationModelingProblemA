# Q2 原料用途分账：29 条预设路径与守恒核对

2026-10-19。本轮在 v10 已选历史候选上分离 APEC 2014 已报告的非能源原料用途，形成可复算的分账试验。全部 29 条 2014—2024 路径执行成功，初始需求/容量、燃料与现金核对通过。它修正了“全部非发电燃料都代表能源服务”的用途解释，**尚未建立全国部门服务模型，也未通过问题二全国预测验收**。

八格中心值合计 182954 ktoe，总控制打印为 182955 ktoe；17.2 的打印小计与组成格也存在 1 ktoe 差异。四个用途部门 × 18 个顶层产品共有 72 格，其中 64 格为横杠。模型没有把这些横杠填成零。在“原料投入非负、各打印值按 1 ktoe 四舍五入”的显式假设下，未分配格的**联合**可行范围为 0—5.5 ktoe；不是每格都能取 5.5，也不是实际未知量的点估计。采用 `1 ktoe = 11630 MWh` 的能量内容换算，只映射八个正值中心；这部分尚未分配量及统计修订不确定性保留。

这是把 APEC 原料用途与 NBS/GCB 聚合残差联系起来的研究假设。它没有消除地域、版本、热值与统计口径差异，不能因核对加总成功而升级为观测到的全国设备/服务初态。

## 固定试验和计算边界

[冻结配置 v2](../../workflow/q2_candidates/nonenergy_episode_v2/manifest.json)含以下 29 条路径，全部保留、不拟合、不排名：

1. `v10_control`：完整原 v10 训练选择及初态，用于逐字段回归。
2. `same_growth_split`：原料与原残差保持相同 GDP 响应，煤/油/气分别为 0/0.5/2；用于检验分账本身。
3. `material_response_*`：三个载体的原料响应分别取 0/1/2 的全部 27 组合。这些值是未拟合假设，不是实测需求弹性。

原料需求为 `2014 原料量 × (当年 GDP / 2014 GDP)^响应指数`，只使用当前及以前年度 GDP；设备效率仍在运行层计算。原料与能源残差按初始比例拆分四时段需求和设备输入容量，不增加燃料供给、设备总能力或初始资金。工业、转换、交通原料分别由相应主体付款；沿用原残差的服务价格只是现金闭环假设，并非实测原料市场价。

运行层仍采购原料所占燃料并支付供应和资源费用。原料设备的零燃烧系数只表示暂时移出**部分燃烧代理账**。真实原料排放与碳储存保持 `null`，移除信用为零。旧模型系数是 GCB/NBS 有效比值，并非物理含碳量；按旧系数计算的排除项不能称为实际储碳或避免排放。结果指标将该碳账改名为 `partial_energy_combustion_proxy_after_material_partition`，不再使用 `gcb_fuel_co2` 身份，也不与旧 GCB 目标计算误差或宣布改善。

## 结果与验收

[完整结果摘要](../../outputs/q2/nonenergy_episode_v2/summary.json)记录 29 条路径，1540 条逐年原料账和 957 条煤/油/气平衡账，原料短缺均为零。该结论限于继承的宽松供给/容量/资金假设，不能作为现实全国原料保供结论。

- 原 v10 对照的完整结果对象与保留账本完全一致。
- 所有路径的初始燃料需求、设备总输入能力和初始资金守恒。
- 同增长率分账控制的来源/转换流量最大差为 `3.82e-6 MWh`，全系统资金最大差为 `4.77e-7` 百万 2008 年美元，资源成本最大差为 `1.17e-10` 同单位；均通过事先采用的绝对 `1e-6` 或相对 `1e-8` 容差。各主体现金分配可变，全系统不创造资金。
- 同增长率控制的部分碳账加旧公式排除项与原账的最大数值差为 `1.91e-6 t`。这是公式核对，**不是完整碳收支验收**。

新增 12 项测试覆盖原表缺格/重复行/负值、非法映射、容量和现金守恒、原料真实付款、部分碳账身份、未来 GDP 信息隔离、目标值不能影响未拟合结构，以及来源校验失败时不创建成功输出。完整测试集 **381 项通过，其中 Q2 为 199 项**。

首轮负向测试发现提取函数会覆盖重复行，并对缺行抛出未分类异常；原源表解析器已有完整标签校验，但独立提取函数缺防护。原冻结版本、原构建器和实际失败记录均保留在[变更记录](../../archive/q2_review_history/nonenergy_before_row_validation/disposition.json)所指位置。v2 只增加输入结构校验，不改变八格原值、29 组假设或阈值。

## 离线复现

在仓库根目录、已安装锁定依赖的 Python 环境执行，输出目录必须尚不存在：

```powershell
python -B -X utf8 scripts/build_q2_nonenergy_episode.py
python -B -X utf8 scripts/run_q2_nonenergy_episode.py --output-dir outputs/q2/nonenergy_reproduce
python -B -X utf8 -m unittest discover -s tests -p test_q2_nonenergy.py -v
```

运行器先重建并核对冻结输入、源记录、原件指纹和构建器，再执行所有路径；不允许覆盖既有结果。失败保留 `attempt.json`，完成时记录代码、输入、父账本和输出哈希。[复现报告](../../outputs/q2/nonenergy_episode_reproduction.json)列出 168 文件的独立副本：两个已安装环境中各 **37/37 个产物逐字节一致**。两环境均为 Python 3.13.9、Mesa 3.3.1、NumPy 2.3.5、SciPy 1.16.3；这是固定软件组合的同作者离线复现，不宣称跨平台或第三方独立评审。

本轮没有新增训练执行，累计仍为 4989 次有效训练执行（含重复控制）。v10 油/气/风/光四项失败继续保留。完整全国服务/设备映射、2024 初态、技术价格、运行时序、净碳边界及全国 S0/灵敏度仍未闭合；B3—B6 不能由此次局部分账代替。此改进提供了可审计的用途分账和反例测试，尚不宣称已获得通过实证验收的研究创新。
