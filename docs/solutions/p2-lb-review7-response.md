## 4. 共同入口

Issue #7 的命令现在通过显式兼容路由执行全国候选：

```powershell
python -B -X utf8 run.py q2 --config workflow/q2_inputs.json --output-dir outputs/q2/review_pr9_common_entry
```

启动信息明确说明：`q2_inputs.json` 保留旧候选清单的身份和原字节；实际执行由 `q2_national_design.json` 和 `q2_national_input_review.json` 的新用途审查准入。兼容路径是公开记录的命令别名，不读取或将旧清单中的候选许可升级为全国许可。显式全国配置命令与默认命令也执行同一模型。独立复现实际走上述共同配置路径，输出目录另设以避免覆盖主结果。
