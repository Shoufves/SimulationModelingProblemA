# 问题二：人民币电价与常价美元财务口径

新增2008—2024年、17行可复算的货币换算参照，将历史名义人民币金额转换为常价2008美元。本轮不改变v9合同、投资或运行结果；这只是后续电价映射所需的会计桥接，不是全国价格准入。

## 来源与实质核验

- 中国汇率复用既有`WDI_CHINA_MACRO`原始JSON，无重复下载和重复观测计数。统一目录原先仅允许Q2专属原件目录；现在仅在显式声明旧源键、规范路径和SHA全部匹配时允许跨用途复用，仍拒绝未知、变更或非公开路径。完整响应有126条记录、6项指标、21年；本次只取CHN／PA.NUS.FCRF／2008—2024共17条正值，2025不使用。新Q2注册身份仅标示新用途，原`data/catalog/sources.json`保持不变。
- 美国GDP平减指数新增USA／NY.GDP.DEFL.ZS／2008—2024单页响应，共17条正值；与旧2008—2014参照的7项数值完全一致，同源重叠不算独立验证。两份数值响应的数据库更新时间均为2026-10-08，不能解释成当年的实时发布数据。
- 两份WDI指标定义JSON已核对：汇率方向为“每美元对应多少本币”，是期内平均，底层来源为IMF IFS；GDP隐含平减指数是当年价GDP／不变价GDP，指数基年因国家而异，不能假设其2008值为100。

逐文件URL、SHA和用途见[源注册表](../../data/catalog/q2_sources.json)，本次5条源记录由[用途审查](../../data/catalog/q2_currency_bridge_review.json)单独绑定。新增原件3份，既有宏观和旧平减原件直接复用。原宏观下载时间未重新确认，保持缺失，不用本次审查时间替代。

## 换算与明确假设

设当年年均汇率为`FX_y`（人民币／美元），美国GDP平减指数为`D_y`。金额`X_y`（当年名义人民币）的换算为：

```text
常价2008美元 = X_y / FX_y × D_2008 / D_y
百万元常价2008美元 = 上式 / 1,000,000
名义人民币/kWh → 百万元常价2008美元/MWh的乘数
                    = 1,000 / FX_y × D_2008 / D_y / 1,000,000
```

使用美国一般GDP平减指数是在美元会计单位下的研究假设，不代表中国设备价格或技术学习率。年均官方汇率也不是每个项目的成交、结算或套期保值汇率。保留原始人民币价格，不能用换算后的单值替代其原税基和地区／批次条件。

例如2014年`FX=6.14343409448867`，`D_2008=83.5215456690289`、`D_2014=91.5006903474734`，故1元当年人民币对应0.1485808876455132常价2008美元；1元/kWh对应148.5808876455132美元/MWh，即0.0001485808876455132百万元美元/MWh。该示例仅展示单位换算，不授予任何项目1元电价。

2024年同一名义人民币的因子为0.09749233813099085。这说明固定名义人民币电价并非固定常价美元电价，不能在授予合同的一年换算后永远保持同一实际价格。反过来，也不能让2015年的投资者预知2024实际汇率和平减指数。后续合同实现必须分别处理已知合同条款、当期结算和事前预期。
