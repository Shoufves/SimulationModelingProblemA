# 问题二：活动量驱动与交通统计口径

本轮补齐“活动量改变服务需求，设备效率改变能源投入”的可执行接口，并核对 2014—2024 年交通活动原表。它改善需求模块和输入准备，不改变 v10 校准结论，也不构成全国交通用能预测。

## 计算与信息边界

[需求驱动模块](../../src/energy_model/q2/demand.py)允许每项服务显式选择 GDP 弹性或逐年活动量。活动量模式采用 `D(t)=D(初年)×A(t)/A(初年)×(1−服务强度改善率)^(t−初年)`；设备效率只在运行层将服务换算为能源投入，不再次减少期望服务。同一服务同时填写活动量和 GDP 弹性会被拒绝。

每年活动记录必须写明单位、统计边界、来源或研究假设，以及“事后观测/情景假设”。初始活动须为正，之后明确的零活动可以使用；缺年、重复年、非有限值、边界变化和归一化溢出均拒绝。初始服务规模及活动到服务的映射仍须另行核验；提供活动量不是提供燃料强度。

训练运行可保留尚未读取的后续记录，实际运行只读取当年和初年活动。未来活动值改变时，过去的运行、投资、资金、资产、队列和信息账本须全部不变。使用 2025 年鉴修订值属于给定已实现活动量的事后回放，不是当年主体预见该修订，更不是无条件预测。

## 原件与口径复核

[审查记录](../../data/catalog/q2_transport_activity_review.json)绑定六条来源记录和转录表。复用 lb 已保存的统计年鉴 2025 表 16-6、16-8 及指标解释 PDF，原件路径及字节不变；补入同年鉴的篇章说明以及交通运输部 2019、2020 年统计公报。审计发现指标解释下载件与既有原件完全相同后，按哈希核对去重，并保留[路径别名及去留依据](../../archive/q2_review_history/transport_definition_deduplication/disposition.json)。公报与年鉴的重合数据不重复计为独立观测。

转录覆盖 11 年、55 个客运单元格和 77 个货运单元格。22 项源内加总按原表末位精度核对，保留舍入残差。货运水路已含其海运子集，不能再加一次；人公里与吨公里不能相加。数据见[活动原值及来源](../../data/processed/q2/transport_activity_2014_2024.csv)和[加总诊断](../../data/processed/q2/transport_activity_arithmetic.csv)。

| 发现 | 核验依据 | 处理 |
|---|---|---|
| 2018 公路客运转录错位 | 原图为 9279.7 亿人公里，初稿误写 9297.7，导致 −18.0 残差超过 0.25 的舍入诊断界 | 保留[初次失败与更正依据](../../archive/q2_review_history/transport_activity_first_arithmetic_failure/correction.json)，更正转录；不调整原件或容差 |
| 2019 公路货运口径变化 | 交通运输部 2019 公报注 4 明确专项调查后调整统计口径，增长率按可比口径计算 | 原值保留，尚无完整回溯桥接，不输出同口径 11 年驱动 |
| 2020 水路统计方式变化 | 2020 公报注 3 明确海洋运输改为企业联网直报，水路客货运增长率按可比口径计算 | 水路客运、货运两条完整路径也暂不导出；加总通过不能代替时间可比性 |
| 远洋与海洋标签不一致 | 年鉴“远洋”列的 2019 年 54057 对应公报“远洋”54057.47；2020 年 89897 数值对应公报“海洋”89896.90。2019 公报另列沿海 33603.56 | 数值吻合不证明分类等价；不静默改名，不把跳变解释为远洋实际增长 |
| 营业性与全国能源边界不同 | 年鉴篇章说明限定营业性公路/水路；民航按国内注册承运人统计并包含国际航线；管道记录运输服务量 | 不替代私人出行、全部油气消费或领土燃料消费；监测企业单耗不自动代表全国车船 |

2019 公报使用页面 `PubDate=2020-05-12`，没有用 URL 中的迁移目录日期当发表日；2020 公报所存转载页公开日为 2021-05-20。

首次仅根据年鉴准备的 8 条序列和当时复现证据保存在[口径复审前快照](../../archive/q2_review_history/transport_before_mot_scope_review/data/catalog/q2_transport_activity_review.json)。补查公报后收紧为 6 条：铁路、公路、民航客运，以及铁路、民航、管道货运。合计、重叠子集、公路货运和水路路径不作为连续驱动导出。[导出序列](../../data/processed/q2/transport_activity_series.json)仍只是活动参照，不含能源强度、设备比例或 2060 路径。

统一目录原来先处理 Q2、后处理 lb，因而无法验证 Q2 对 lb 原件的合法复用。本轮将原始来源登记置于 Q1/Q2 用途复核之前，仍逐项核对来源键、路径和哈希；没有放宽复用条件。NBS 历史唯一记录文件的字节保持不变。

## 执行与验证

```powershell
python -B -X utf8 scripts/prepare_q2_transport_activity.py
python -B -X utf8 -m unittest discover -s tests -p test_q2_activity.py -v
python -B -X utf8 -m unittest discover -s tests -p test_q2_transport_activity.py -v
python -B -X utf8 run.py catalog
python -B -X utf8 run.py test
```

8 项驱动测试包括实际铁路活动序列进入明确的合成服务夹具；该夹具的初始服务、设备和燃料参数均非全国铁路估计。7 项交通测试检查重叠加总、单位、缺项、表注限制、原始错位和原件篡改。算术校验失败时，程序在创建输出目录之前抛出异常，不导出供模型使用的序列。

[独立目录复现](../../outputs/q2/transport_activity_reproduction.json)在两个环境离线执行；[回归证据](../../outputs/q2/activity_regressions.json)记录原 v10 选中模型完整账本一致、训练损失仍为 0.1615137337952601、19 项工程科学产物逐字节一致。本轮没有重新搜索或增加训练执行数。旧的 PNG 跨环境字体差异限制仍保留。

## 未关闭的验收项

活动量不能唯一识别设备效率、燃料分配和服务强度。新增资料尚未连接到具有同年能源账和设备结构依据的全国交通服务；工业、建筑活动映射也未完成。v10 的油、气、风、光四项失败保留，累计训练执行仍为 4989 次（含重复控制）。全国六组输入、S0 的 2030/2060 完整指标、全国灵敏度及外部同 SHA 评审仍未验收。该模块是可复现的实现进展，不能单凭接口或测试宣称已经取得实证创新。
