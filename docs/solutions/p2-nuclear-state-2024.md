# 问题二：2024年末核电设备与在建队列参照

本轮从既有Q1原网页补取两张附表，逐行核对58条在运记录和27条在建记录，形成[设备/队列参照](../../data/processed/q2/nuclear_state_2024_reference.csv)、[冲突表](../../data/processed/q2/nuclear_state_2024_diagnostics.csv)及[核对记录](../../data/processed/q2/nuclear_state_2024_checks.json)。它缩小2024同年初态的资料缺口，但尚不能直接成为全国模型资产清单。

## 原件与时点

原网页为中核智库编制、国家核安全局网站转载的《2024年我国大陆核电机组情况》，发布于2025-01-07，统计截止2024-12-31。正文注释列出IAEA、能源局、地方政府、中电联、行业协会等来源，但没有逐机组标注上游出处。应称为该机构的统计汇编，不能将所有行视为监管许可原件或独立于NBS的测量。

[网页原件](../../data/raw/q1/nnsa_nuclear_2024.html)复用Q1已保存字节；[在运附表](../../data/raw/q2/nnsa_nuclear_operating_2024.png)和[在建附表](../../data/raw/q2/nnsa_nuclear_construction_2024.png)为本轮新增原图。HTTPS取图握手失败后，从同一官方主机HTTP地址取得PNG，记录实际取回地址和字节哈希；未以第三方重绘代替原表。两张完整原图均已目视核对。

[转录](../../data/catalog/q2_nuclear_state_2024_transcription.json)保留项目、原机组标签、技术、额定功率及开工/首次并网/商运单元格。缺失破折号、并未存在的日期列和不同状态不混同。转录及三条用途来源均绑定[专用审查](../../data/catalog/q2_nuclear_state_2024_review.json)，新用途不继承Q1模型准入。

## 加总与冲突

| 检查 | 结果 | 可作出的判断 |
|---|---|---|
| 在运58行额定功率 | 6088.094万kW＝60880.94MW | 与同一网页正文精确一致 |
| 在建27行额定功率 | 3230.91万kW＝32309.1MW | 正文为3230.9万kW，差0.01万kW，符合正文打印位数的四舍五入诊断假设 |
| 2024年开工6行 | 740.8万kW | 与正文开工数、容量相同；不是当年新增在运容量 |
| NBS2025年鉴2024核电 | 6083万kW | 与汇编差5.094万kW＝50.94MW；原因未桥接，不调平或替换历史表 |
| 在运＋在建＋核准待建102台 | 102−58−27＝17台待建 | 仅是正文计数差额，不生成17个虚构项目或精确容量 |

前面三项是同源算术核对，不是独立数据验证。正文总容量“1.13亿千瓦”是低精度汇总，不能用它减去高精度在运/在建量，伪造待建队列的精确容量与资金。

需要保留的原文问题：

- 在运表第48、49行均写“防城港3号机组”，日期分别落在2023、2024；正文另称2024新增并网包括防城港4号。两行保留原标签，标记身份冲突，不自动把第49行改成4号。
- 在运表石岛湾1号为HTR-PM、21.1万kW；在建表石岛湾1号为华龙一号、122万kW。仅按电站名和机组号去重会删掉不同技术项目，必须带技术与来源表格上下文。
- 国核示范工程1号开工、首次并网、商运日期均为破折号，2号开工日期亦缺失。保留缺项，不按正文“已在运”反推具体日期。
- 漳州1号首次并网为2024-11-28、商运为2025-01-01。截止2024年底属于已并网记录，不能算作当时已商运；2025发布日期亦不倒灌到2024年初或历史投资信息集。

每行使用`来源表:原行号`作为转录键，该键不冒充已经消歧的真实资产ID。额定功率原表未说明毛/净口径，不等同于可用出力、利用率或2024全年发电能力。正文的2024预计发电量及2025预计投运量没有作为实际观测采用。

## 复现与模型用途

[处理脚本](../../scripts/prepare_q2_nuclear_state_2024.py)先校验原件、转录、来源记录和NBS参照指纹，再做单位换算、时点检查、重复标签诊断及加总。五项测试覆盖原件篡改、日期倒置/跨期、错误单位/容量及源内冲突保留。

[离线复现](../../outputs/q2/nuclear_state_2024_reproduction.json)复制11个必要文件，在两个独立Python环境重建，三个产物均逐字节一致。

```powershell
python -B -X utf8 scripts/prepare_q2_nuclear_state_2024.py --output-dir tmp/q2/nuclear_state_2024_reproduce
python -B -X utf8 -m unittest discover -s tests -p test_q2_nuclear_state_2024.py
```

尚缺运行可用率、合同/许可有效期、年龄到退出的规则、剩余建设支出及投运预测。表中开工日期不能自动变成未来投运年份，机龄也不自动给出退役期限。本轮没有改变v1—v10历史模型，没有构造全国2025—2060队列；正式配置的`current_initialization`缺口仍有效。
