# 问题二：历史风光电价与信息时间线

本轮核对三份发改委通知及四张原始附件表，形成六组电价安排、23项分区价格和七条公布／替代事件。资料用于修正后续历史政策映射，**未接入或改变v9模型，也未批准全国电价或未来政策路径**。

## 不得压平的政策差异

1. **预告与替代。** 3044号曾在2015年底预告2018电价；2729号第一条明确此前发布的相应年份新建风电价格政策不再执行。因此保留原预告，在2016-12-28后才移出“当时仍有效的已知预告”。不能把最终0.40等价格回填为2015年主体已知，也不能删除旧信息而失去预期路径。
2. **新批次与旧项目。** 3044风电脚注区分核准期、两年内开工和2017年底仍未开工；2729另有年度财政补贴规模、2019年底和跨年度规模条件。取消2018旧预告不等于抹去所有2015／2016已获资格项目。这里没有项目级日期和补贴资格，不能直接给每个资产授予电价。
3. **开工和投运。** 风电两年条件针对开工；光伏2016脚注要求截止日前“全部投运”，2017脚注文字为“投运”。这些不是同一个日期字段，不能把建设期或装机观测替代行政资格。
4. **地区随版本变化。** 3044风电表与旧2009表相比不再把昌吉列Ⅰ类、张掖列Ⅱ类；2729风电表把云南列Ⅱ类。2729光伏Ⅱ类增加阳泉，西藏单列1.05；3044西藏另行制定，缺值继续保留。不同版本的同名zone不能未经核对沿用全国权重。
5. **标杆价和现金。** 附件价格含税、以名义人民币每千瓦时列示；它是全额标杆上限，不是普通售电之外再付一次的补贴。当地电网与可再生能源基金分担、竞争电价上限、到账时点及税费需要分别映射。这些通知本身不提供完整补贴期限或全国实际付款价格。

本次仅取陆上风电与电站式光伏的这六组安排。2729正文的海上风电、3044分布式模式转换条款不在本表内；既有2013分布式补贴记录仍在旧参照表。没有把本次局部提取写成完整政策日历。

## 可复现实现与限制

[离线处理器](../../scripts/prepare_q2_policy_timeline.py)先校验原件、转录、用途审查及注册记录，再输出[23行参照表](../../data/processed/q2/policy_timeline_reference.csv)、[事件表](../../data/processed/q2/policy_timeline_events.csv)和[检查记录](../../data/processed/q2/policy_timeline_checks.json)。仅进行每千瓦时到每兆瓦时乘1000换算，不做全国平均、税前处理、汇率或平减。

`visible_schedules(document, as_of)`返回截至给定日期已公布且未被明确撤回的条款，包含当时已知的未来预告。它不决定项目资格、不选择实际付款价，也不授予合同。没有明确撤回的旧项目条款不会被机械的“最新年份”筛选抹除。未来仍可能有后续修订；本表不会自动生成2060政策。

四项新测试覆盖：落款不能提前公开日期；撤回不倒溯且旧批次保留；跨技术错误替代拒绝；篡改原件、转录或未通过实质审查拒绝。全部337项回归通过，含155项Q2。[12文件独立快照](../../outputs/q2/policy_timeline_reproduction.json)在两个环境各复现三个输出，全部逐字节一致。

```powershell
python -B -X utf8 scripts/prepare_q2_policy_timeline.py --output-dir tmp/q2/policy_timeline_reproduce
```

历史模型继续缺区域与项目批次权重、核准／开工／投运及财政规模资格、名义人民币与常价2008美元的统一财务口径、完整后续政策和支付时序。本次实质核对缩小政策资料缺口，但不能据此关闭全国技术价格输入组。

后续[货币会计桥接](p2-currency-bridge.md)已核对2008—2024的年度换算因子；它只处理单位，不替代税费、项目资格或未来信息审查，也未改变v9。
