# 历史煤价、投资时点与新老机组效率核查

2026-10-20。当前整题仍未通过科学验收；本轮没有修改默认全国价格，也没有提交commit或PR。

## 已完成

1. 新下载9份公开电煤指数原表，补齐2016年后三个月及2017—2019全年。新旧合计73个非空月份，其中2014—2019各12个月完整，另有2020年1月。25次重叠比较一致；独立提取与原件哈希复核通过。2020年2月以后仍缺，税基仍未知。详见[原表扩展](../sources/q2_coal_prices_extension.md)。
2. 新增年度燃料价格接口。初始价先于企业收益先验和消费者固定收入重建，当年价进入运行、账单与投资学习。未来投资规划只延续当前价，不读取未来价格；缺年报错。电煤到厂价只用于共用市场敏感性，未冒充工业煤价。8项专项测试和完整497项测试通过。
3. 关闭接口，三组完整2015—2024结果与已冻结修正工厂精确一致。独立复核另重建authority25完整路径及一组敏感性，验证未来价格不影响过去决定、15案例燃料账单代数误差0。
4. 完成15组2015年动态对照，以及15组2015—2019完整月指数窗口对照；固定原训练参数和所有承诺权限，不依据结果选择税口径，不调整验收门槛。源代码与输入哈希全部保存。

## 结果与下一步

15组五年对照中，煤电累计新增批准均为0。低煤价确实改善收益，但未跨过投资门槛；2017年后指数上升还会侵蚀早期收益。因此不能把总装机缺口单独归因于煤价，也不能用提高补贴额度代替机制核查。

进一步核读同一本IEA技术成本工作簿：中国超超临界煤电效率单元格为`3.3!E22=0.45`，CCGT为`3.2.a.b!E24=0.58`。模型统一毛效率分别0.41和0.52，两者不能直接相减。当前成本使用2014厂用电重建的净铭牌比例0.9301/0.9741，在同一条件换算下，新技术毛效率为0.483819/0.595421。该比例仍是重建假设，非新项目实测厂用电率；净效率解释另由原报告与独立核查确认。

固定历史发电和资产路径，将燃料节省按原学习率加入新项目收益诊断后，部分候选NPV由负转正。例如原煤价条件下，2018年气电NPV从约-119.45万元/MW变为+54.37万元/MW。该结果只定位“新建成本和收益效率是否对应同一技术”的影响，**没有**实际批准这些项目、改变调度或修复历史装机。2025新建技术参考不能冒充2015年观测；下一步需要有依据的技术年代设置、项目队列效率、实际混合机组燃料/排放核算，再重训和验收。
