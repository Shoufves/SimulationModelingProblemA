## 修正依据和实现

1. **光伏新旧批次与价格年。** IRENA《Renewable Power Generation Costs in 2014》物理页 93—94 的中国典型集中式项目成本范围为 1320—3090 美元/kW（2014 年价格），容量因子为约 17%。范围中点 2205 仅是研究网格点，不冒充全国均值。新增批次独立于原存量；原存量的“年发电量/年末装机”不再强行作为新项目参数。报告 2015 年发布，按已有保守约定从 2016 年决策起可用。美国 WDI GDP 平减指数 2014/2008 比为 1.095533968086073，显式统一到原模型的 2008 美元；这是一般价格基准换算假设，不是中国光伏产业成本指数。总安装成本作为项目资金代理、O&M、名义政策价格及全国集中式/分布式比例仍未完成口径准入。
2. **共享建设额度。** 同种技术的多个批次共同占用年度建设额度和总容量上限。队列占用总上限，只有已投运且运行的存量可影响假设中的建设能力增长。比较固定额度、2014 新增/年末装机比率、该比率的两倍三个假设；它们不是实测供应链产能。现金、许可、总建设与接入限制继续共同约束。默认未配置分组时，原行为和输出不变。
3. **核电初始队列。** 国家能源局《百问核电（上册）》第 33 问列出 2014 年末 26 台在建机组、合计 28450 MW，包含机型、容量和开工年月。与国家核安全局 2014 年报物理页 23—25、27、29、32、34—36、38—40 的状态逐机组匹配。福清 1、阳江 1、方家山 1 等已运行机组排除；石岛湾的设备吊装准备时点不当作投运时点。源表剩余工期、实际未来投运时间和现金余额仍为空。模型按同期状态设 1/2/3/4/5 年的研究工期，另比较统一延后 1、2 年及空队列对照。均匀建设支出和代表性核电样本造价是显式假设，剩余款从原有企业现金转入托管，不创造现金。NEA 第 34 问在运容量与 NBS 修订存量相差 20 MW，未调平。

来源和用途审查分别在 [光伏/价格参照审查](../../data/catalog/q2_mapping_2014_review.json)、[核电队列审查](../../data/catalog/q2_nuclear_queue_review.json)。[离线提取器](../../scripts/prepare_q2_nuclear_queue.py) 可由原 HTML 重建 26 台队列并复核原表加总。历史来源注册、转录与模型假设分开；未继承 Q1 的全国模型准入。
