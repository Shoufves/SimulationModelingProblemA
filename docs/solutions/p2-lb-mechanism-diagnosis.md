## 1. P1：电网约束随电源自动扩大，无法研究配套滞后

定位：`src/energy_model/q2_national.py:420`、`:554`，`NationalGrid.propose`。

- 电网功率上限直接设为所有发电装机之和，没有独立的输送资产、接入额度或建设队列。在此全国单节点结构下，这个上限基本不能成为独立瓶颈。
- 同初态仅增加100万MW光伏，电网功率上限也增加100万MW；没有新增电网项目及支出。这是对状态映射的反例，不是假设现实可以凭空建电站。
- 储能投资按风光装机的10%目标决定，函数收到的弃电量始终为0；实际弃电、缺供和运行结果没有进入这条决策规则。

影响：电源、输送与储能建设没有形成主方案要求的反馈关系，尤其不能用这版全国模型支持“配套赶不上转型”的机制归因。

修复验收：独立保存输送/接入资产及建设状态；增加电源不能自动增加电网容量；配套申请读取实际可用出力、缺供及约束诊断。即使首版只做全国聚合，也须明确可识别的接入限制及其来源，不能把全国单节点上限称为区域网络。

## 2. P1：企业资金只记账，没有约束投资

定位：`q2_national.py:115`、`:130`、`:203`、`:474`。

把每家发电主体初始现金分别设为 `+1e15` 与 `-1e15` 元，其余条件相同，2025年新批准项目完全一致：约67.91万MW、承诺投资约3.276万亿元。投资申请不读取现金，审批按GDP比例形成全国融资额度；没有主体债务、偿付或融资资格反馈。

影响：已有资金流水平衡验证的是会计恒等式，不能证明“资金—融资—投资—收益”闭环。企业亏损或资金耗尽目前不能通过融资能力约束扩张。外部储蓄融资可以作为简化，但须说明分配规则及承担风险者，不能同时声称主体财务约束已实现。

修复验收：区别自有资金、融资承诺、建设付款及偿债，明确最低资金/融资资格；资金变化在约束生效时应影响可批准投资。全国预算约束继续保留，不能用主体约束替换掉它。

## 3. P1：光伏建设能力被设成装机的自我放大函数

定位：`q2_national.py:130`—`:137`；冻结设计第8行记录了此前只修订风电建设规则。

在当前参数下，光伏净现值为正时，年度申请量约等于现有装机的 `35% × 1.3 = 45.5%`，再经全国预算缩放。它把电站存量当成建设产业能力；尚无土地、接入或新增项目资源质量递减约束。固定电价与滞后的平均收益预期也不足以描述大量新增项目的边际收益变化。

原候选复算证据：

| 指标 | 数值 | 解释 |
|---|---:|---|
| 2030年光伏新增申请 | 2.177 TW | 是申请，不是最终获批或当年投运 |
| 2040年光伏新增申请 | 9.379 TW | 装机放大规则仍在驱动申请 |
| 2060年光伏装机 | 29.776 TW | 全部风光合计34.735 TW |
| 2060年风光未利用的模型可发电量 | 51.70% | 由模型出力上限减实际发电推导，非真实弃电观测 |
| 2060年光伏实际容量因子 | 4.92% | 在当前出力/需求/储能假设下算得 |
| 2060年未满足服务 | 3.254亿MWh服务量 | 占请求服务量0.864%；不同服务代理相加不是统一的缺电量 |

2060年缺口中，原有电力服务约2.246亿MWh，交通服务代理约1.008亿MWh。模型自2041年开始出现超过1MWh的缺供。多建风光与夜间缺供并存本身并非逻辑矛盾；问题是当前建设、配套和需求规则不足以把这种结果解释为可靠的全国预测。风光变量同为零边际成本，技术间弃电分配可能受最优解非唯一性影响，故优先报告合计未利用比例。

修复验收：建设能力与电站存量分开，给出施工、资源与接入约束的依据和结构对照；项目预期收益必须检验新增装机的消纳条件。不能只把35TW截断到一个“看起来合理”的数再重跑拟合。

## 4. P2：碳价传导不完整，不能把局部无响应解释为稳健

定位：`q2_national.py:186`—`:191`、`:431`、`:471`。

同初态将2025年碳价从0提高到约9794元/吨，仅用作机制探针：运行LP输入和调度输出完全相同，用户设备申请也完全相同；发电企业结算利润确实变化。碳价不是没有接入，而是主要经事后利润、下一年度投资阈值传递。

原0.5/1.5倍碳价试验中，2030年排放、总装机、非化石代理份额不变；2060年正排放分别变化约 **+1.463亿吨 / -0.829亿吨**，因此不能声称全路径完全不受碳价影响。2025年模型煤电排放强度低于其假定免费配额基准，高碳价可提高该年煤电结算利润，这也不应直接当作符号错误。

主方案允许以资源成本最小化作系统调度，因此“LP没有碳转移支付”本身不必然是编程错误；直接将碳交易额加入社会资源成本反而会混淆边界。但如要研究市场报价、覆盖行业的终端替代和政策传导，需要另设对应行为/约束，并把实际覆盖范围、机会成本与现金结算分开。应先明确政策机制，再设计有预期方向的反例。

## 5. P2：日内SOC守恒不等于跨年状态连续

定位：`q2_national.py:422`。

每年期初SOC重新设为当年储能容量的50%，没有继承上年末SOC；新建/退役储能携带的能量未单独记账。复算最大跨年差为2044年约6.883万MWh。燃料库存同样每年重新初始化，不能承接上年的事件状态。

当前每个代表日强制循环，不能据此声称模型每天都凭空获得这部分电量，也不能把跨年差乘365当作额外发电。问题是模型未建立跨年库存交接，却被描述为年度状态闭环；它会阻碍将跨年压力事件可靠接入主模型。

修复验收：显式继承库存，并记录新增储能初次充电、退役库存处置；或明确研究只比较各年独立稳态，收回跨年库存连续的表述与用途。

## 6. P2：长期需求与关键统计口径仍由强假设决定

定位：`q2_national.py:311`、`:315`、`:440`、`:458`、`:528`。

- 2005—2014拟合的用电活动弹性1.0905固定外推至2060，叠加每年1%强度下降，原有电力服务成为2024年的2.081倍。仅作公式诊断，把弹性改成0.7就为1.406倍；这不是推荐值，却说明只做GDP增速敏感性不够。
- 非化石占比完全复用PEO统计桥。每MWh清洁发电折成2.4955MWh的一次能源等价值是2024锚点派生系数，不是物理转换效率。固定锚点不能自动证明未来非化石消费与政策考核口径相同；生物质、抽蓄和非电非化石边界需分别核对。
- 历史2024年正排放桥接值约12.663Gt；按初态燃料与过程排放公式重建约12.517Gt；2025年模拟为12.943Gt。存在衔接差异，但这组差异本身**不足以证明2025峰年完全由拼接造成**。峰年需单列初态、在建队列及排放桥接的稳健性检验。
- 全国模型没有氢载体/制氢链、显式抽蓄充放电、CCUS或独立输送项目。不是每项新技术都必须假定大规模增长；但题面和主方案点名的能源边界需逐项说明已有部分如何核算、何者因证据不足禁用，不能以八类电源代替完整覆盖。
