# 问题二：名义电价合同、逐年结算与有限批次对照

本轮将已核对的货币换算用于年度合同层，完成七条2014—2024配对路径。**收益和财政支付发生变化，但装机、运行指标与历史拟合均未改善。** 原v9控制完整账保持一致，油、气、风、光四项质量失败继续存在，全国S0未准入。

## 合同实现

[contracts.py](../../src/energy_model/q2/contracts.py)新增可选`nominal_currency`，并在[年度模型](../../src/energy_model/q2/annual.py)结算与项目估值中使用当年可见的`currency_conversions`。未声明名义币种的旧合同继续按模型货币报价；使用名义合同须明确`model_currency`，转换记录包括目标币种、正数因子、转换年份、可见年份和来源或假设。

同一合同保留原始名义报价，每年结算才换算为模型货币。全额电价只支付其与普通售电收入的差额；若差额为负，则按既有规则回收，不能将全额标杆价当作额外补贴。财政预算同样以模型货币约束换算后的金额。缺当年因子、错误币种／日期、非正或非有限数值，以及乘法溢出均失败，不延用旧年份因子。

投资估值只使用当前可见的转换因子，并将它保持到预期运营年。这是明确的静态预期规则，不是未来汇率预测。实际未来因子只在对应年度结算时进入；测试修改2026年及以后因子，证明2026年前的投资、现金、项目、资产、信息和运行记录全部不变。

年度数值采用2026年修订的历史汇率／平减参照；在本次事后回放中将它作为当年年末信号使用。该约定不是已经核验的当年实时发布日期。此机制也没有自动解决增值税、地区基准煤电价、补贴资格或实际拨付时点。

## 冻结的有限批次实验

[映射审查](../../data/catalog/q2_nominal_policy_episode_review.json)明确六项研究假设后，[构建器](../../scripts/build_q2_nominal_policy_episode.py)冻结七条路径：v9原控制、三个2013光伏资源区各自的名义人民币合同、三个按2015换算因子锁定常价美元的对照。全部沿用v9训练所选行为规则、扩张率、初态和现金；本轮没有拟合或挑选方案，累计训练次数仍为3531。

仅对`solar_new_build`的2015年申请开放合同，并假设该批符合电站式光伏备案／年度规模资格，且模型2016投运代表2016年6月30日前全部投运。后一个条件是实验明确施加的年度映射，不能由整数年份推断真实项目日期。其他批次和现存资产不获本次额外合同。因此本试验是有限条件干预，不能当作完整中国历史政策回放。

三种资源区价格900／950／1000名义人民币每兆瓦时来自既有2013原件，分别试验，不作全国加权或选择“最佳地区”。支持年限按原文“原则上20年”设为20个模型运营年，仍是对假定合格批次的映射，不证明实际项目权利。分布式0.42元补贴、风电和后续完整政策日历均未混入。

政府初始现金和私人资金均不增补；年度支持上限采用既有政府初始现金作为宽松但有限的诊断上限，实际支出仍受账户余额约束。该值不是实测中国财政预算。差额计算沿用模型70常价2008美元/MWh的母线价格，不能冒充真实地方燃煤标杆价。报价保留含税基准，未建VAT缴纳与抵扣，因此下面的NPV是模型现金估值，不是实测项目利润。

## 结果：财务变化被既有建设额度截住

| 条件 | 2015年模型项目NPV（百万2008美元/MW） | 名义合同2016—2024累计支持（百万2008美元） | 锁定2015常价对照累计支持（同单位） |
|---|---:|---:|---:|
| v9原控制 | 0.056333 | 0 | 不适用 |
| 假定Ⅰ区条件 | 1.182939 | 8151.580916 | 13294.479106 |
| 假定Ⅱ区条件 | 1.317701 | 9456.120002 | 14884.734758 |
| 假定Ⅲ区条件 | 1.452463 | 10760.659089 | 16474.990411 |

同一区名义合同与锁定常价对照在2015年拥有完全相同的当期报价及NPV；未来实际支付因逐年转换而分开。锁定2015常价意味着另一种合同条款，不能把它当作同一名义合同的正确换算。

七条路径中，该技术2015年的假定年度安装上限均为16340MW，原控制已经投资到上限，加入合同后仍为同一数量。所有[物理指标](../../outputs/q2/nominal_policy_episode/metrics.csv)和[约束用量](../../outputs/q2/nominal_policy_episode/constraint_usage.csv)逐行一致，训练损失均为0.2357603114879326，四项失败没有变化。这说明在这组既有参数和假定约束下，提高收益没有增加获准建设量；不证明真实补贴没有装机效应，也不证明16340MW是真实制造或接入能力。

[执行器](../../scripts/run_q2_nominal_policy_episode.py)额外按每年运营容量占比，从运行账独立重算每个获合同批次的实际发电量，再核对“发电量×当年电价差”和已付／回收现金。六条合同路径各有九年运营记录，共54行[批次现金核对](../../outputs/q2/nominal_policy_episode/cohort_cash.csv)，最大残差约4.55×10⁻¹³百万美元。原始报价、转换后电价、普通售电价格、发电量和转移额均保存。

## 验证与复现

七项新测试覆盖等价币价手算、避免双付全额电价、名义合同由补贴变为回收、合同币种随授予保留、当前因子估值、未来信息隔离、缺年不前填、无效转换与溢出拒绝，以及转换后的财政限额。完整回归344项通过，其中162项Q2。

[99文件独立快照](../../outputs/q2/nominal_policy_episode_reproduction.json)在两个环境各执行构建器与七条路径，15个结果文件分别全部逐字节一致，包含当前溢出保护代码。旧v9控制完整账一致；既有工程入口的19项科学产物也与旧参照相同，见[回归证据](../../outputs/q2/nominal_contract_engineering_regression.json)。重复运行目录保存在忽略的tmp中，正式结果留在outputs/q2。

```powershell
python -B -X utf8 scripts/build_q2_nominal_policy_episode.py
python -B -X utf8 scripts/run_q2_nominal_policy_episode.py --output-dir outputs/q2/nominal_policy_episode_reproduce
```

输出须使用新目录。本轮有可复算的“收益变化—执行约束—实际支付”机制证据，但不是H01完整验收、全国政策效果识别或未来B6。下一步应检验初始光伏建设队列与有效建设约束的共同作用，同时继续完成服务、设备、统计边界、2024初态和净CO2映射。
