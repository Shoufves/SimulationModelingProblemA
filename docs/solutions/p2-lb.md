## 已实现的计算链

`run.py q2` 是新增离线入口。Mesa 3.3.1 组织供给商、电源企业、工业/交通/建筑用能、电网储能和政府主体，SciPy 1.16.3 / HiGHS 解给定资产下的跨时段运行。

每年按固定顺序推进：到期投运及合法退出 → 读取当年驱动与已发布生效政策 → 活动量形成服务需求 → LP运行 → 燃料、能碳和现金结算 → 更新收益预期并申请项目 → 共同许可约束下按比例批准 → 队列留到未来。

企业正NPV产生投资申请，审批不靠遍历顺序抢额度。建设资金全额预留、按建设期逐年等额支付，投产后不再重复支付。运营亏损侵占承诺资金会明确返回 `financial_infeasible`。设备更新采用存量/寿命的轮转近似、安装限额和现金限制；只能下一年生效。该近似**尚不是全国设备年龄队列**，新增设备和初始电网的完整更新退出仍需扩展。

电源按队列区分建设、在运与永久退役；备用、停产不提供出力，退役不能复活。许可退出日期由输入显式给出，尚无全国延寿/停复机行为识别。电网储能采用显式的缺供响应扩建规则；供给商根据上期利用率形成报价，国产与进口能力分列，不把进口冲击乘到国内产量。

## 运行与账本

- 所有运行流量是时段 MWh，功率 MW 只乘一次小时；燃料采用低位热值。电力终端与母线之间计输送损耗。
- 工业用气、电源和转换设施共用同一燃料账；原料供给、库存容量、注入和提取能力均受限。氢能用电解与燃料电池转换接口检验；不把没有运行的氢业务当全国应用成果。
- 先逐层固定服务缺口最优值，再最小化资源运行成本。服务优先级及同层“有用能MWh相加”的价值假设都由夹具预先给出，不代表真实社会福利排序。
- 储能SOC连续，充放电功率与能量分别限幅，共用逆变器；水能预算、机组可用率、平均功率爬坡与最小出力显式约束。若LP产生同时充放电，返回需离散约束的状态，不隐瞒循环耗能。
- 本轮工程窗口为4个连续6小时段构成的确定性循环日，重复365次。权重只进年度流量/费用，不进库存递推；日末SOC/燃料库存回到日初。没有季节储能、时序天气概率、完整网络安全、启停机整数约束或CCUS。全窗口信息已知是条件假设，不能称真实全年可靠性。
- 企业现金、政府收入和社会资源成本分账。税款在企业/政府两侧抵消，内部购售电/氢支付抵消；资源成本只计供给成本、运行维护及实际建设支出，不再叠加LCOE。
- 碳费是夹具的“已覆盖排放净收费”，**尚不代表中国免费配额与履约规则**。一次能源采用显式物理折算法，不能直接判定官方中国非化石消费占比目标。生物质零因子和碳桥常数只属工程设定。

## 校准与试验已跑到什么程度

固定 2015—2021 训练、2022—2024 已接触留出。五个目标为一次能源、非化石份额、装机、发电和燃烧排放；使用 `Σ(权重/实际可比年数)×标准化误差平方`。27组有界网格只用训练记录选参，之后才评估留出。保留逐年残差、缺年、分项损失、训练末值持平基线及关闭投资/替代的机制对照。

**观测由同一个模型显式生成，零拟合误差不是科学验证。** 当前得到3组等效参数，说明即使工程夹具也不能凭一个最优参数宣称识别成功。等效参数均继续运行至2060；GDP年增长上下1个百分点、成本下降率上下1个百分点、碳价乘0.5/1.5均实际运行，属于计算测试幅度，未取得团队的现实参数共识。确定性模型不虚报重复种子精度或现实达标概率。

2030/2060工程表包含能源、份额、正排放、移除、净排放、中和比率、强度、2005/2025基准和峰年。缺少可比2005基准时明确留缺。峰年要求后续至少5年连续不反弹下降，且余下模拟期均低于峰值；端点最大、平台和短降反弹不确认。即便工程情景出现峰值，也需联合检查缺供，不能将供能不足造成的减排当转型成功。

运行器不联网、不生成新准入、不自动刷新指纹。每次先把最新尝试写成未成功，再运行；失败不覆盖旧成功成果，但校验器会拒绝把旧成功当作当前结果。产物、代码、配置、输入哈希、真实提交及dirty状态、环境、求解状态和残差均留档。成功复跑时旧结果移到相邻attempts目录保存。

`scripts/make_q2_fixture.py` 是单独的夹具开发命令；它明确重建合成参数和自生成观测，普通运行与核验不会调用它。不能用它绕过真实输入变化。
