# 本轮：新机效率、项目竞争与煤价联合机制

2026-10-20。完整目标仍未完成，默认长期预测尚未迁移。本轮修复物理与企业投资机制，并完成新的对照，不将测试通过或单项改善等同于全国科学验收。

## 已完成并可核验的改动

新煤气项目在批准时记录技术效率，投产时传入自身资产；旧资产及期初在建项目不免费升级。运行使用按有效容量加权的调和效率，队列燃料与CO2回到LP总账。煤净0.45、气净0.55/0.58为两组明确技术参照，不冒充全国逐年实测效率；净毛转换仍采用既有厂用电参照比例。

独立核查发现原热机投资审核计算整个同技术行业的新增利润，相当于统一业主。新版本依主方案改用项目自身实际可售量，允许分走旧机组销量，但新旧售量之和必须等于LP输出。风光按每时段可用出力、热机按有效容量分配；每年核对各队列售电、燃料、运维、ETS和利润回行业总账。实际现金仍走原有限融资与结算，不重复支付分解账户。代表部门资金池、共同利用率等限制仍明确披露。

独立审查还修正了ETS现金流方向与“关闭热机审核却开启项目竞争”的配置漏洞。最终520项全量测试通过，见 `outputs/validation/project_competition_full_tests_20261020.log`；其中8项为新增项目竞争专项。此前512项热机阶段结果保留。

## 已完成的实验与结论

| 实验 | 可复现产物 | 实际结论 |
|---|---|---|
| 三组财政承诺×关闭/净55/净58效率 | `outputs/q2_thermal_pairs/20261019T235331010638Z/` | 9组成功，关闭时完整恢复上一工厂；新机技术进入燃料与现金账，但没有解决总装机缺口 |
| 两组效率×三组承诺×统一业主/项目竞争 | `outputs/q2_project_competition_pairs/20261020T000557617231Z/` | 12组成功，6组关闭控制逐表精确恢复；固定原参考煤价时，总装机仍约230万MW，不能宣称修好全国拟合 |
| 统一业主下，煤价与效率联合 | `outputs/q2_thermal_coal_window/20261019T235712704081Z/` | 30组完整2015—2019对照；部分配置2015新机平均NPV已正，但行业增量利润审核仍拒绝全部煤电新增 |
| 项目竞争下，相同煤价与效率联合 | `outputs/q2_competition_coal_window/20261020T001012712040Z/` | 30组成功；17%税额扣除假设下，初态保持原价格时批准约4.64万MW，初态使用指数时约8.99万MW；保留实际工期。未扣税及原参考价仍0新增 |

上述两种税口径均为事先声明的敏感性，不能按新增投资是否出现选择税基。正在核读公开矿权评估报告中引用的发改委指数编制说明；未完成核对前不改变旧实验的税基未知标记。2014—2019月指数完整，2020以后同系列仍有缺口，也不能把电厂到厂价视为非电部门实测价格。

政府支持仍在独立财政、资格、应收应付和实收账户核算。气电/煤电容量收入、全国年度CfD、税收融资优惠仍需继续接入；本轮没有用新增无来源补贴把NPV强行调正。详见 [政府支持覆盖](government_support_status.md)。
