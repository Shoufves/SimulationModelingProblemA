## 3. 固定用途与复算

`scripts/prepare_q1_review.py`仅负责把以上已完成审查写成指纹配置，不由`run.py q1`隐式调用。新增数据或口径变化必须重新审查，不以改哈希代替审查。Q1运行检查处理文件及原件指纹，按固定筛选条件处理数据；缺输入、单位错误或重复记录阻断运行。

`history.csv`保存来源记录，并明确跨发布/跨汇编记录的角色。统计局统一历史已经去除同源重复转录；公报、研究库和IR​ENA另列，不把一致性当独立确认。不同年份/单位/发布版本不合并；缺年显式列于`coverage.csv`。图表和结论只能引用相应口径内的值。

## 4. 尚不能支持的结论

完整2024全国初态、全技术相同可靠服务总成本、近年完整价格波动、天然气净进口依赖、原油国家HHI、小时安全裕度、全国净零/CCUS路径均未由本次用途审查批准。三张新增转录只属于lb方案的可复核增量；未经三人评审不能宣称共同验收输入已被统一更新。
