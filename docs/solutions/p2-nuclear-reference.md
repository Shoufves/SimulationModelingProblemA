四组许可身份及日期来自既有[2015年数量补充核对](../../data/catalog/q2_nuclear_permit_2015_supplement_review.json)。本次[转录](../../data/catalog/q2_nuclear_capacity_2015_transcription.json)、[用途审查](../../data/catalog/q2_nuclear_capacity_2015_review.json)及[逐机组表](../../data/processed/q2/nuclear_capacity_2015_reference.csv)保留页码、容量合并格和两类原始编号。旧版审查原样保留。

## 许可和实际事件不能合并

田湾[原通知HTML](../../data/raw/q2/nnsa_tianwan56_notice_2015.html)为国核安发〔2015〕275号，生成日期、落款及印发日期均为2015年12月23日。URL包含20151225，不能单凭URL认定公开发布日期。通知同时颁发两台建造许可，但只批准5号机组首次核岛基础混凝土浇注；6号机组还必须另经检查批准。

[5号许可证](../../data/raw/q2/nnsa_tianwan5_permit_2015.pdf)国核安证字第1515号，物理1—3／印刷3—5页；[6号许可证](../../data/raw/q2/nnsa_tianwan6_permit_2015.pdf)第1516号，物理1—3／印刷5—7页。6号第六条将首次浇注列作控制点；未经放行不得开展对应工作。已核验的6号首次浇注放行日期仍为空。2015年12月23日的建造许可不能替代该日期，更不能替代运行许可。

许可证中的田湾5/6编号为CN-53/54，CNS7中则为CN-55/56；CNS7的CN-53/54对应防城港3/4。若直接按CN编号连接，会把田湾1080MW(e)误接为防城港1180MW(e)。[冲突表](../../data/processed/q2/nuclear_capacity_2015_conflicts.csv)保留两套编号及误连对象；本次根据原件电厂名称和机组号对应，不猜测冲突原因。

仓库另存的福清资料有后期修订或2021年发布的1161MW口径，未覆盖本次2015状态表的1150MW(e)。源版本、容量定义和时间差异未被平均或消除。

## 复现与仍需完成的事项

```powershell
python -B -X utf8 scripts/prepare_q2_nuclear_capacity.py --output-dir tmp/q2/nuclear_capacity_reproduce
python -B -X utf8 -m unittest discover -s tests -p test_q2_nuclear_capacity.py
```

提取入口离线读取已目视核验的转录，先检查原件、审查文件和来源记录指纹，再按电厂/机组核对一一对应、日期、单位及缺项语义。它不声称通过OCR自动恢复合并单元格。输出3个文件，分别是逐机组参照、编号冲突和核验摘要。负向测试覆盖原件损坏、身份重复/缺漏/误连、热功率混用、非有限容量、日期越界及把缺失事件填成许可日期。

目前仍缺多年完整许可及放行日历、同期信息可见时间、剩余工期/现金与运行许可。2016—2018年报的申请审评记录不等于颁发记录，关键词检索未命中也不能推出零许可。任何执行模型的日历修订都必须再有实质证据和冻结对照，本次不据此重写历史模型或宣称全国S0完成。

本次完整回归319项通过；[独立复现记录](../../outputs/q2/nuclear_capacity_2015_reproduction.json)保留13个输入/代码文件的哈希，两种Python环境各3个产物均与正式提取逐字节一致。首次沙箱测试中一个临时目录读写遇到Windows ACL限制，使用正常本地权限重跑完整套件后通过；未将环境错误写成模型成功。

后续已取得CNS8§6.1的明确零颁发陈述，2016—2018这三年不再依赖关键词缺失推断；其具体审批回放和第八轮结果见[v8说明](p2-iteration-v8.md)。本页2015容量、日期及编号核验原值不变。

2024年末当前状态另见[核电设备与在建队列参照](p2-nuclear-state-2024.md)。它与本文2015历史许可用途分开，2025发布的回顾资料不反向填充历史信息集。
