# 问题二第八轮：核电实际发证结果与新建审批

v8将有明确证据的2016—2018年核电零建造许可颁发纳入逐年审批，保留原参数、初态、建设队列和质量阈值。核电留出MAPE由12.29%降至4.58%，RMSE／持平基线由1.502降至0.558，通过原数值门槛。**仍有油、气、风、光4项未通过，全国S0及完整问题二未验收。**

## 来源、时间和适用边界

[中国第八次《核安全公约》国家报告](../../data/raw/q2/china_cns_8_2019.pdf)封面日期为2019年8月，物理41页／印刷36页§6.1明确说2016—2018年未颁发建造许可证。这是原文给出的零，不是检索未命中推断的零。三年非负颁发数量合计为零，故每年均为零；不能由此推出同期没有核电施工、首次装料或投运。

[用途审查](../../data/catalog/q2_nuclear_nonissuance_2016_2018_review.json)固定原件、页码和源记录，只允许回放这三年的实际行政结果。此用途与同期信息有严格区别：2019年回顾报告不是2016年提前公布的停批政策。模型在每年审批环节才施加当年结果，投资主体的估值不读取未来停发年份；所得历史路径仍是给定实际行政事件的条件回放，不能声称预测了政府行为或识别了政策因果效应。

报告的45台运行／11台在建与NNSA2018年报44台商业运行／12台在建分类不同，未据此拼接在运口径。2015年8台容量与开工状态见[另册核验](p2-nuclear-reference.md)，本轮未把其直接转成离散项目决策，也未补猜其他年份。

## 实现与冻结设计

[逐年审批事件](../../src/energy_model/q2/approvals.py)为可选输入，仅影响对应年度、对应新建选项。到期前既有队列照常支付和投运；新申请被拒时不发生资本承诺、建设支付或入队。未提供事件的配置保留原行为，事件之外仍须满足原有许可、资金、施工、接入和替换限制。缺少某年的事件不会被解释为实际零颁发。

[冻结构建器](../../scripts/build_q2_permit_candidate.py)从v7训练选择继承全部数值参数，只新增3个明确的政府审批结果。文献纠正为本版本必用条件，不能因旧错误假设的训练损失较低就丢弃；旧版本保留为[配对对照](../../outputs/q2/historical_candidate_v8_ablation/summary.json)。在纠正后的同一结构下比较原有3种行为规则，无新增数值参数。训练窗口仍为2015—2021，选中instant_margin，训练损失0.262688888；旧v7为0.255206596，**训练损失略上升**。

本轮3组训练均成功；累计8轮3045组有效训练候选。2022—2024留出已在前序开发中接触，本轮没有盲测意义，不改阈值，也不按留出重新选择参数或规则。

## 配对响应与复现

沿用既有GDP增长倍率0.8／1／1.2、技术降本倍率0.5／1／1.5、碳费0／25／50常价2008美元每吨的27组研究响应范围；[27组均运行成功](../../outputs/q2/historical_candidate_v8_sensitivity/summary.json)。这些是2014—2024条件响应，不属于全国2025—2060的B6验收，也不是概率区间或真实历史碳价政策。

单因素GDP增长倍率上下浮动20%，2024能源代理变化−6.12%／+6.86%，燃料CO2代理变化−7.02%／+7.76%；降本倍率0.5／1.5下光伏装机变化−13.62%／+10.04%。全部组合、基准和失败状态均保存，没有据此挑选更好留出参数。

完整回归326项通过，含144项Q2。7项新审批测试覆盖拒批资金与队列、其他技术不受误阻、现有项目继续投运、未来事件不影响过去、空输入与范围外事件不改旧结果、错误事件和留出目标不参与训练选规则。此前6项新核电参照测试仍通过。

[独立复现记录](../../outputs/q2/iteration8_reproduction.json)包含95个代码/输入文件的指纹。固定环境候选17/17、配对对照8/8、响应33/33个产物逐字节一致；另一环境分别16/17、8/8、33/33，唯一候选差异为字体栅格器产生的PNG，数值账本及规范SVG相同。已目视核对图表。旧v7完整控制账不变；v8配对结果与响应基准的完整账本一致。旧候选结果未覆盖。
