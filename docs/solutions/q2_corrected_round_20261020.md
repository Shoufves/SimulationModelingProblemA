# 联合投资与补贴期限修正的实际结果

2026-10-20。当前候选统一使用`q2_corrected_factory:build`，修复一项投资失败会连带缩减另一盈利投资的问题，并接入已核验的光伏支持期限。旧源码与历史实验保持可复现。

## 已完成

- 新审核只缩减非正NPV项目，每次重算整个组合；次数耗尽时移除失败项后再次审核。融资、建设、补贴承诺及已批准项目保护保持。9项反例测试通过；其中真实调度反例由误批风电1 MW＋光伏2 MW修正为风电2 MW＋光伏2 MW。
- 关闭两项修正，完整历史及财务、资产、项目、年末运行状态与旧工厂逐位一致。独立收据：`outputs/validation/corrected_factory_independent_review_20261020.json`。
- 717候选全部重新训练，0失败；全部训练评分独立重算差0。2015—2021选参、2022—2024已接触评估，原门槛不变，三个未知授权条件全部报告。
- 九组投产时点敏感性、Q3普通快照、六边界和气电增发冻结均承接修正工厂。Q3重建历史路径完全一致，不再使用旧工厂冒充本次结果。
- 最新全量489项测试通过：`outputs/validation/corrected_full_tests_20261020.log`。

## 结果和未解决项

联合训练选择与前次相同。气/纯油/生物能源/风/光发电MAPE仍为3.38%/12.03%/19.59%/2.18%/11.89%；总装机与光伏装机MAPE仍为24.90%/26.77%，未通过原门槛。2024总装机缺口约10.47亿千瓦。修复算法的真实问题不能等同于改善这个获选案例的拟合。

已生成[八项历史对照图](../../outputs/q2_revenue_recalibration/20261019T225922280430Z/figures/historical_validation.png)，同目录包含可编辑SVG及逐点数据/来源哈希。图中明确区分训练与已接触评估；它展示当前局限，不作为最终论文结论。

独立收益核算未发现煤气燃料单位错误、固定运维或燃料费重复扣除。固定技术参考价、2018后售电价延续与新建技术成本套用存量的假设，是继续核查的重点。旧获选案例煤电和水电均没有自主新建；气电2015—2017有三项项目。水电经营现金为正，但学习预期收益不足覆盖新建成本；不能把这一现象全部归为融资不足或缺少补贴。

已实际取得电煤指数编制方案及2014/2015全表、2016前九个月与9月比较表。去重33个月有值，2016第四季度仍缺；5000大卡/千克到厂和全国加权口径已核读，税口径未明示。资料和限制见[电煤价格说明](../sources/q2_coal_prices.md)。固定2015发电量的价格诊断显示收益对该假设敏感，但只是会计敏感性，不是重跑后的投资改善；尚未替换模型价格。
