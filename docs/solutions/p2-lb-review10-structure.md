# 问题二：发电结构与非发电需求的解耦修复

2026-10-20，`p2/lb`。本轮继续处理 `review(9)` 暴露的问题。V9 已完成完整独立复现，36项交付检查中35项通过，唯一失败为经验误差验收；煤、油、气份额MAE均不合格。其代码快照、正式结果、复现结果、日志和逐文件哈希已归档到 `archive/q2_review9_policy_dispatch_failed.zip`，不能将其作为V10通过的证据。

## 修改依据与方法

原全国同质电力成本排序导致气电、油电被煤电完全替代。再用同一个总量损失校准终端燃料需求，会让终端参数补偿发电结构错误。V10按以下顺序处理。

1. **独立识别非发电需求。** 对煤、油、气分别计算条件残差 `R = 统计一次燃料消费 − 该燃料观测发电量 / 假定发电效率`，以2014为锚，仅用2015—2021拟合GDP弹性。该残差包含非能源原料、其他转换及统计差异，不是新增实测终端消费。弹性固定后再校准投资和调度，不再让调度误差自由改写它。原煤油气份额目标与验收门槛保留；不把同源残差再算作独立样本增加权重。识别明细导出为 `demand_identification.json`。
2. **约束内的化石内部调度分配。** 先求服务短缺最优；适用年份执行原非化石替代优先步骤；再按原实际费用求基准解，并固定该解的化石总发电量。最后在同样的物理、燃料、储能、付款约束内，用实际费用加凸分段行为评分分配煤、油、气发电。没有硬发电下限，缺燃料或相对价格变化仍可使某技术退出。评分不能进入现金、社会资源成本或排放账。
3. **纠正初态利用率分母。** 水、核、风、光的初年发电量除以前后两年年末容量均值，近似年内平均在运容量，而不是把年底才投产的全部机组视作整年在运。只读取初态及此前数据，保留0.9上限；这是中期投产近似，不能解释为实测小时可用率。
4. **识别2014未观测在建队列。** 水电、核电各有一个有界的初始队列倍率，由训练期选择；倍率同时缩放容量、总造价、分期付款及未付余额，建设期不变。2024预测初态独立按当时以前的三年净新增重构，绝不复制2014训练投产路径或其倍率。另检验未来队列上下界。
5. **生物质交付能力不再套用默认2.5%历史增速。** 使用2005—2014生物质发电增长作为有限交付能力代理；2024以后仍按已声明规则逐步回落。它不是实测原料供应、不是必须消耗的数量，也不产生负排放。
6. **让分技术误差进入训练。** 总发电损失权重由1拆成总量0.5、八技术各0.0625，家族总权重仍为1。装机家族也保持总权重1：总装机0.25，风/光各0.25，水/核各0.125。每项误差尺度只取训练均值。数据同源且依赖，不算作新增独立证据；原全部验收门槛不放宽。

首轮575次训练的V10诊断已通过油、气份额门槛，但煤份额MAE为2.28个百分点，仍超过原2个百分点门槛；失败结果和快照保存在 `archive/q2_review10_identification_diagnostic.zip`。该诊断还发现，仅以发电量识别水电初始队列，会与后续偏快的新建能力相互代偿。因此增加水、核装机目标，并在 `[0.25, 0.5, 1]` 内识别水电建设能力系数，申请和最终批准都服从同一个实际建设上限。系数不是剩余水能资源的实测值。进一步冻结三轮交替搜索，共1012次训练调用；参数选择仍只看2015—2021。

行为评分采用 `H_i(Q) = −c_i0 Q + κ/(2B_i) × (Q−B_i)²` 的分段近似（省略不影响决策的常数），其中 `B_i` 由初态发电/装机和当期模拟装机确定，`c_i0` 为初态工程边际成本。固定化石总量后，共同线性常数不影响内部选择。燃料价格冲击不重新标定 `c_i0`，否则会把真实冲击抵消。分段默认宽度0.1，另检验0.05/0.2；曲率在冻结的有限训练网格中选择，并有关闭与上下界对照。

## 原始依据与适用范围

- [Howitt (1995) 原始论文](../../data/raw/q2_structure/howitt_positive_mathematical_programming_1995.pdf)，AJAE 77(2)，329—342页：提供从初态配置校准凸响应的PMP方法动机。论文研究农业，不提供中国电力调度参数；本模型是借鉴其思路的聚合近似，不能声称复现原论文或识别真实市场摩擦。
- [IEA《中国电力系统转型》2019原报告](../../data/raw/q2_structure/iea_china_power_system_transformation_2019.pdf)，印刷14—15页：讨论计划分配与经济调度转型及报告情景中的气电分配。用于说明纯成本全国完全替代的局限，不提供当前机组级约束或本模型曲率值。
- 原国家统计局容量和能源表、OWID原CSV仍为原511条观测的来源；本轮扩展用途经过单独记录，未新增或伪造观测。

查到的广东、上海气电电价和生物质政策说明全国统一收入假设存在局限，但其地区、机组、利用小时、补贴资格与回款边界不同。本轮没有将其中一个价格冒充全国历年平均收入，也没有新增虚构热负荷、垃圾量、容量补贴或无限财政资金。既有收入代理仍需通过财务假设敏感性解释，分技术残差不能隐去。

## 验证与解释

调度反例覆盖初态恢复、相对价格变化、缺燃料、零需求、清洁发电排序、储能耗散、重复时段、单位缩放、真实费用与行为评分分账及分段细化。默认未启用新机制的路径与归档V9夹具逐字节比较，保持兼容。

新增全国反例验证：2022以后观测扰动不影响需求拟合；均容量仅用初态及此前数据；训练队列倍率不进入2024重构；价格冲击不会被重新标定抵消；三个新增诊断字段恢复到原始单位。独立交付审查还从实际供应、发电和电网支出重新加总资源账，防止行为评分混入费用。

最终验收以当前代码完整训练、2015—2024路径、2025—2060路径、全部条件试验与独立进程复现为准。阶段试算不替代正式收据。2022—2024已被多轮结构修订接触，始终标注为已接触评估，不能重新称为盲测。

条件试验最多使用4个独立进程，每个试验有自己的状态、随机种子、现金与项目队列；按冻结的输入顺序收集结果。串行与并行结果逐项一致的回归测试是交付检查的一部分。执行方式不改变参数、试验点或误差门槛。改为并行前的未完成串行运行标记为中断且产物无效，随后从正式入口完整重跑，不能沿用旧收据。

全国单节点、代表日、热电联产缺口、抽蓄/水电统计边界、非电清洁能源、未来收入及过程排放/碳汇仍是明确的适用范围限制。通过数值容差不等于验证所有这些机制，也不等于官方非化石目标认证、全温室气体碳中和认证或团队批准。
