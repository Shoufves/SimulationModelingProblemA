## 全国能源表的核查结果

在原作者同一数据集合内找到全国能源清单，版本 DOI 为 `10.6084/m9.figshare.5425546.v1`，2017-09-20 发布；与已有的 30 省清单分开保存。[原始 XLSX](../../data/raw/q2/ceads_national_energy_inventory_2000_2015_v1.xlsx) 的文件 ID 为 9360832、大小 139260 字节、MD5 为 `ffbcc886b7e880dd88c883c71aa78365`，均与[原始元数据](../../data/raw/q2/ceads_national5425546_v1.json)一致。SHA256 为 `541f53af9bad48184aa87f7378a229cba765de6b9157b08f0411461a9c86a237`。

仅审查 2014 工作表，不使用后续年份作初始化。[离线脚本](../../scripts/prepare_q2_national_balance.py) 使用固定版本 openpyxl、以 `data_only=False` 读取未修改的原件，保留原单位、符号、留白、单元格地址及版本，输出 [1260 个数据单元](../../data/processed/q2/national_balance_2014_reference.csv)。20 个能源品种的终端明细、转换明细及净消费恒等式共 60 项，在原表一位小数的累计舍入界内成立。控制合计、Coke Input 附列、非能源用途和损失均不重复相加。

原作者[方法论文 HTML](../../data/raw/q2/ceads_national_methods_2018.html)说明排放计算排除非能源用途、运输损失及非燃烧转换。该说明不意味着清单每个单元格已经完成上述扣除，也没有解释本项目发现的全部差额。[用途审查](../../data/catalog/q2_national_balance_review.json)和[对照表](../../data/processed/q2/national_balance_2014_comparisons.csv)保留以下差异：

## 第五轮模型改变与冻结方式

[构建器](../../scripts/build_q2_fuel_candidate.py)读取固定的 v4 输入和**仅训练期**选择，保留建设结构、核电初始队列、光伏成本、电力弹性及投资调整。新增两种气体初态对照：

1. 保留原先按热电装机比例分摊发电用气的映射，作为控制。
2. 将 CEADs `2014!R54` 的 228.2 亿立方米发电用气按 WRI 默认热值换成 246779283.3333333 MWh，再从原候选的 NBS 2014 气体一次能源代理中扣除。只改变残余气体需求，不改变其他燃料、电力服务、容量或价格。

第二项是明确的跨来源映射假说，并不证明两套总量边界相同；没有将 CEADs 总量缩放到 NBS，也没有倒算观测气电效率或强制调度下限。模型优化运行后，2014 年实际气电用量仍可能不同于原表，所以不声称完成初年精确重放。

煤、油、气残余需求分别设 GDP 弹性，在同一个 `0、0.5、1、1.5、2` 网格上检验；此前将三者绑定一个弹性的限制被移除。边界是研究假设，不是经验置信区间。残余需求仍不是已核验的工业热、交通里程或建筑舒适服务，也未实现真实同服务设备替代。

在查看本轮结果之前冻结 [v5 输入清单](../../workflow/q2_candidates/v5/manifest.json)：2 个初态映射 × 3 种预期/投资规则 × 125 个响应向量，共 750 组。完整保留上游模型搜索的累计自由度；这是已经接触留出后的探索性修正，不能声称独立盲测或全参数联合最优。

## 27 组实际响应实验

[固定实验配置](../../workflow/q2_candidates/v5_sensitivity.json)绑定 v5 输入及训练选择，使用相同种子、初态、资金和工程约束，实际运行以下全组合：

- 各历史年度 GDP 增速乘 `0.8 / 1 / 1.2`，保留年度差异，不把增速变成 GDP 水平。
- 各技术降本率乘 `0.5 / 1 / 1.5`，保留原来的光伏 10%、风电 3%及其他零趋势的区别。
- 所有被模型纳入履约的化石燃料施加 `0 / 25 / 50` 美元（2008 年不变价）每吨 CO₂。按模型的百万美元单位除以一百万；不是中国碳市场实际覆盖或名义人民币价格。

27 组均成功，每组完整运行、动作、资金和资产账保存为 `case_*.json`。[结果汇总](../../outputs/q2/historical_candidate_v5_sensitivity/summary.json)与[单因素配对表](../../outputs/q2/historical_candidate_v5_sensitivity/one_factor_2024.csv)可逐项核查。基准情景还与原 v5 的科学路径核对，而不仅检查设置值相同。
