# 连续运行窗口：技术出力、储能与缺供

日期：2026-10-17。本模块是合成运行机制验证，时间单位为小时、功率为MW、能量为MWh；数值不对应中国观测或任何真实电站，不是全国可靠性评估。与年度主体原型分开运行，不把抽象步当作小时，也不把年度能量直接塞进储能容量。

## 目标和接口

补上原型尚缺的连续运行机制：水电、核电、风电、太阳能、煤电、气电分别给出可用能力；储能有连续荷电状态、功率与能量上限、充放电损耗。比较相同需求和可用出力下有储能/无储能的窗口缺供，检查储能能解决什么、不能解决什么。

入口为`examples/synthetic_operation_windows.json`，实现为`src/energy_model/operations.py`，结果为`outputs/prototype/operations/`。原有`agents.py`的投资时序与三个机制对照保持可独立复现。此模块尚未反馈主体投资收益，不能称年度与小时层已经耦合。

所有参数组均标记`synthetic_assumption`，记录用途、单位和敏感性任务；`mode`必须是`synthetic`。只有完整的合成窗口配置可以运行；配置并不提供绕过真实数据准入的入口。

## 配置与时序

|参数组|含义与单位|
|---|---|
|generation|六类技术的容量MW、效率、变动运维CU/MWh；煤气指定燃料，其他技术按发电输出进入电力边界|
|fuels|窗口内每时段供给功率上限MW燃料低位热值、价格CU/MWh燃料、合成燃烧排放因子|
|storage|容量MWh、期初电量MWh、充/放功率MW、充/放效率、放电变动成本CU/MWh|
|grid|发电侧送出功率上限MW、送达效率；储能位于发电侧|
|windows|连续时段的时长h、终端负荷MW、各技术可用比例、送出上限乘数；不是典型日年权重|
|policy|当期合成碳价CU/合成排放单位；外生|

每个窗口独立从明确的期初SOC开始；**同一窗口内部不重置SOC**。各对照使用相同期初电量，输出期末SOC差异，不强行补成循环边界。示例设置期初为0，不能利用免费初始库存制造收益。若自行改变初始电量，其历史来源、费用和排放均在窗口外，结果不含这些上游量。

每时段仅向调度器传入当前负荷、可用比例、送出能力、碳价和上一时段SOC：

1. 根据负荷、网损和送出能力，计算本时段发电侧供能目标。
2. 非燃烧技术按变动成本排序。先满足该目标；只有当前剩余非燃烧出力可以充电，受储能功率、剩余容量和效率限制。没有跨时段价格预测，没有煤气充电。
3. 没有充电时，储能在非燃烧供能不足时放电，先于煤气机组。放电与其他电源一样受送出上限限制，不能绕过线路瓶颈。
4. 煤气按含碳边际成本补足剩余需求，受装机及燃料供给限制；剩余缺口显式记录。
5. 更新SOC，保存技术出力、燃料投入、弃用可用电量、储能及网络损耗、成本与排放。

这是明确的“优先利用非燃烧出力、储能先于火电”的调度规则，不是全期成本最优调度。它可能过早耗尽储能，不承诺储能在任意冲击下均降低缺供。

水核风光的可用比例是当前时段外生输入；水电没有库水约束，核电没有最小出力/爬坡，风光没有天气预测。仅煤气燃烧排放计入，不含核燃料上游、生物质、生命周期、工业过程或移除。

## 守恒和经济边界

储能：

`SOC末 = SOC初 + 充电输入×充电效率 − 放电输出/放电效率`

同一步不同时充放电；功率上限乘以本步实际时长，不把MW当MWh。电力账本：

`非燃烧发电 + 火电发电 + SOC初 = 终端已供电 + 网损 + 充电损耗 + 放电损耗 + SOC末`

火电燃料投入与热电转换损耗另外逐项核对。非燃烧电源以其电力输出进入本模块边界，不能据此计算一次能源消费或非化石一次能源占比。放电不计为新生产的非化石电量，排放只在煤气燃烧时计算一次。

分别报告燃料/运维/储能变动成本和碳支付。未提供储能投资、固定成本、寿命及缺供价值，不能据窗口运行成本判断完整经济性，也不能把碳支付直接称社会资源成本。

## 对照与验收

示例包含三个彼此独立、各自连续的合成窗口：

- 常规波动：日间可用光伏与后续低出力，检验充放电及缺供变化。
- 持续低风光：检验没有可充电能源时储能作用的边界。
- 送出受限：检验发电侧储能不能绕过线路上限。

每个窗口运行有储能和无储能两种机制，初始需求、电源、燃料与线路相同。对照不是赛题全国基准加至少三种正式情景；只报告窗口内缺供MWh、受影响小时、最大缺供MW、合成排放、运行成本、弃用非燃烧出力和期末SOC。不外推全年EENS、LOLP或停电概率。

必要测试：逐时守恒及损耗、非一小时时长、SOC连续性及边界、充放互斥、燃料/输送能力、无未来信息、无储能确实改变结果、持续低出力及线路瓶颈下的局限、初始与期末库存披露、不修改输入。

## 接入真实模型前

1. 对电源技术、部门负荷、储能与线路参数分别建立已核验输入；附件只能按已核实项目字段使用，不能由样本外推全国容量。
2. 锁定年度总量与运行窗口的映射及覆盖权重，年度调度与窗口核验各保留账本；连续极端事件不能拆成每日SOC复位。
3. 先接单个可核实运行窗口，再验证投资模型如何使用已观察的缺供、弃能及收益。尚未完成前，W4保持进行中，W5不因窗口测试通过而改为已校准。
