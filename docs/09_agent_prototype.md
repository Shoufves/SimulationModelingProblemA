# 主体决策原型：实现契约

日期：2026-10-17。此原型使用完全合成的数值和第1—8步，不对应中国任何年份，也不生成全国2030/2060预测。合成案例用于验证主体交互、时序和守恒，不能替代历史校准。

## 首版范围

载体：煤、油、气和电力。供给技术：合成煤电、气电、可再生电源。工业和交通两个需求主体分别持有燃料设备/电气设备份额。燃料供应者持有国产和进口能力，报价响应已观察到的上一期能力利用率。政府按外生政策输入碳价；系统运营者按报价调度，限制网络输送、燃料和发电能力，并记录未满足服务。

暂不实现氢、生物质、水核风光细分、储能运行、完整网络、工业过程及碳汇。现有储能/碳函数继续保留，原型不能冒充赛题全口径模型。附件和已核验全国数据尚未连接到合成案例，避免把缺年限/状态的电站样本强行用作全国初态。

补充：上述限制指本文件描述的年度抽象步主体原型。另有operations.py及docs/10_operation_windows.md实现水核风光煤气细分与连续储能运行窗口，和本主体原型分开验证，尚未耦合投资反馈；不把EU或抽象容量当作MWh或MW。真实历史接入顺序见docs/11_calibration_input_contract.md。

## 参数和单位

所有值集中在examples/synthetic_agents.json。每组参数注明purpose、basis、unit和sensitivity；basis固定为synthetic_assumption。原型拒绝配置标签缺失或mode不是synthetic的文件。

|参数组|字段|单位及解释|
|---|---|---|
|run|steps、initial_electricity_price|抽象步；CU/EU，CU为抽象货币，EU为抽象能量|
|policy|carbon_price_by_step|CU/抽象排放单位；只在当期揭示|
|fuels|domestic_limit、import_limit、base_price、scarcity_markup、emission_factor|EU/步、CU/EU、无量纲、抽象排放/EU|
|generation|initial_capacity、energy_per_capacity、variable_cost、efficiency、capex、lead_steps、life_steps、budget、max_build_per_step、expected_sales_floor、discount_rate|容量用抽象CUap；能量EU；效率是电输出/燃料输入；建设至少1步，投资/容量CU/CUap|
|demand|service、growth、electric_share、fuel_efficiency、electric_efficiency、replacement_limit、switch_cost_per_share、budget、payback_steps|服务SU；能量转有用服务SU/EU；设备份额无量纲；转换投资CU/全份额|
|grid|delivery_efficiency、generation_transfer_limit、scarcity_price|效率；EU/步；CU/EU|

资本预算每步外生重新给定，不模拟企业完整资产负债表。供应价格是基价乘上一期利用率的加价函数，不等于已估计的真实市场。发电收入按统一合成出清价，缺电时使用配置中的稀缺价格；不存在声称市场迭代已收敛的问题。

## 时序与可见信息

1. 仅揭示当步碳价和当步冲击，年初投运到期项目并按寿命退役。
2. 燃料供应者根据上一期实际用量/能力更新报价；形成当期国产和进口能力。
3. 需求主体用当步服务量和既有设备份额提出燃料/电力需求，不能即时免费改设备。
4. 燃料先满足直接用途（短缺按同燃料需求比例配给），剩余燃料可用于发电。该优先规则是合成调度假设。
5. 系统运营者按含碳边际成本排序发电，受燃料、装机和网络限制；电力配给按部门需求比例；分别核算转换、网损和未满足服务。
6. 主体只用当步已观察价格/用量提出投资：需求主体比较两类设备每单位服务成本与转换投资回收期；电源企业比较预期收入的净现值，在预算和步建设上限内投资。
7. 需求设备更新到下一步生效；发电项目在决策步+建设步长投运。保存完整决策信息集和项目队列。

服务增长率是已知合成驱动参数，但主体不能读取未来政策/供应冲击。报告记录每步初态、调度、价格、燃料来源、决策和下一步设备份额。禁止未来信息通过“修改第k步之后政策，前k步记录完全相同”的程序检验。

```mermaid
  A[既有设备与服务需求] --> B[燃料需求和电力需求]
  B --> C[含碳调度与供给约束]
  C --> D[价格 供能 排放]
  D --> E[设备替代与投资决策]
  E --> F[下一步设备及未来投运队列]
  F --> A
```

## 决策公式

需求侧单位服务成本：电力价/电效率；燃料价加当期碳成本后除燃料效率。只有相对当前设备的年节约为正、每份额节约乘回收步数大于转换成本时，按设备替代上限、预算、剩余份额更新。支持从电转燃料，但原型不细分设备报废年龄。

企业每单位容量预期利润：技术单位能量×预期销售比例×（已观察出清价−含碳变动成本）。预期销售比例取自身当期利用率与配置期望下限的较大值（上限1），体现可检验的乐观预期假设。按寿命和折现率形成净现值，净现值为正才在预算和建设上限内新建。无未来价格或冲击。

## 验证与机制对照

运行完整反馈、冻结设备替代、冻结发电投资三种机制；它们是合成程序对照，不能充当题目所需全国基准+三种正式情景。比较设备份额、投运容量、未满足服务、能源相关合成排放和投资；不要求每个机制在所有指标上单调改善。

必须通过：四载体分别守恒、燃料能力/网络上限、未满足需求显式、设备非负且不超份额/预算/替代上限、工期至少1步、寿命退役、相同输入确定复现、未来政策变化不影响既往决策、关闭交互机制确实改变路径。程序验证不等于中国历史验证。

统一入口为run_prototype.ps1，输出限定在outputs/prototype/；数据准入与现状初评仍走run_verified.ps1。所有结果醒目标注synthetic，不进入data/observations/。
