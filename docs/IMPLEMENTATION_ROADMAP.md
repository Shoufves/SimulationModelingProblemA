## 必须保持的模型限制

原 `agents.py` 的燃料倍率同时影响国内与进口，直接燃料先于发电分配；原 `operations.py` 在当前时段先用储能再补化石发电。这些代码保留为合成规则基线，不能直接改称进口中断实验或跨时段最优调度。整理未偷偷更改其科学行为，也不以测试通过证明它满足正式LP规格。

正式模型的年度顺序：旧项目投运/合法退出 → 冻结共同信息 → 需求与运行条件 → 供需求解 → 能源/碳/现金结算 → 主体申请 → 统一审批入队 → 下一年。库存按连续物理时间推进；代表时段年权重只能用于年度量。投资当年不自动可用，LP不替代企业投资决策。
