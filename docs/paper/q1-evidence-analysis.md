# 问题一：规模增长与多能源转型的约束

本文是供团队核验后采用的分析稿。原始表、完整九类能源清单、静态账和地区资料仍见[原报告](../../outputs/q1/p1_yx/report.md)。本稿在已合并的lb主线与mmj成本补充上重新组织论证，并增加同一来源跨运输方式的暴露分析。数字后的E编号对应[证据登记](../research/q1-q3-evidence.json)，文献L编号对应[查新登记](../research/q1-q3-literature.json)。这份文字及补充计算有AI实际参与，人工核验尚未签署。

## 结构变化为什么不能只看份额

同版统计中，能源消费从2015年的43.4113亿吨标准煤增至2024年的59.6000亿吨标准煤[E1]。煤炭消费份额由63.8%降到53.2%，按同表总量与份额计算的煤炭标准煤量却从27.6964升到31.7072亿吨[E2]。因此，低碳转型发生在总需求继续扩张的背景下。份额下降可以支持结构改善的判断，却不能单独支持煤炭需求已经见顶，更不能把标准煤量直接换成实物煤或燃烧排放。

以同版实际GDP增速连乘指数作分母，全口径能耗强度和化石工业CO₂强度在2024年分别为83.717与76.015，基期均为2015年[E3]。这两项下降反映单位经济活动的变化，并不等于总排放下降。能耗强度还应与官方扣除特定用能后的指标区分，化石工业CO₂则不能代表包含土地利用和移除的净温室气体总账。

九类能源各自承担的服务也不同。煤炭需要同时考察电力、供热和工业用途，石油要区分交通燃料与化工原料，天然气的气电和工业需求共用气源。水电受来水与库容约束，核电依赖长建设周期和持续利用，风光的装机增长只有结合时序可用率才能转成供能能力。氢是需要生产、输运和终端设备的载能形式，不能与一次能源直接相加。其他可再生能源中的生物质还涉及燃料来源和统计重叠。原报告分别保留这些信息，避免把技术名称做成一个缺少共同服务口径的优劣总排名。

## 保障问题：进口方式与进口来源不能混为一项

国内总量账显示，2023年石油净进口占消费的78.85%，煤炭为9.99%[E4]。前者沿用含油品的原表范围，不改称原油依存度。国际价格也只作为价格环境证据，年度均值不能识别短时断供的损失。原有价格序列在基准变更处断开计算，冲突记录继续隔离。

原报告把管道气与LNG分别计算来源集中度，这能描述各运输方式内部的结构，但尚未回答两者是否共用同一国家来源。本次只使用已经准入的EI工作簿，统一到2024年、China目的地、40 MJ/m³热值口径，并实际复核45个数值单元格[E5]。两种运输方式总计176.4664 bcm，其中1.6843 bcm仍只识别到地区桶，不能强行分给具体国家[E5]。这里的分母是该工作簿的年度毛进口量，与国内总量账、真实可中断供给以及全国消费量都不同。

将各方式的同名具名来源相加后，俄罗斯的进口量为38.0913 bcm，占总量21.59%，高于本表中其他具名来源[E6]。这与单独查看LNG时的主要来源排序不同。该变化说明运输渠道多样化并不自动消除国家来源的共同暴露，也提示后续通道冲击需要另做真实来源映射。本次没有把俄罗斯份额代入问题三的假设通道。

设来源国在管道、LNG中的进口量分别为pᵢ、lᵢ，共同总量为T。具名来源的集中度为10000Σ[(pᵢ+lᵢ)/T]²；若误将运输方式当成独立来源，得到的只是10000Σ(pᵢ²+lᵢ²)/T²。两者相差20000Σpᵢlᵢ/T²。本题中这个遗漏交叉项为194.94点，运输方式拆开后的具名来源下界为1308.22点，合并后为1503.16点[E7]。这是平方项恒等式在本数据上的诊断，不是新的HHI理论，也不是给单方式HHI简单求和。

未识别地区桶若允许任意细分，具名来源项提供下界。为避免擅自认定未知桶与已知国家互斥，上界允许全部未知量叠加到最大具名来源，得到1545.28点[E8]。该上界忽略了可进一步核验的地理排除条件，因而保守且未必可达。原工作已有单方式HHI区间，本次增量仅是跨方式合并及重叠暴露解释。HHI描述集中度，不能直接转换为事故概率或风险等级；能源多样性评价本来已有成熟研究，详见L06。

## 经济性与协调性如何进入后续模型

经济比较先固定价格年、服务边界和融资假设。IEA/NEA的煤气核案例属于报告投影，IRENA的风光成本属于另一价格年和项目集合，两者不能直接拼出当年的全国成本排行榜[L01、L02]。沿用mmj的同参数风电计算，在5%实际折现率、共同寿命假设下，陆风和海风的条件成本分别为0.03104与0.05148美元/kWh[E9]。这一计算用来检验融资敏感性，仍是厂门电量成本，没有包括保供储能、调峰和接网等系统成本。水电、生物质、氢的原有成本或价格证据继续按各自服务口径展示，不以缺失参数补零来比较。

地区协调同样需要克制。2024年31省发电份额与用电份额差异指标为0.1266[E10]，说明生产和负荷分布有别，但不是跨省电量、线路容量或拥塞价格。新型储能在同年为73.76 GW、168.2 GWh[E11]，功率和能量需要同时保留，公开名牌容量还不能证明极端时段一定可用。地区消费责任、风光消纳、核电与水电集中分布见原报告，不能以全国均值替代省级运行约束。

据此，后续仿真的输入应分别对应燃料供给、转换设备、建设资金、工期和连续库存。来源暴露分析补上了“运输不同而国家相同”的一个可复核环节；它没有补齐原油国别结构、可动用库存、省际网架和完整净排放路径。问题一的主要贡献是把不同统计口径下的事实组织为可追溯的约束，以及揭示具体来源结构的解释偏差。它属于应用分析与证据工程，尚无依据宣称原创评价算法或全球首次发现。
