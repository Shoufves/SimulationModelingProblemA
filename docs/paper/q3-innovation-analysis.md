# 问题三：政策是否真正实施，以及条件收益来自哪里

本稿依据已完成的年度主体和连续运行实验，补充政策实施等价类、贡献归因与退役规则比较。完整设定、五方面建议和失败条件见[问题三交付](../solutions/p3-yx.md)，原结果保持不变。E编号对应[证据登记](../research/q1-q3-evidence.json)，L编号对应[查新登记](../research/q1-q3-literature.json)。本稿与补充代码由AI协助形成，待团队逐项复核后采用。

## 条件实验能够回答什么

年度层比较基准、碳价政策和储能降本，连续运行层则在共同事前状态下比较正常、气源受限、天气受限及联合冲击。燃料库存和储能状态随时间继承，短期事件中的损失单独记账。问题二的统计桥接、已接触评估和聚合节点限制仍然存在，所以这里研究的是冻结假设下的反应，而不是官方预测或现实灾害概率。

年度S0、SP、ST的累计资源成本分别为389.014873、388.787441、388.387217万亿元，期间为2025—2060年[E12]。成本包含运行及真实施工，财政拨款和内部碳费不重复当作资源消耗，期末账面资产另列。碳价和降本在此有条件作用，但差值不能直接解释为现实政策的因果效应，也不能缩成单年收益。

在共同2030快照的12天事件中，S0与SG成本均为2291.226531亿元，SW与SGW均为2490.200790亿元[E13]。各情景最大服务缺供率为0[E13]。按服务分开的正常响应与气电向上响应冻结对照，缺供交互J也均为0[E14]。因此，天气条件影响了运行代价，而本事件域没有识别出正的缺供放大或该响应通道的缓释贡献。不能为让创新成立而事后扩大冲击再保留有利结果。

## 退役规则的作用没有跨条件稳定成立

原H01的160个标签点中，156个超过5%年度服务界[E15]。固定项目组用于隔离既有清洁项目投运时间，完整主体组允许经济申请和融资反应，两组工期参数作用于不同项目，不能混称同一种时滞干预。上一轮已把提前退出与受计划管理的到龄退出分开，本次不改该分类。

本次先核对两条速度网格交点的重复物理条件，再按项目组、选择/检验身份、两种速度及工期匹配四条规则。40个标签条件对应34个不同物理条件[E16]，这些是确定性设计点，不是独立随机样本。最大缺供率比较采用原有数值容差，不用尾数差异宣布方法获胜。

与固定日程相比，滚动保障规则在2个条件更好、32个持平；与成本规则相比，1个更差、33个持平；与替代可用规则相比，34个全部持平[E17]。最后这组风险相同并不意味着成本或完整轨迹相同：滚动规则有10个条件成本更低、9个更高、15个相同，最大绝对差为228.374903亿元[E18]。滚动规则在这34个条件中仅1个满足服务界[E18]，因此成本降低不能越过安全约束成为推荐依据。

滚动前瞻与能源优化已有研究先例[L04、L05]。当前实现是利用前瞻服务阈值做有限延期的规则，不能称为求解一般多动作最优控制的MPC算法。公平对照的意义在于找出它在哪里无效以及何时排序翻转；这些证据不支持普遍优于透明简单规则的结论。

## 名义政策组合为什么没有自动形成协同

单看候选名称，电网、储能、气源分散及其组合似乎给出了不同方案。然而本次按实际公共承诺、动作容量、付款及投运年份构造签名后，8个基准标签只对应4类部署[E19]。等价配对为policy_0与policy_1、policy_2与policy_4、policy_3与policy_5、policy_6与policy_7。额外电网申请没有获得剩余施工额度，因此加上电网标签并未增加真实投运资产。

分组依据先来自部署账，而不是看结果相同再归组。随后核验基准及两档成本条件下24条年度账本，并对36对事件账本逐一核对，等价组内规范化内容一致[E20]。这种检查能防止把没有落地的措施解释成有效政策，也为以后先检查执行可行性提供依据；本次只是既有条件下的事后验证，未实现新的在线剪枝程序，更没有实测计算量减半。

对于完整三措施析因表，采用已有Shapley分解分配相对无措施的变化[L08]。在累计成本节省中，储能分量为1.190352万亿元，气源分散分量为−20.061631亿元，电网分量为0[E21]。在累计减排中，储能分量为159.813859亿吨，另两项均为0[E22]。这里的分量属于同一模型、同一窗口和已给定组合的数学归因，不是分别实施后可向现实承诺的收益。

成本的储能—气源交互为−0.0625元，低于由原金额浮点间距确定的1元计算误差界[E23]。其余高阶项同样没有超出计算精度。应表述为“本表没有实质超加性收益证据”，不能把组合名称包装成协同创新。所有候选的年度最大缺供率改善分量也为0[E24]，进一步限制了将成本收益宣传为安全收益的说法。

## 建议与研究贡献的边界

能源结构方面，替代服务和终端更新速度应先与退役条件匹配，不能用成本排名批准越界方案。调度方面，应保留共用气源、连续库存和储能状态，跨省网架尚不足以支持线路级结论。应急方面，当前事件域没有识别气源分散的缺供收益，需要真实来源和库存资料才能扩展推荐。市场机制方面，碳价作用受已有覆盖范围和行为假设限制。科技应用方面，既有储能方案在有限候选中表现较好，而独立氢、CCUS、AI与就业效应缺少完整准入证据，不给出数值承诺。

主体仿真、线性运行优化、前瞻规则、析因实验和Shapley都已有先例。本文可保留的贡献是：在共同资金、施工和信息条件下检查政策能否落地，用实施账本解释名义组合的重复，并用完整对照报告收益来源与零交互。它们补强了结果解释和可复核性，尚不足以证明新的算法理论或普遍性能优势。若后续希望提出更强方法创新，应先独立登记新的假设和检验域，再取得真实对照证据；本轮不以临时增加复杂算法替代已有问题的完整回答。
