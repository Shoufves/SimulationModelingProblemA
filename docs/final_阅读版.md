## 4. 问题一：先找短板，再把短板变成模型输入

第一步，整理生产、消费、装机、发电、区域、进出口和价格；国家统计局同版表作全国规模主线，能源局补技术细分，研究数据库作有边界的补充。四个附件共890条具名记录，缺统计时点、状态及完整燃料类型，只作项目样本与属性证据，不能当全国同期电站清单。[Y §3、14][Y] [M附件][MATT]

第二步，计算以下四维原始指标。有数据才算；缺项写“工作区未记载”，不填零。

| 维度 | 主要计算 | 对模型的直接作用 |
|---|---|---|
| 保障 | 同口径净进口/消费、来源集中度 | 确定燃料来源、共同供给约束和进口压力入口 |
| 低碳 | 非化石消费占比、能源强度、碳强度 | 给需求、结构与排放提供历史校准目标 |
| 经济 | 同服务成本、价格波动、采购与建设支出 | 约束企业收益、设备替代和政策成本 |
| 协调 | 弃电、区域发用电差异、储能功率与能量 | 确定输送、调节和连续能量约束 |

第三步，需要总分时才采用 yx 的固定参照标准化和分层加权；基准等权属于明确的价值选择。指标、参照与权重跨年份/情景固定，另做权重变化检查，缺维度时不强算总分。[Y §16][Y]

第四步，输出“证据—短板—进入模型哪里”的对应表。例如 mmj 已有天然气发电用途记录，因此把工业与气电放进同一气源账本；但年度用途比例不足以给出每小时气源能力。现有四维初评只是阶段结果，尚不能给全国安全等级。[M4D]

## 5. 问题二：模拟主体怎样改变未来，而不是先画排放曲线

**长期用多智能体，年内用受约束供需分配。** Python串联数据和实验；Mesa组织主体；SciPy求解给定资产下的线性规划。选择它们是职责分工，工具名称本身不算创新。[Y §15—17][Y]

| 主体 | 每期观察与动作 | 必须保留的限制 |
|---|---|---|
| 煤油气供给 | 看销售、库存、合同与进口条件，安排采购及供给 | 国产、进口、通道、库存及提取上限 |
| 电源企业 | 看已发生的收入和成本，算预期项目收益，申请投资/改造/退出 | 资金、工期、接入、许可；投资当年不自动投产 |
| 工业、交通、建筑等用能主体 | 先形成服务需求，再比较同一服务的设备成本 | 设备存量、更新速度、效率、适用燃料及预算 |
| 电网与储能 | 分配既有能力、输送及充放电，提出扩容 | 功率、能量、损耗、连续库存及建设时间 |
| 政府 | 实施已知政策；在改进方案中按提前定义的缺口规则行动 | 财政和工程能力；不能预知未来实际冲击 |

每年固定顺序：**旧项目投运/获准退出 → 冻结共同信息 → 形成需求与运行条件 → 求解供需 → 结算能源、碳与现金 → 更新预期、提出投资/换设备 → 统一审批入队 → 下一年。** 各主体先提出动作再统一执行，避免遍历顺序抢占共享资源。[Y §17.7][Y]

运行时先尽可能满足按既定优先级区分的服务，再在相同缺供条件下降低运行费用。供给不足必须输出缺口；工业与发电不能各自重复使用一份天然气；储能每个连续时段接续库存，不能每天恢复满电。年度费用可用经过核对的代表时段权重，极端事件单独连续算；没有概率资料就不报全年停电概率。[Y §17][Y]

校准只调整历史能够约束的少量需求、替代、投资和预期参数，同时检查总量、结构、装机/发电和排放。保留 mmj 四种真实需求基线作比较，但它们使用已实现GDP，且留出结果已经看过，不能当盲测，也不能代替多智能体校准。[M15]

最终输出：能源总量、非化石消费占比、CO₂路径、峰年及峰值、能源与碳强度降幅、2060中和率及剩余排放。能源排放由实际燃烧量产生；工业过程、净碳汇与移除单列。现有完整全国净排放路径输入工作区未记载，因此目前不能给全国碳中和结论。政策目标仅用于比较，不能预先强制模型达标。[Y §18][Y]

## 6. 问题三：保留六组设计，分阶段定位风险和选措施

采用主方案的六组名称。**实施顺序为先S0/SP/SG/ST，再SW/SGW**；这只是加入lb的工程顺序建议，未删除主方案的H02。正式幅度、起止时点和恢复过程逐项登记；尚未形成的统一参数值写“工作区未记载”。

**【裁决：情景编号和AI优先级】** lb原S1中的碳价强化对应SP；S2为较广外供风险，其中“指定进口气源”子情景对应SG；S3的储能降本子情景对应ST。SW/SGW继续单列。保留lb的S4/S5/S6时显式标为“lb扩展”，不覆盖主方案编号。R-L希望第二层AI形成主创新，但大陆AI专属基期与可调任务等必要输入未齐，因此本文保留H01/H02为主实验，AI达门槛后再扩展。不得把煤、油、气冲击或天气变化都塞进同一个S2后解释单项作用。 [RL 第4—5页][RL]  [RY E1—E4][RY] 

| 情景 | 相对基准只改什么 | 要查什么 |
|---|---|---|
| S0 基准 | 已有政策实施与技术趋势 | 当前路径的双碳、安全和成本 |
| SP 政策强化 | 碳价格路径，保留适用覆盖和配额规则 | 投资和设备替代怎样响应 |
| SG 气源受限 | 指定来源/通道的进口能力及恢复 | 哪些用途争用天然气，库存如何消耗 |
| SW 天气压力 | 指定同期风光可用率、水电能量上限 | 哪些地区缺功率或连续能量 |
| SGW 联合压力 | 原样叠加SG、SW | 额外损失来自哪里 |
| ST 储能降本 | 新项目功率、能量投资成本 | 降本是否真转成建设及保供能力 |

氢能/CCUS突破、石油供应中断保留为有数据的子情景；不会因首轮聚焦而删除这些能源。AI快速发展与AI叠加外部风险另作 lb 扩展，不能与气源×天气联合实验混为一组。[Y §19][Y] [L1]

**【补入mmj：保持单项变动】** SP/ST比较长期路径；S0/SG/SW/SGW先用同一资产快照做短期配对。SW首轮不另加高温需求，ST不顺带提高效率或寿命；长期事件另写发生日历。 [RM 第5节][RM] 

每种情景报告缺供量/比例、最长连续缺供、恢复时间、库存最低值、进口暴露、费用和累计排放，分地区和服务保留原单位。恢复判据及关键服务限值的正式取值，工作区未记载；不得由全国平均改善代替局部安全验收。[RM]先用小幅增加某种能力的诊断实验识别瓶颈，再比较可建设的储能、输送、需求响应、储备和合法退役节奏。正式政策必须经过主体申请、资金与工期，不能直接赠送容量。[Y §19][Y]

政策先用少量离散组合逐个仿真；检查预算、费用、累计排放、关键服务、工期与许可，再排除各方面都不占优的方案。在没有情景概率时比较指定条件内的最坏表现，保留成本—排放—安全取舍；没有可行方案就报告冲突，不暗中放宽条件。[Y §19.5—19.6][Y] [M3]

### C1. 原始指标与可选评分

| 指标 | 公式 | 计算前检查 |
|---|---|---|
| 燃料净进口依赖 | `d=(进口−出口)/同口径消费` | 相同燃料、统计期和实物口径；缺出口/库存边界时不补造 |

## D. 问题二：最少需要实现的数学与程序规则

### D1. 状态、服务和投资

采用yx第17节的状态关系：`主体动作=行为规则(当时可知信息,参数,政策)`；统一审批后进入未来队列。实际运行由当期已可用状态确定，结果更新下一年的资产、库存、资金和预期。[Y]

1. **服务需求。** `年度服务Q=活动量A×单位活动服务需求ζ`；`时段需求q=Q×形状φ`，满足`Σwφ=1`。工业、交通、建筑使用各自服务；活动量不足时才用已有GDP/人口作明确聚合近似。参数值与完整部门活动/设备初态工作区未记载。
2. **设备服务。** `提供服务y=η×能源输入x`；`Σy+未满足服务u=q`，并受现有设备服务能力×可用率×时长限制。燃油设备不能不经更新就用电/氢，同一节能效果不能在ζ与η重复扣除。
3. **更新选择。** 比较同一服务的年化设备投入、运维、燃料/效率及适用碳履约费用；只在可更新设备和新增需求中按更新比例ρ实施，受预算、安装与设备寿命约束。
4. **投资申请。** 按yx净现值式，把建设期支出、运行现金流及残值按对应时点折现。预期来自已知合同及已观察收益；更新可用`m̂下一期=(1−λ)m̂当期+λm当期`。正收益只是申请条件，仍需资金、建设、接入、许可及未来承诺支出审核。
5. **容量队列。** `本期账面容量=上期容量+到期获批项目−永久退役`；运行可用量再由状态、检修/备用等映射。备用、停产、延寿、永久退役分开，永久退役后不能自动恢复。长周期水核项目缺行为资料时按有来源的在建队列推进，注明外生部分。
6. **需求响应。** 仅移动已有可调服务，约束比例、时间窗口、补偿与窗口内服务守恒。若减少消费须记录服务损失，不能把缺供重命名为节能收益。

**实现映射：** [accounting.py][CODE1]提供容量、储能和碳核算基础；[fuel_ledger.py][CODE2]保留缺项及边界未核的状态；[agents.py][CODE3]有合成投资/替代反馈；[asset_lifecycle.py][CODE4]有许可信息回放。正式输入先经过缺失检查，不能利用基础核算类的默认0掩盖未知量。已有合成外生预算、销售预期下限等设定不自动成为中国主体参数。

### D2. 年内运行与核算

实现采用**时段能量变量**：发电g、燃料/转换投入b、终端输入x、跨区输送F、储能充放电c/d、库存S/I及服务缺口u。电力用MWh；燃料转为MWh低位热值时，必须先有匹配热值与换算依据。与mmj现有以MW输入的接口连接时只换算一次时长。[Y §15.3、17.5][Y] [M10]

| 约束 | 要实现的关系 |
|---|---|
| 各载体平衡 | 国内供给+进口+转换产出+期初库存 = 已满足终端+转换投入+原料+出口+损耗+期末库存；按具体账本边界避免项重复 |
| 电力平衡 | 发电+储能放电+计损输入 = 终端实际用电+转换用电+充电+外送；服务缺口已扣除时不能再补一份缺电 |
| 发电及燃料 | `0≤g≤可用率×MW容量×时长`；燃烧发电的燃料投入`b=g/效率` |
| 共享燃料 | 工业、发电、制氢等从同一来源/库存扣减；生产、进口、库存容量、提取速率和通道均有限 |
| 储能 | `S下一时段=S+充电效率×c−d/放电效率`；充放电功率×时长与能量容量分别限幅 |
| 输送 | 时段流量受通道能力×时长限制，计损耗；双向共用上限，检查同时反向与循环输送 |
| 技术边界 | 水电功率及可发能量；适用最小出力/爬坡；生物质原料；氢的输入输出；CCUS附加能耗和封存上限 |

求解分层：先固定关键服务最低缺供，再处理次级服务，最后最小化燃料获取、运维、损耗和调节等资源费用。每层检查求解状态、残差、约束及非负边界；求解失败不是0缺供。若必须增加启停/互斥等离散约束，明确局部已不是纯线性规划。

运行变量、企业现金、公共预算、社会资源成本分别保存。碳税、补贴及内部交易支付不能重复计入全国资源成本；求解器边际值不能直接当企业实际收款电价。[Y §17、19][Y]

**【补入mmj/lb：经济与信息边界】** 已含建设和运行内容的LCOE不能再作一项运维费用重复相加；价格基年、折现和残值口径须一致。LP只表示系统运营者安排运行或检查物理可行性，不替代企业投资与用户设备选择；完美预知只作理想化参照。正式运行的预测窗口、误差来源、企业可见信息和服务优先规则需固定，具体正式取值工作区未记载。不同规则比较必须共用信息，若信息不同则单列其效果。 [RM A5][RM]  [RL 第3页][RL] 

**时间连接的验收重点：** 代表时段权重只用于年度量，库存按真实连续时段推进，不乘年权重；短时循环边界和期初能量须有来源。季节储能须更长连续序列。独立压力检验复制相同事前资产/库存，其损失不直接并入基准年收益；明确规定事件在某年发生时，才替换对应时段并将损失与库存传入下一年。完美预知仅作参考上界，正式比较需写明预测窗口与信息条件。[Y §8.5、17.7][Y]

[operations.py][CODE5]已实现的只是合成连续窗口：先用非燃烧出力，富余才充电，储能先于煤气放电，不能保证全窗口最优；无水库能量、核电爬坡等完整约束，且尚未与年度投资耦合。应保留其守恒测试和对照价值，不将它改名后当成上述正式求解器。[M10]

### D3. 历史校准、灵敏度与现有结果的边界

**校准。** 先固定观测可约束的规模和技术量，再校准少量ρ、投资调整速度γ、预期更新λ及需求活动响应。目标采用yx多指标归一化误差平方和：每种指标只用可比训练年份，先按年份平均，再按固定权重汇总；误差尺度、权重、允许范围在评估前固定。具体正式参数界、权重及可接受误差阈值工作区未记载。[Y §18.1][Y]

**【补入mmj：把误差定义落实到实现】** 校准损失为

`J_cal(θ)=Σ_j (ω_j/n_j) × Σ_{t属于该指标可比训练年} [(模拟值−观测值)/s_j]²`。

这里n_j是该指标实际可比年数，s_j是误差尺度，ω_j是固定权重；缺失年不补成观测。尺度和权重只能由训练期或事先说明的依据固定，不按评估结果调整。所有参数应先通过用途审查；原型默认零不能代替未知观测。 [RM A4、C][RM] 

首版有界网格/少参数搜索；确有计算需要才使用已在yx记载的SciPy `differential_evolution`。不声称搜索恢复真实行为或证明全局最优。多组参数同样拟合时保留，并比较政策结论是否一致；更换少量合理行为规则、审批顺序检验结构依赖。

**现有回算。** mmj已存的总能源需求四方法MAPE依次为：强度冻结0.2192%、能源时间趋势1.8644%、GDP弹性3.6769%、强度时间趋势5.2363%。全部报告，不按留出误差事后只留最好方法；其七年训练、三年已接触评估、已实现GDP和舍入指数限制必须保留。这是工作区既有局部统计结果，不是本次新运行，也不是全国ABM校准。[MRUN] [M15]

**灵敏度。** 按yx已有设计依次做：单因素方向检查 → Morris筛选有界连续参数 → 对重要输入采用`LatinHypercube`联合覆盖与配对政策比较。GDP增长、技术成本下降、碳价为题目必关心因素，燃料价格、设备更新、投资响应、建设延迟按机制补充。相关输入保留关系，离散年份/是否达标不强求导数，基准缺供为0不计算除零弹性。[Y §18.4][Y]

yx的90次、200组及mmj的30个种子均为计算设计示例或初步预算，不作为已验收精度。正式样本数与收敛阈值工作区未记载；确定性同输入不重复。有随机机制时各方案用配对样本；无可信概率分布，结果称“所检验条件范围”，不能称现实达标概率或统计置信区间。

## E. 问题三与创新实验的操作表

### E1. 情景参数登记

统一登记`parameter_id、baseline、scenario_value/trajectory、unit、start/end、source_id、evidence_status`，并记录只影响哪个主体或约束。沿用yx：政策增幅经渐进函数r(t)进入，进口损失经事件函数e(h)进入，恢复过程显式给出；所有正式数值未确定项写“工作区未记载”。[Y §19][Y] [M3]

yx示例中的碳价增25%/50%、气源减15%/30%、风光水降幅、168小时持续/72小时恢复、额外延迟2/4年等均是演示值，**本final不将其转为正式预测设定**。原配置若保留，应维持`illustrative`标签，不能因写入程序而变成实证参数。

S0不是所有变量恒定；已实施政策、技术渐进、需求和外部条件都可演变。各方案共享初态、历史参数、核算边界、信息、未改背景及服务要求；技术进步保留建设与融资限制。碳价外生时保留实际覆盖/配额影响，不能同时用固定碳价和内生市场价格两套机制。[Y] [L1]

### E2. H01：退役、替代与配套滞后

1. 分开终端替代速度`vE`、获准退出速度`vR`、配套额外延迟`L`。先比较`vR×L`并固定vE，再比较`vE×L`并固定vR；正式网格工作区未记载。
2. 每组输出成本、累计排放、缺供及分区服务，标注满足共同边界、失败和参数敏感的区域，不预设唯一阈值或单调关系。
3. 候选规则用当时资产、建设队列和预先规定的压力条件预测未来H年缺口；超过容许ε才触发。H、ε及其正式依据工作区未记载。
4. 触发后先诊断缺功率、能量、燃料、输送或可调服务，再选择缺口出现前能完成的项目/合同/合法延寿；来不及的部分必须输出风险。
5. 对照固定日程、费用排序和“替代服务可用后再退出”。固定项目集合只比较合法时序；完整主体实验允许新增项目不同，不能把效果全归于时序。两类实验分报。
6. 阈值选择与评价使用不同事件/参数集，同预算、碳边界和服务要求比较；计入保留费用、额外排放及期末资产价值，不能无限延后到2060以后。

预期成果是“什么条件下失效、怎样提前识别、规则付出多少代价”，并不预先承诺新规则更好。[Y §9.1—9.2、20.1][Y]

### E3. H02：气源与天气的联合压力

固定同一事前资产、库存、服务及单项冲击参数，运行S0/SG/SW/SGW，对同一缺供指标U计算：

`J = U(SGW) − U(SG) − U(SW) + U(S0)`。

J表示联合影响相对单项增量的差异，不足以证明跨能源传播。按yx要求同时保存气源、工业/电厂用气、跨区流量、储能SOC、设备运行和服务缺口。再冻结指定的事件后替代响应，保持资源与服务条件不变，比较`J正常−J冻结`；不能用无限供气、降低需求或重置库存“关闭耦合”。短期物理传播与后续投资适应分开报告。[Y §9.3、20.2][Y]
