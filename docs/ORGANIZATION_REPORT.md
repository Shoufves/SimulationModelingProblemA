# A题工作区整理验收

整理开始于2026-10-17，主要复现检查完成于2026-10-18（Asia/Shanghai）。任务是归并研究工程及数据去重，未运行全国预测或新算法创新实验。

## 整理结果

- 原A题目录5,846个文件；逐文件登记去向或删除依据。
- 移除4,776个已确认的重复/生成文件及混入A题的B/C副本，合计296,840,178字节（约283.09MiB）。这是移除的原文件体积，不等于新增索引和档案后的净节省。
- 正式文件级去重47项；另有重复截图归入可重建预览处理。保留1123条原路径的内容追溯，包括指向同一实体的旧路径与6个赛题根目录B/C原件位置。
- 合并为一个工程，原A题_mmj、A题_lb及旧script/分析整理入口已消除；数学稿、代码、数据和来源分别归位。
- 赛题PDF、附件1—4与只读目录三个文件的SHA256均与整理前一致。附件890条记录及重复组保留，未按名称擅删电厂样本。
- 原始文件层已没有字节完全相同的重复实体。两个不同需求回算版本的报告文本相同，但版本目录与输入追踪不同，作为可解释的历史结果保留。

## 数据去重与来源

统一来源目录登记637条来源记录，其中581条能够按原登记直接定位到已存文件；这不是637个独立来源。mmj人工摘录另保留在各来源的evidence_files；获取失败、原件未存与摘录存在分别说明。原来源记录完整嵌入JSON，旧source_id带命名空间使用。

统一数据目录覆盖80个原处理/观测文件，另有统计局唯一记录视图。对明确相同版本和口径的消费、生产、装机及GDP增速转录，704个候选数值单元归为362条唯一记录，移除342个重复单元；所有候选行列追溯保存在nbs_record_provenance。不同表号的GDP增速保留不同指标族；本次无同键冲突。

其他异构资料继续按主题、统计期和边界分存，未通过同名或相近数值强行合并。例如EI/GIIGNL年份单位差异、世界银行版本问题、通道货物流量交叠、家庭收入组与就业存量边界均保留。原转录表作为证据和旧程序输入保留，统一视图禁止再次追加这些副本作为独立样本。

## 尚存的真实缺口

final列出的G01—G16、AI、居民和就业缺口已落到[实施路线](IMPLEMENTATION_ROADMAP.md)，并保留已存待提取报告。正式年度↔运行闭环、全国初始化与校准、2030/2060预测、政策求解仍未完成。整理不能制造这些原本不存在的参数和研究结果。

两份创新独立原稿及lb评审引用的验证结果文件在整理前就缺失，见[缺失引用说明](history/MISSING_REFERENCES.md)。现有final和gemini整合稿完整保留，后续主线可按其规范推进。

## 复核与恢复入口

从README开始。执行 `python -B -X utf8 run.py audit` 可再次检查原件保护、逐文件保留、引用、语法和去重边界。逐文件CSV/JSON、整理前清单、旧路径映射、修改前原文及复算前结果均在archive和data/catalog中，能够说明每个删除项为何可删、每个有效文件现在在哪里。
