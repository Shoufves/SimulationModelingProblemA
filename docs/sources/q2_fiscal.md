# 可再生能源电价附加：2014—2024年财政部决算原表

核验日期：2026-10-20。这里记录政府性基金收支，作为问题二财政约束的研究证据；未改动生产模型、输入准入或 `q2_revenue`。

## 口径与主要结果

财政部每年的**全国政府性基金收入决算表**均明确列示“可再生能源电价附加收入”；**全国政府性基金支出决算表**也均明确列示“可再生能源电价附加收入安排的支出”。因此可以取得连续11年的全国年度预算、决算，单位全部为**亿元**。以下全国数直接读取对应年度原表，没有用中央或地方金额拼接。

## 中央口径和不能直接映射的项目

同批保存每年中央收入、中央支出原表，作为范围检查，CSV分别使用 `scope=central` 和 `scope=national`，不能相加。这里“收入”“支出”是政府性基金预算会计项目；全国表为全国财政范围的相应项目，中央表为中央财政范围。中央支出总量包含中央本级和中央对地方转移支付，本研究未将其当作中央本级企业补贴或直接企业付款。

- 中央收入表2015—2022年明确列出目标项目，预算/决算与对应全国收入相等。中央收入表另有“上年结转收入”列，提取器按**列名**定位预算、决算，未将结转列误取为预算。
- 2014中央收入原表用“可再生能源发展基金收入”名称：上年结转58.73、预算470.00、决算491.38。保留在原表和全部规范化行中；因非精确目标名称，该中央记录标为 `not_separately_disclosed_in_table`，不通过数值相等自动改名。全国2014表则明确使用所需“电价附加收入”项目名，年度主表无需该别名补值。
- 2023—2024中央收入表没有精确目标行，而含“其他政府性基金收入”；即使其数字与全国该项相等，也未把“其他”转换成目标项目。
- 中央支出2014—2021年有明确目标项目。2022—2024中央支出原表未单列精确项目，保留缺项状态；没有把“其他政府性基金支出”冒充目标项目。
- 全国、中央支出决算可能不同。例如2014全国448.43、中央508.17；2015全国579.60、中央519.15；2021全国890.38、中央890.68。中央支付包含财政层级间关系，全国统计与中央总支出不能互换；此处如实保留，未用中央数字覆盖全国表。

`not_separately_disclosed_in_table` 仅表示检查的这一张表无明确目标行，不表示该项目没有收入/支出、没有别处披露或经济金额为零。

## 用于模型时的边界

收入决算是该财政科目年度实收，**不是地方补助预算**，也不是发电企业经营收入。支出决算是原表明确列示的项目年度支出，不能进一步自动解释为当年可再生能源项目新增投资、分技术资本开支、当年发电补贴应收清偿或新增补贴承诺。

2022—2023年全国该项支出显著高于当年收入；原表支持收支事实，但本次未额外核清所有调入资金、跨年结转和财政层级结算。因此不能把“当年收入减当年支出”当作基金余额、欠补余额或新增投资能力，亦不能用收入决算替代支出校准。风电/光伏/生物质分配、企业回款时间、存量与新增项目范围仍需独立证据。

补查[2022年中央决算说明](https://yss.mof.gov.cn/2022zyjs/202307/t20230714_3896446.htm)与[2023年中央决算说明](https://yss.mof.gov.cn/2023zyjs/202407/t20240716_3939579.htm)，已保存原HTML及 `central_notes_anchors.json`。2022说明首段交代**中央政府性基金全部科目**：2021结转354.68、一般公共预算调入150、中央单位特殊上缴利润18100亿元；收入总量22728.67、支出6330.48、调入一般公共预算9000亿元，其余结转等另列。说明后文明确150亿元一般公共预算调入增加的是**铁路建设基金**，不能计为可再生能源专项追加。

2023说明首段同样为**全部中央政府性基金**：2022结转7393.09、收入决算4417.54、收入总量11810.63、支出5744.42、调入一般公共预算5600、结转下年391.87亿元。两份说明正文均未出现“可再生能源”字样，未提供可再生能源科目的资金来源拆分或一次性补助金额。因此上述中央总量的结转、上缴利润或调入，**均不分配给本专项**；不能把全国专项收支差额当作外部拨款，也不能按累计差额倒推专项初始余额。当前可表述为**财政收入、财政支出已观测；企业实际到账、专项初期可用余额仍未观测**。

## 复现与验证

在项目根目录运行：

```powershell
tmp/q2-venv/Scripts/python.exe data/raw/q2_fiscal/build_fiscal.py
```

此命令仅读已保存HTML，重新生成CSV、原文行JSON、全部表行JSON和清单，不联网。首次取得原件可加 `--download`，已有原件不会覆盖。脚本从财政部各年度决算索引发现四种表；2019中央表通过 `index_1.htm` 分页发现，没有通过猜测数字URL补表。

提取器检查年度标题、亿元单位、唯一“预算数/决算数”表头、目标行唯一性及列数匹配；缺少明确项目行时保留空值与状态，绝不赋零。记录44个范围/科目组合，其中全国22个均有精确项目行，中央16个有精确项目行，6个保留缺项状态。原件文件共44张表、12张索引和2份决算说明。验证还检查全国收入的2015—2022中央交叉一致性、文件SHA256，以及预算/决算均为有效数值。

本目录为独立候选证据包；统一目录和模型用途准入由主任务审核后处理，尚未自动准入。
