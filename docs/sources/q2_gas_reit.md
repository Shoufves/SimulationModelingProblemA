# 气电项目样本：容量收入与综合结算均价

核读日期2026-10-20。原件为鹏华基金管理有限公司《鹏华深圳能源清洁能源封闭式基础设施证券投资基金2025年年度报告》，送出日期2026-03-30，从巨潮资讯下载。共103页，已渲染并目视核对物理页16、17。

原件：`data/raw/q2_gas_reit/penghua_energy_2025_annual.pdf`；来源URL、哈希见同目录`source_manifest.json`。复核入口：`python -B -X utf8 scripts/review_q2_gas_reit.py`。结构化结果见同目录`evidence.json`。这是项目公司自身披露的一手经营资料，不是政府的全国统计。

同报告第69页“项目公司主要税种及税率”明确电力销售适用13%销项税率，已由独立复核渲染核读。它与基金资管产品的3%税率不同；电力收入含税化核对使用前者。

## 实际取得的内容

样本为深圳市东部电力有限公司、该REIT底层发电项目。2025年结算电量为315108.75万kWh，售电收入为1352933480.27元、不含税；报告将综合结算电价定义为售电收入除以结算电量后含税化，披露精确到四位小数的0.4852元/kWh。

物理页17把同年全部售电收入分成电网代购及跨省交易、年度双边、月度双边、月度转让、现货、其他电费收入和容量电费。其中容量电费12032.73万元、不含税，披露占全部售电收入8.89%；其他电费收入8584.37万元，包括分摊补偿、调频及两个细则等。月度转让为负值，不得当缺失或改成零。七个分项以万元保留两位小数，汇总与总额存在印刷舍入差，由处理脚本核对。

因此，对**这个项目、这个年份**，先统一含税/不含税口径，再把综合结算均价乘上网电量后加全部容量电费，会重复记收入。可以按已披露的分项拆开，但不能把剔除容量后的全部余项直接称为纯能量价格，因为还包含其他电费收入。报告均价只有四位小数，精确收入核对必须以披露收入总额为准，不能用四位小数均价反推精确到分的收入。

同报告页16列2024对照：结算电量351198.65万kWh，售电收入1560469240.08元、不含税，综合结算均价0.5021元/kWh、含税。已核读对照表未单列2024容量收入，不能拿2025年的容量占比回填2024。

## 用途限制

这是2025年单个广东项目，不进入2015—2021训练或2022—2024全国校准。其澳大利亚合约气源、经营方式和收入构成不能代表全部国内气电。它证明了收入均价中包含容量费的一个明确实例，但不能证明NEA2013—2018全国平均上网电价包含多少容量收入，也不能解决全国各省资格、考核扣减、应计与实收的缺口。

报告后部还有未来经营和评估预测，均未提取为实际观测；报告所述2025年政策变化也不追溯写入历史期。此次未改变模型参数，未把容量收入当无付款方的财政拨款。
