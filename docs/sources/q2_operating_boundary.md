# 毛净电量、抽蓄与回收能量接入记录

2026-10-20。本轮实现和测试物理/财务接口；尚未将未经识别的EI Other组成填成全国默认输入，旧V10结果不能据此转为正式预测。

## 已修正的实现

1. 厂用电与电网损耗分开：机组容量、燃料和运维按毛发电量计，扣厂用电后的电量才进入电网。收入适配器提供的计量比例与物理扣减共用；初始终端电力需求也同步扣减。该适配器明确假设扣除厂用电后全部上网，自备自用另需独立计量，不能混入厂用电率。
2. `q2_operations.py`可并存多套储能，各有充放功率、效率、SOC和终端约束。重复日权重不进入库存递推；同时充放拒绝。回收载体只来源于实际已服务燃料输入中明确可回收的损失份额，多个回收申请共用损失上限。禁止把原料投入作为已燃烧热损失，禁止内部载体再做上游回收源，禁止未知期初回收库存或新购零碳回收燃料。
3. `q2_boundary.py`的`InheritedOperatingBoundary`接入年度模型，表示继承的抽蓄/回收发电资产。需要显式输入2009至初始年的主技术容量重建、补充资产初值/退出年/费用、初始抽水耗电与出力、统计差额及依据。主容量与补充容量必须闭合，主发电+回收+抽蓄出力+统计项也必须闭合，重复计算或未声明余项会拒绝。
4. 初始终端用电扣抽水输入和统计调整各一次；统计项不能发电。未来回收出力受上游实际服务与机组能力双约束；抽蓄必须真实充电并承担损耗。所有补充资产只继承与退役，不自动免费增建。规划用未来已知寿命，不读取未来实际装机，不回填SOC；实际退役清除相应SOC并报告能量损失。
5. 回收机组售电由电网支付，变动/固定运维与补充储能费用进入现金和资源两本账；回收载体不再次计一次能源或燃烧排放。全国发电总量单列回收和抽蓄毛出力，同时保留各技术、母线电量及抽水量，禁止把抽蓄当非化石一次能源。

回收核算仅适用于上游燃烧碳已记账的损失流。它不自动等于已识别的钢铁副产煤气碳流，也不能据此把EI Other全部指认为回收发电。补充储能在此全国适配器中按抽蓄统计；通用多储能求解器的其他储能用途须另行指定统计映射。

## 新取得的真实锚与边界

见`data/raw/q2_scope_components/README.md`及逐行原件清单：2014抽蓄发电13.19TWh、2021为39TWh、2024为65.7TWh；2014容量CEC后版22.11GW与NEA初步21.83GW分别保留。全国全年抽水耗电本轮未取得，不能把往返效率反推值写成观测。中国统计水电含抽蓄，不自动决定EI Other的对应组成。

取得中国垃圾焚烧七厂八工况碳14研究原文和补充表，其烟气化石碳占比仅为特定时空样本；不是全国垃圾发电的化石电量比例。其作用是反驳整个含垃圾生物能源组零化石碳的假设，而不是提供统一的50%发电划分。全国碳边界仍需显式混合成分和范围实验。
