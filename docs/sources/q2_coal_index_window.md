# 完整月指数窗口的历史价格机制对照

2026-10-20，在运行前固定设计。已核读2016年10月、11月表和2017年1月的上期比较值，可补足2016年；另取得2017—2019全年原表。与旧2014—2015原件合并后，仅2014—2019每年12个月完整。本轮使用这些完整年份，不把2020年1月值外推全年或2021—2024。

沿用`q2_fuel_price_timing.md`价格接口与适用范围：电煤到厂指数只作共用燃料市场敏感性，不能当非电部门实测煤价；税基仍不明，0和17%扣除两个条件均报告。17%为统一诊断边界，不宣称2014—2019法定税率恒定，更不据拟合选择税率。每个年份由12个原始月值算术平均，按5000大卡热值和CPI换算。

固定既有2015—2021训练参数，终点2019；权限5/25/100均做原参考价、两种税口径×两种2014初态，共15组。既不重新训练，也不检验或选取2022—2024结果。报告全部年度煤电NPV、新建批准和投产、燃料及现金流。新建有原工期和融资约束，2015后决策不能改变2014初始资产。初态价格替换会改变消费者的固定收入重建，故另保留只改变2015起运行价格的控制。

运行前后核验原件、数据、配置与代码哈希；原参考价须复现当前已冻结工厂的2015—2019前缀。没有足够价格年份、原件变化或重叠月份不一致时拒绝运行；不更改原准入契约或默认模型。
