# 2025—2060统一延续实验的边界

2026-10-20，三小时交付轮次。历史来源为项目竞争工厂两组独立训练，参数只由2015—2021选择，2022—2024已接触评估。每个情景重新构造完整历史并与保存路径精确比较，然后从模拟2024年末继续，不免费补足现实装机缺口、不重置债务、现金、队列、欠款和累计补贴电量。

## 已声明的前瞻条件

- 2024年实际口径的售电价格、厂用电率、财政基金收入及支出授权按不变价延续。既有补贴权利按原年限/小时退出，旧欠款保留；按2024代表性生物质报价延续新增支持，不新增风光旧制补贴资格。未来参数是条件假设，不是已取得未来财政预算。
- 此S0是**现有模型中的旧政策延续条件基准**，不是已经完整实现2026现行政策的预测。全国容量收入、2025后新能源差价机制和分布式自用仍未完整覆盖；必须连同结果披露，不能称所有政策已覆盖。
- 已有有限垃圾交付情景延伸到项目规划所需年份并保留总量上限；没有拿未来实测资料反推投资。
- GDP、技术降本、碳价、非电需求及统计桥沿用已保存的前瞻假设，另做单因素边界。已知历史拟合失败仍随结果报告，不因前瞻能运行升级为科学验收。
- SG为2028—2030进口气供给与价格条件冲击；SW为同窗年平均风光可用率和水电能量约束。它们是声明幅度的压力测试，无现实事件发生概率或中东特定国家归因。投资者只将当前冲击延续到规划期，不预知恢复年份。
- SP只提高已建模碳价格信号，ST只加快已有风光成本下降；这两个单项情景避免把多种措施打包后混淆原因。幅度沿用原设计灵敏度范围，非官方承诺。
- H01交叉改变既有煤电退出提前年数和新增电网/储能建设滞后，资金约束不放松，债务不注销；设备替代响应另作已声明控制。不能以提前退出的账面排放下降代替满足用能服务。
- H02对S0/SG/SW/SGW同初态配对；冻结只针对2025后新气电投资审批，既有与已承诺资产保留。此为长期投资渠道消融，与旧五日调度响应冻结分别报告，不能混称同一个机制。
- 有限政策集比较增加有限基础设施预算或改变价格/替代信号，仍走原建设成本、工期、融资与运行账。基础设施预算是GDP比例情景，上限不是已核验的实际政府投资额度。报告实际投资支出、服务缺口、CO2和资源成本；补贴转移不再计作资源成本。

## 结果解释

2025—2060逐年路径、2030/2060指标、同状态差值、政策集内非支配方案均实际运行后生成。没有宣称有限网格为全局最优，也不将情景范围当概率或置信区间。绝对缺供、排放和资源成本与代数交互同时报告；交互量变小不自动代表安全改善。全国单节点循环代表日不能解释为全年小时级或跨省可靠性。

独立氢能供应链、非能源温室气体和负排放技术仍缺，不以固定碳汇假设认证2060碳中和。2024起点装机偏差、2018后电价延续和新技术成本历史适用性是主要解释限制。
