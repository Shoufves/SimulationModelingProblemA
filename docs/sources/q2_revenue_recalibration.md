# 收益、分项成本与新老项目队列的条件重校准

设计固定于 `workflow/q2_revenue_recalibration.json`，执行入口 `scripts/run_q2_revenue_recalibration.py`。2015—2021选择参数后先保存训练选择，再运行2022—2024已接触评估。三种承诺额度假设全部报告，不挑选评估最优者冒充真实国家预算规则。旧正式准入契约及默认生产模型不自动改写。

## 修复的机制

1. IEA固定/可变费用分账并处理净/毛边界，详见 `q2_project_costs.md`。固定费用在闲置时仍支付，不进入出力边际排序。
2. 风光新项目使用明确的新项目容量因子，旧机及继承在建队列保持原能力。项目审批时固化能力，投产后才生效。各时段同技术队列按可用能量分配实际发电和弃电，实际补贴按这一分配计量，不能继续按容量平均。候选项目支持NPV使用自身电量，净新增售电收益仍经过共同市场需求审查。
3. 生物能源以“整个混合项目属于统计桶”的显式条件解释内部组成，不从EI Other强行搬移。国家能源局将垃圾发电纳入生物质行业统计，而EI通用说明不足以证明中国已拆出垃圾化石部分。桶内物理非化石发电、垃圾化石燃料及化石碳单列；原统计PEO桥不冒充物理组成。另一种可再生子流解释需单独模型比较，不能同时使用。
4. 固定混合配方中农林燃料仍有采购成本，垃圾输入在该服务场景下免费。垃圾处理费独立按实际吨数计量，有限市政拨款约束实收，欠款保留，不计入中央可再生电价补贴。收款改善现金；新投资的服务收入预期单独形成，避免旧欠款一次到账变成永久利润。
5. 同时保留有限燃料供应与有限垃圾吨数，预测规划先恢复未截断机组预算再应用已声明的未来供应情景，防止无垃圾仍发电或恢复供应后永久锁零。未来路径是初态重建的公开假设，不读取未来全国观测。
6. 有限补贴授权不再等同全部项目的施工许可。先分配有限支持额度并审查组合，再允许具备正的无补贴NPV的追加项目接受单独的共同市场边际审查。追加部分没有补贴收入，审批后与受支持部分分成独立物理项目和计量队列；资本、融资、施工总上限、工期和实际支付约束保留。若追加组合挤压原已验证支持组合，保守保留原组合。此为显式行为规则，不能据此声称历史所有项目均可自由平价入市。
7. 水电装机观测包含抽蓄，训练比较项改为模型常规水电加独立抽蓄容量。原始观测不改、不将抽蓄加进常规水电发电能力，不把缺失抽蓄观测填零。当前继承抽蓄只有2014初态队列，后续付费扩建仍待实现，因此口径修正不代表扩建缺口已经解决。
8. 垃圾处理费的投资预期同样受当前已知垃圾供应和拨款限制。预期分母包括现役容量、候选投产前可投运的已批准在建容量及本次拟建量；已投产队列不重复计入。新项目请求按自身规模重新核验预期利润，不能在多个决策年重复预期同一份垃圾或同一笔服务资金。未来信息采用当年值持久预期，已知现役未来退役暂不扣除，是偏保守的假设。

## 参数的含义与限制

后续扩展搜索单独冻结在 `workflow/q2_revenue_supply_search.json`：两遍坐标搜索增加光伏施工能力比例及2014初始在建队列，并允许新项目容量因子与施工增长率交替调整。它们是针对训练窗内装机/发电残差的潜在能力参数，不是逐年全国建设观测；原设计和旧结果保留，承诺额度仍逐场景报告、不用评估窗口选场景。

- 风电新项目CF取0.25/0.30/0.33，光伏0.15/0.18/0.20。参考IRENA新项目能力与既有IEA技术参考范围建立候选，不是各年份项目普查值；固定年份参数是待训练的聚合近似，不宣称2015投资者已知道2024实测。
- 农林/其他非MSW采购价继续使用既有100元/MWh燃料工程假设，仅将垃圾份额从采购量中分开；原件只有元/吨且无配套热值，不能据此声称已获得全国真实农林燃料价。
- 垃圾份额w是混合燃料能量份额；a=0.5是假设的垃圾化石能量份额。0.2 tCO2/MWh完整垃圾燃料来自跨研究敏感性范围内的研究取值。`CO2=w*Q*e`，不再乘a。4.8MJ/kg热值和0.3共同电效率形成0.4MWh毛电/吨，为工艺情景，非全国配对观测。
- 75元/吨是2024实际价基准的研究服务费，在企业披露的名义50—105元/吨范围内，不声称已完成原样本税率、地域和年份权重统一。2014垃圾量由同版初态、w、效率及热值重建，加10%供应余量；增长率0.08/0.12/0.16与3.5亿吨上界是有限情景假设。年度市政拨款取同一供应上限×服务费×75%，不是中国实际财政统计。
- 原NEA分技术总电价减煤电参考价仍为复合生物能源有效支持代理，不等于逐垃圾项目280kWh/t及农林750元/MWh规则的逐条复刻。后续正式细分仍需项目类别和资格数据。
- 不计尚未在物理系统交付的热量及其收入。没有用热价资料直接凭空增加利润。

## 验证及剩余任务

2026-10-20前序102次训练与六组完整路径保存在 `outputs/q2_revenue_recalibration/20261019T203823119619Z/`。该版本气电2022—2024 MAPE在三种承诺假设下为11.68%、7.32%、5.83%，风电仍为62.26%、57.41%、39.18%。其后查明有限补贴额度误限全部新项目及水电目标口径错配，因此前序结果不是当前代码的验收凭据。修正后重新执行相同训练设计，保留原结果和中断运行状态，不用评估误差选择承诺假设。

容量收入核查见 `q2_capacity_revenue.md`。NEA均价按售电收入/上网电量计算，不能先当作纯电量价再叠加地方容量费。当前没有把未经拆分的全国固定收入重复计入。

工程验证覆盖固定/可变费用、无免费旧机升级、投产时点、实际项目补贴计量、垃圾供应双向变化、化石排放不重乘份额、市政欠款和资金守恒。条件重校准使用原正式多指标训练损失及同版训练尺度，不放宽科学阈值。原有较大误差、初始队列可识别性、来源年代差异、统计与物理桥差异须保留披露。
