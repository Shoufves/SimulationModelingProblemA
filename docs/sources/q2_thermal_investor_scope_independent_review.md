# 热机投资审核的主体范围：独立复核补充

日期：2026-10-20。此记录补充而不替换已保存的九组物理、现金和复现核验收据。

## 结论

`src/energy_model/q2_thermal_vintages.py` 中 `thermal_candidate_npv` 使用有无候选项目的**同技术聚合经营贡献之差**。这是一个拥有该技术全部既有资产的聚合业主的扩建收益，不能直接解释为竞争性新项目自身收益。它内化了候选项目挤占同技术既有机组的利润。

既有独立核验准确验证了该公式与实现一致、热耗与碳守恒、年度现金闭合以及结果可复现。那些通过记录不构成“竞争性进入机制合理”的证明；此前应当更明确披露这一主体边界。

## 本地方案依据

- `只读工作区/final.md:101`：电源企业计算“预期项目收益”后申请投资、改造或退出。
- `只读工作区/final.md:342`：LP表示短期安排运行或物理可行性，不替代企业投资与用户设备选择。
- `docs/design/A题内容分析与数据准备清单.md:402`：评估有合同和明确补偿的项目收支。
- 同文件409、413、922行：销售电量、预计可利用小时、合同和项目现金流约束投资；没有规定项目必须增加整个同技术行业的销量或利润。

因此，“候选不能凭空获得销量”要求候选自身售量必须来自共同可行的运行结果，不能自动推出“只允许行业净增销量”。

## 最小可检验替代机制

在维持当前同技术共同利用率及调和效率的物理近似时，可将候选与其他拟建技术加入同一规划LP。令该技术调度后总发电为 `E1`，已有有效容量为 `K0`，候选有效容量为 `Kc`：

`E_candidate = E1 * Kc / (K0 + Kc)`

项目燃料为 `E_candidate / eta_candidate`，以该项目售量、燃料、变动运维、固定运维、适用碳履约净支出计算项目自身贡献。补贴报价如适用，也按候选自身售量及资格计算，不能把整池发电全部计给候选。建设期、年内暴露、融资、政府权限和共同组合复核保持既有约束。

这一分配与现有物理队列账的共同利用率假设一致：所有机组分配售量之和等于LP总售量，各自按效率计算的燃料之和等于调和效率对应的总燃料。新项目可能夺取旧机销量；旧机损失体现在旧资产自身经营结果，不作为候选额外成本。

该规则仍不能表现高效新机组在同技术内部优先发电。若需要这一行为，应进一步拆分新旧LP机组，并明确成本、配额与结算规则，不能仅改变收益公式便声称已有机组级竞争。

统一业主与项目进入两种规则应保存为不同机制版本，分别报告；不得以已接触评估误差选择规则，或在已冻结运行期间修改源代码。
