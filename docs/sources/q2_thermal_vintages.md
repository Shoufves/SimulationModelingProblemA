# 新老煤气机组：技术条件、燃料守恒与投资审核

2026-10-20，在实验前声明。现有成本工厂使用IEA2020中国2025新建技术参考，但统一存量毛效率煤0.41、气0.52。原报告和燃料度电分项支持煤0.45、气0.58为净效率；转换使用成本接口原有净铭牌比例煤0.9301、气0.9741。这仍是2014群体厂用电重建比例，不是IEA样本实测自身用电率。不能不作说明地将净效率直接写入毛发电燃料核算。

历史资料另见IEA2010/2015中国样本核读：早期报告有煤0.46/0.45、气0.58/0.55，但部分技术输入为公开材料研究或默认值，不是全国实测。故本实验明确保留`net55`、`net58`两种气电技术参考，不根据已接触2022—2024评估择优。煤采用与当前成本同包的净0.45。2015起可采用该参考是历史条件实验；2025假设新建成本不能冒充2015实际投资成本或当时公告。

## 实际机制

- 旧资产和期初在建项目保留原效率；2015以后自主决策项目在批准后记录效率，投产传入自身队列，不在成熟时用最新技术改写老项目。
- 同一技术内部共享利用小时，年度效率为`sum(MW*exposure)/sum(MW*exposure/efficiency)`。投产、退役年度使用原曝光权重；年末快照使用实际存活容量。该聚合不是逐台择优调度。
- 年度LP、发电账单、燃料采购、CO2与ETS使用同一混合效率；逐队列燃料和碳账反核总量。初态非电残差识别不变，不全局替换`FUEL_EFFICIENCIES`。
- 新机收益单独学习：从当前混合机组实际利润中按同利用小时扣去/换入候选热耗；2021后包含燃料节省对应的ETS边际成本，免费配额的同发电量项不重复改变。旧机群收益已包含新机节省时，不再次按初始效率加成。
- 候选与联合组合另跑真实LP，比较有无该项目的增量同主体利润，包括销量变化、燃料、可变运维、ETS及固定运维。以学习预期与边际收益的较小值审核NPV，失败项逐步缩减或移除，再审核剩余组合。不能仅凭效率更高就扩大投资；融资、建设和补贴权限不变。
- 热机联合审核明确传递支持比例，无补贴建设使用0；若调用方提供热机补贴报价，使用非负增量销量折算小时，而非把原有机组全部发电重新申领。现有历史煤气未配置补贴报价，这项接口修正不会额外增加现金或历史补贴。
- 未来规划按已知在建及存活队列计算效率，不读取未来实际新增或未来煤价。新增候选改变规划时的混合效率和碳信号，但不修改当前物理资产或实际效率。

关闭模块必须精确复现原修正工厂。固定训练参数先报告全部三种机制×三组承诺权限，再按2015—2021训练、2022—2024已接触评估实施完整重训；不改变目标权重或验收门槛。工程通过和条件对照改善均不自动等于全国模型验收。

工厂逐进程核验2010/2015原PDF固定SHA256及四份历史原件与抽取清单的一致性。历史技术资料、证据页码、限制、工厂和当前代码一起进入实验来源快照，结束时再次核对；没有通过改写旧实验哈希使旧结果适用于新代码。
