# 2024观测初态的主情景交付

本轮依题面“从当前状态”要求，采用独立2024观测装机、能源统计与经济规模为起点，沿用2015—2021训练选择的行为参数。2022—2024是已接触的历史评估窗口；2024观测装机匹配是初始条件，不计入历史拟合成绩。历史校准实验、误差及旧连续初态实验全部保留。

`scripts/q2_current_factory.py`提供初态；`src/energy_model/q2_forward_current.py`提供政策、价格和冲击延续；`scripts/run_q2_current_delivery.py`负责执行和来源冻结；设计见`workflow/q2_current_delivery.json`。原完整历史训练先经独立复核，再提取训练参数。每个情景重新建立相同初态，各主体仅获得当期信息。

物理总量中有2024观测；热电子类、设备年龄、存量项目资格、开工队列、债务、股东权益及补贴应收属于明示的重建。账本满足资产负债恒等式不证明这些重建值是现实观测。年龄、队列、债务、现金、欠补分别安排单因素敏感性。

强制主情景为S0/SP/SG/ST，另有SW与SGW；GDP增速、技术成本下降率和碳价做双侧扰动。已有H01/H02和有限政策集合一并执行，但不是自行增加的题目验收门槛。政策比较只报告实际测试集合的非支配性，不称全局最优。

基准是2024实值价格、财政强度及已建机制延续的条件推演；没有完整逐项复刻2025—2026全国电价机制改革。空间为中国大陆总量，年内为循环代表日，不是全国8760小时可靠性结论。CO2及净移除口径不等于全部温室气体认证。清楚披露这些边界后形成题面问题二、三的计算答卷。

运行：`python scripts/run_q2_current_delivery.py --workers 3`。短检查：`--only S0 --end-year 2027`。结果保存逐年路径、2030/2060指标、峰值检查、冲击交互、政策比较、初始账本、逐年财政及来源SHA256。失败情景单独保存，不以空值替换。
