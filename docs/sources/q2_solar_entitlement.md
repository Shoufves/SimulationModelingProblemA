# 光伏补贴期限与设备寿命分开

2026-10-20。已在Chrome打开并核读国家发展改革委原文《发改价格〔2013〕1638号》，落款2013-08-26、发布2013-08-30；原件和获取记录保存在`data/raw/q2_solar_entitlement/`。原文第四部分（二）明确期限原则上为20年。第三部分覆盖2013-09-01后备案/核准，及此前备案/核准但2014-01-01以后投运的电站。完整原件SHA256见来源清单。

旧条件模型把2021前新增光伏资格期直接取设备寿命25年。设备能运行25年不意味着全寿命都有电价补贴。新配置工厂`run_q2_solar_entitlement.build`将已知适用项目的补贴资格改为20年，发电设备寿命仍为25年；先配置报价与初始资格再开始年度运行。物理资产、现金初态、历史累计电量和欠款不赠送、不清零。

适用边界：2014起投运的光伏队列和2015起新增报价；2014前旧项目缺备案日期，保留原重建并标注未知，不强推全部旧项目同一期限。预2021未有小时数上限时，用20×8760小时作为保守完整权利上界；2021后的既有寿命小时规则继续独立约束，不延长期限。有限承诺额度仍是研究假设，原文不支持将它说成财政法定授权。

同文另明确：集中式电站以资源区标杆价与当地煤电基准之差支持；分布式按全电量补贴，余电另由电网收购，自用电并非售给电网。现有聚合电站模型尚未分别重建分布式自用、余电、零售购电节省及对应容量，不能把0.42元/kWh套至全部年份/全部光伏来填误差。此发现作为后续细分要求，未伪造全国分布式份额。

本轮在原联合训练选出的三个额度和两种组成模式下分别运行，参数固定，保留旧版作配对。修正政策输入的理由来自原文，不能由拟合改善与否决定是否采用。新配置尚未重新训练，也未进入旧全国默认前瞻；需继续统一训练、前瞻与情景入口。不得把本轮对照称作全模型科学验收。
