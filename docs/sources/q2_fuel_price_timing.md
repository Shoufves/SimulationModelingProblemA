# 年度燃料价格接口与2015年动态诊断

2026-10-20。先冻结比较设计，再运行。旧模型源码和已冻结工厂不改；新增`FuelPriceNationalModel`继承修正后的联合投资审核。初始供应商建立时安装2014价格，早于发电企业收益先验和消费者收入初态；每年运行前安装当年价格。未来规划继续使用当前供应商价格，不查询未来价格表；缺年立即报错，不补零、不暗中沿用。

模型仍是每种燃料一个共用市场。现有电煤到厂指数不代表非电部门煤价；本轮只能用于明确标注的共用市场敏感性。模型的进口5%成本加成仍为旧技术假设，不能解释为已测到的全国分来源采购成本。要将电煤指数正式接入发电部门，仍需区分发电与非电采购合同、到厂费用和来源结构。

本轮固定已完成的2015—2021训练参数，三组承诺权限5/25/100全部保留。不做选参、阈值修改、制度优选或2022—2024评估。实验终点2015：旧固定价格对照，及两种未知税口径（不扣税、假设17%扣税）分别与两种初态配对。第一种保留原2014价格先验，只改2015运行价格；第二种连2014初态一起改为同口径指数。两种税口径均是假设，不能称已核定税率或指数税基。

使用完整12个月算术均价，不把它称为全年采购量加权均价。按5000大卡/千克转换为5.815MWh/吨，再以CPI转2024年不变价。只读取2014与2015完整原表，不用不完整2016年表外推。原件、提取数据和代码哈希纳入结果。

必须核验：关闭接口时完整2015—2024路径、项目、财务、资产和行为均与旧修正工厂一致；只改未来价格不能改变当前历史和投资规划；动态运行现金守恒；2015价格真实进入运行、收益学习和项目批准，而非事后报表调整。报告所有案例的发电、需求、煤电NPV与新建批准。该实验不能证明未来装机缺口已解决，不能作为全国历史价格校准。
