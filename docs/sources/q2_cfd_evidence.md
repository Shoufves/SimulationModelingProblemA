# 新能源双向差价结算：2025年后前瞻所需证据

2026-10-20核查。全国136号原件已保存于 `data/raw/q2_revenue/ndrc_renewable_market_2025.html`，不重复下载。机制电价不是只向企业付款的中央可再生电价附加补贴：市场均价低于机制价补差，高于机制价反向结算；限定机制电量、期限及省级规则，费用纳入当地系统运行费用。现有只支付正向补贴的基金不能直接冒充双向机制。该接口尚未接入全国前瞻。

本轮新增上海市政府通知及其完整XLSX原表，见 `data/raw/q2_cfd/source_manifest.json`。通知为沪发改价管〔2025〕45号，2025-12-03发布。官方页面可通过清单URL复核。

`extract_evidence.py`校验原件哈希、表头和单位、项目编号唯一性及通知中的数量/电价，再逐行保留H/I/J/F原单元格。2039行处理证据不再复制项目名称、申报主体和住宅地址。没有把单个地方样本赋予全国地域权重，没有把2025年末文件注入2015—2021投资者的信息集。

用于后续实现的约束：先记录实际有资格的物理电量，再限制在项目机制额度；差额采用同税价/同电量边界的市场参考价格计算。正负差额分别记录应收和应付、实际付款和未结余额；市场电费、财政补贴、机制差价、绿证收入须核查可兼容范围，不能重复叠加。机制电量年度/月度分解、市场均价定义、负价处理、申报与实际投产核验及全国覆盖仍需相应配套规则；现阶段原表不提供这些完整全国输入。

上海来源只证明地方真实竞价价格、额度与期限可取得，不代表全国新能源的统一保底合同。作为未来S0政策模块的地区证据和边界检查，暂不自动进入主模型。
