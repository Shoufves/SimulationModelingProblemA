2026-10-20。此轮保持实际模型、初态、财政来源、资格、承诺和现金机制不变，只检查既有分块粗网格造成的参数耦合。既有训练、已接触评估结果及所有失败记录保留；不宣称盲测或全局最优。

## 来自训练窗口的动机

既有完整研究`20261019T221146446406Z`中，2015—2021光伏发电贡献训练损失0.278079，是最大单项；光伏装机贡献0.103393。光伏2019—2021发电偏高已存在于训练期。旧网格只比较新增项目CF=0.15/0.18/0.20，另行调整建设速度，不能充分探索收益门槛附近的联动。

只改CF、其余参数固定的训练反例显示：2015年CF=0.15/0.18的新光伏总NPV分别约633.9/925.0万元每MW，但不计补贴的NPV为−153.5/−19.9万元每MW。因此项目有正的支持后预期，实际批准仍受有限承诺约束。CF=0.20能通过无补贴收益门槛并扩建。此差异解释为什么粗网格会用偏高利用率补偿受限建设，不能因此认定中国真实项目CF或财政授权。

## 预先声明的处理

- 沿用2015—2021加权损失，原尺度算法、权重和验收门槛不变。
- 在原CF范围内加入0.16/0.17/0.185/0.19/0.195。联合检验CF、光伏建设能力、增长率、初始在建规模；新增2.5倍建设能力用于检验原2倍上界。全部是模型参数，不是官方观测。
- 再联合检验风电CF、投资响应和风光配比，最后有限复查光伏CF/建设增长的组合。
- 三种未知承诺额度5/25/100分别训练并全部报告；不选取评估更好的财政制度。
- 使用旧训练选参作起点，不使用旧评估误差排序候选。按固定顺序、固定预算选择严格较小的训练损失；同值保留先到候选。
- 训练前保存设计和来源哈希；训练后先写选参记录，再执行2022—2024评估；来源中途变化则失败退出。并行只改变执行速度，不改变候选与择优顺序。
