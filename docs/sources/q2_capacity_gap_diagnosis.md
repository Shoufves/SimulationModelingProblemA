## 煤电：先卡项目收益，后出现资金耗尽

2015—2024每年的项目NPV均负，申请和自主批准均为0。因此当前缺口不是政府联合竞争审核把正收益煤电申请砍掉。2015年候选净经营预期约24.61万元/MW·年，经营折现因子14.470，建设成本536.99万元/MW，项目NPV为-143.72万元/MW；2024年NPV仍为-287.99万元/MW。

2015年建设上限43.493GW、融资上限1921.555GW；2015—2022融资上限始终高于建设上限。到2023—2024，持续经营亏损使融资上限归零，成为额外约束，但不能倒过来解释前八年已经不存在的申请。模型2024煤电经营现金亏损1048.315亿元；这是本组价格、电价、运维及ETS条件下的结果，不代表实际全国企业财务。

库存流量恒等式是：2014存量832.326GW + 初始重建队列投产162.619GW + 自主投产0 - 重建年龄对应退役164.795GW = 2024存量830.150GW。新增初始队列基本只抵消模型退役。退役年龄是重建假设，缺少实测年龄面板，不能据此断言真实煤电应当退出相同规模，更不能将164.795GW直接称为经因果识别的“过早退役贡献”。

## 水电：全期NPV不足，另有静止抽蓄边界

常规水电2015—2024也没有自主申请或投产；NPV从2015年-67.84万元/MW降至2024年-294.51万元/MW。2024年建设上限39.822GW，融资上限2876.751GW，资金和建设额度均未实际卡住已提出的项目，因为申请在收益判断时已为0。采用1500万元/MW的研究成本与既有电价、收益预期，不足以覆盖折现投入，不能把该结果写成“物理上没有可开发资源”。

常规水电恒等式：2014存量282.747GW + 初始队列56.793GW - 重建退役23.556GW = 315.984GW。另有抽蓄22.110GW，仍为2014边界快照，未建模后续全国抽蓄扩张。已有2024报告给抽蓄58.690GW，仅此边界差额36.580GW约占水电总缺口的37.5%；该细分使用另一发布资料，须保留来源口径。不能把全部水电缺口归于常规水电项目NPV。

## 光伏：盈利、融资和财政都允许，实际获批已触及建设上限

十年每年NPV为正，申请量和最终批准量均等于该年建设上限；融资上限均更高，共同GDP预算批准比例均为1。2022年建设/批准76.707GW而融资上限664.209GW；2024年建设/批准103.661GW而融资上限809.751GW。2021年后补贴报价已经为0，光伏仍以无补贴正收益项目建至上限，不能将晚期缺口归于补贴预算收缩。

## 结论边界与前瞻使用

这是严格库存分解与已发生审批规则的诊断，不是通过放宽某个限制重跑得到的因果归因。所有负NPV、上限和融资数字仅说明当前研究设定如何限制行为，不提供为修好2024误差而反调价格、成本或投资参数的理由。

2022—2024太阳能实际装机增长显著加速，现有2015—2021训练出的制造能力轨迹不能外推复现该加速；这可表述为训练后结构变化的证据，不能仅凭三年数据确认唯一的变化机制或精确断点。另建2024观测初态时，可将截至2024已经观察到的建设吞吐与已知政策作为预先声明的外生起点或边界敏感性，不回写训练历史，也不依照2030/2060目标反推增长率。净增装机还是建成吞吐的下界，不能冒充含退役的真实总施工能力。

当前连贯历史的长期路径会继承31.26%的装机缺口，必须标为条件实验。完整现实规模2024初态仍缺全国逐年龄、负债、补贴应收、在建队列等字段；不应在交付前仓促补资产并宣称观测初态完整。可优先补充纯物理的2024观测规模固定资产对照，保持投资关闭并明确资产效率、可用率与储能时长假设，不称其为预测。
