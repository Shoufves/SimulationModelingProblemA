# 2015—2024完整窗口的收入与补贴条件实验

2026-10-20。入口 `scripts/run_q2_historical_support.py`。在已核验的2015—2018真实输入实验基础上，把既有资产、初始在建项目、新建项目、寿命政策变更和有限资金的传导实际运行到2024。**它是条件机制实验，不是新一轮正式校准，也不是全国项目补贴复刻。** V10行为参数固定；2015—2021是训练窗，2022—2024已接触评估，不用评估误差选择“最优”场景。

## 来源与未知量

- EI2025全部发电类别、CEC2014和前期容量、抽蓄/回收/统计分配沿用 `q2_empirical_support_experiment.md` 的完整来源核验和限制。Other剩余取50%回收只是本轮固定条件；垃圾化石碳未认证。
- 2014—2018采用已核验NEA全国主要报送企业分技术电价及厂用电。风光生物能源以全国煤电均价作为能源部分代理，差额作为有效支持价差；不是逐地区煤电基准价、逐项目法律资格，也不把农林750、垃圾650元/MWh直接套给整个生物能源大类。
- **2019—2024缺少同口径全国分技术电价时，显式延续2018名义含税均价及厂用电比例。** 气电另设0.8、1.0、1.2倍条件，补贴价差另有半额条件。所有这些值标成假设，不能当作收集到的观测或置信区间。公开公司年报可供后续代理核验，但不能直接冒充全国均值。
- 2019年增值税按3个月16%、9个月13%计算不含税系数，2020以后13%；同2018变税年的处理一样，等月电量及一般制度均是简化。付款用支付年的CPI折为2024元。
- 财政部2015—2024全国电价附加收入/安排支出的预算与决算逐行核验原表。实际收入注入基金；实际支出的50%或100%是可到达企业的年度支付**上限**，不等同企业实收。2022/2023支出大于当年附加收入，不凭差值虚构财政拨款；已知外部追加拨款设零、期初现金/欠款设零，保留这一边界条件。资金不足仍欠款。

## 初始在建与新增投资

以前短窗只给初始已投产项目支持；本实验增加独立对照，检验“初始已批准在建项目也有支持资格”这一宽口径假设。它们必须实际完成建设、投产后才计量支持，期初承诺不变成可付建设款的现金。

新项目的支持独立于既有资产：在决策年给定有效价差、预计收款比例0.75、延迟2年，另设即时足额收款预期控制。投资只读当年条件，不读未来实际电价/产量/基金付款；这一当年年度均价条件仍是事后机制解释，不能称企业年初已知价格。

完整寿命的名义承诺上限以当年财政公布支出预算的5倍为控制条件，并另设25/100倍及100倍配及时收款预期的对照；**这是研究承诺额度，不是财政部实际公布的全国全寿命承诺额度。** 单价预留上限事先设1000元/MWh，不取未来实际价差最大值。同时申请共享有限额度，实际补贴仍受基金现金与年度授权双重约束；新项目仍付资本金、偿债和经历工期。输出区分批准数量、已投产数量、付款、应收和承诺。不能把保守的5倍承诺额度造成的新增投资不足，误归因于中国真实补贴规模不足；比较更大承诺额度并不会给企业或基金增加等额现金。

## 政策时间、计量与累计量

2020年10月426号文在模型中按**2021首个完整年度**执行；不能把这一年度近似称作2020年1月已知。变更前暂以机组物理寿命/满时数为有限上界，是未知历史政策期限的研究假设。2021起生物能源15年/82500小时；风光20年，资源区未知分别运行最低和最高小时界（风36000/48000、光22000/32000），不把任一端点当全国平均。特殊项目加成、户用、海上、地域配额和逐项目资格未识别。

执行新期限时保留原投产年、全部历史计量和旧应收；不清零累计量、不注销欠款、不撤销旧承诺后重新花一次。前期投资NPV保留当时预期，不以后来规则回写。2021起新增风光代表“新陆上风电/非户用光伏”退出中央支持；不取消旧项目权利，不能推广成所有风光项目都无补贴。

已修复新项目结算的错误约束：决策时的预计净/毛计量比例用于NPV，投产后采用当年实际/条件厂用电比例，且与物理母线一致。实际比例可以变化；单价上限与完整寿命计量上限继续约束承诺。预期比例不被后见数据改写。

## 本实验能证明什么

能够检验补贴是否实际影响融资、建设和投产，检查十年内资金、欠款、寿命量和能量闭合，并揭示只看四年平均误差掩盖的后期问题。不能证明全国真实资格、企业真实到账、真实欠款，也不能认证碳总量、非化石比例或2060目标。原默认输入与准入契约保留；后续仍需完整分类映射和重新训练，原验收门槛不改变。
