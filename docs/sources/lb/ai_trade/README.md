## 定量使用时的注意事项

1. 原油手册正文称“前十”，却列出11个国家；表格按实际饼图11国+其他录入，未自行删除。中东42.32%是正文精确表述，不能用四舍五入图例强行还原。
2. LNG总量67.0MT；分区小计7.2+22.1+38.0，加净转运调整-0.3，等于67.0。分项四舍五入后可能不等于小计；不擅自平差。原表空白保留为空，不定义为精确零。俄罗斯欧洲与亚洲分别保留，避免重复算区域总量。净转运调整不是供应国。
3. LNG报告正文将澳大利亚份额表述为32%，图表标签31%；模型优先采用贸易矩阵21.2MT及总量67.0MT，保留原文差异。正文“美国几乎为零”不代表零，矩阵为0.3MT。
4. 来源地不自动决定航线，不能把某国全部供应直接判为经过霍尔木兹或马六甲；仍需航线分配假设与敏感性检验。LNG不包含管道天然气。
5. 全国算力中心用电的170TWh为官方网页转载会议报道，不是已取得的底层统计表。2030年800TWh属于预测，不能无条件作为S0的必达值。
