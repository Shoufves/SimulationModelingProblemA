# 问题二技术分类与初态口径复核

2026-10-20；本页为技术口径研究，不覆盖原生产观测。原件保存在 `data/raw/q2_technology_scope/`；逐文件URL、获取时间、SHA256、定位与用途见该目录 `source_manifest.json`，统一目录已登记为研究用途。EI完整提取表另见 `data/processed/q2/electricity_scope/`。未检验的文件不得当作已准入数值来源。

## 关键结论

当前冻结OWID的 `oil_electricity` 不是可直接解释为纯石油发电的序列。仓库原README指向的OWID处理代码 `electricity_mix.py`（版本目录2026-04-24，本次从master下载）在 `process_ember_data` 第117行把 `generation__other_fossil__twh` 改名为 `oil_generation__twh`；第202—225行以Ember为基础，仅拼入2000年前EI记录及EI专属地区。中国2014—2024不属于这些EI补入范围。原codebook只给“oil”列名并列出上游，不能消除实际映射产生的边界差异。[OWID原代码](https://github.com/owid/etl/blob/master/etl/steps/data/garden/energy/2026-04-24/electricity_mix.py)

Ember方法PDF第9页脚注5将Other Fossil定义为石油及石油产品、制造气体和废弃物发电的合计。这里的“制造气体”不能直接当作天然气，也不能全计作石油。下载的聚合表没有给中国各组分比例，不能据此识别焦炉煤气、高炉煤气、非生物垃圾各自发电量。[Ember方法原件](https://files.ember-energy.org/public-downloads/ember_electricity_data_methodology.pdf)

该问题会影响纯油电技术的装机/利用率、纯油耗倒推，以及“统计油耗减去oil_electricity/效率”的非发电残差识别。变更显示名称不足以修复这些物理和碳账问题。回收工业余气的原料若已计入煤或其他一次能源，再新增一笔全油燃料需求还可能重复计算一次能源；反过来，未知组成的废弃物不能全设为零化石CO₂。这里没有找到可把Other Fossil完整分解为一次燃料的中国观测，不能用拟合结果冒充该分解。

## 最小可实施方案（供主模型负责人选择）

1. 保留并归档原OWID版，不静默改值。先解除“Other Fossil=纯油电”以及用该聚合电量倒扣纯油消费的关系；目前训练得到的油需求弹性/油电曲率不能作为该关系正确的证据，需重识别和重新完整训练验收。
2. 主数据采用一个完整版本和一个明确电量口径。最少改动可继续冻结现有OWID全套发电数字作为“历史聚合电源输出”，但将Other Fossil视为多燃料/回收来源未分解的类别，纯油份额、纯油燃料输入与其拆开。对原燃料账已包括的工业回收气/余热，须在同一一次能源账户内做转换和回收，不新增一笔全油输入或第二笔煤输入。没有来源分配观测时，不宣称该类别的煤油气或化石CO₂细分已独立验证；保留未分配来源及有界情景，不能默认全油或全零。
3. 生物质大类保留官方“含垃圾”的技术口径。将“可再生政策分类”与“燃烧化石CO₂=0”区分；垃圾非生物部分未识别，至少单列垃圾发电子类/边界不确定性。不要用未注明来源的50%等比例当作中国实测值；只有外部准入依据才能设定参数及上下界。
4. 气电初态优先使用明确版本的官方/CEC装机锚，并与同版发电及厂用电核对。NEA2014初步值与CEC后续详细值各自标注，不混合成伪精确序列。以气电与生物质合理装机修复初态，避免按错误发电结构反推不存在的燃油装机。
5. 如改用新版Ember，必须全期各技术、总量和水电/抽蓄一起替换，并重新拟合统计桥与核对代表日储能账；如改用EIA，先解决净发电与厂用电、抽蓄负净电量，以及Biomass and waste边界。上述定义缺口未补全前，将EIA同版作为完整敏感性对照更稳妥。

本研究不改变已有验收门槛，不把同源分类修正当作新增独立样本，也不声称当前已实现这些修复。
