# 地方气电容量收入：有限原文核查

核查日期：2026-10-20。范围仅为上海2019、上海2024、广东2023三份指定地方文件，复用已保存的国家能源局2013—2018电价报表。新增官方原件三份，没有扩大省份检索，没有修改模型或将地方机制激活为全国默认输入。本文记录的是历史规则，不宣称截至核查日这些规则未经后续调整。

## 1. 核查结论：NEA均价可能已含固定收入，暂不叠加

**国家能源局“平均上网电价”不能直接解释为不含容量收入的电量单价。** 2016、2017报表附表2-1及2-2（PDF物理页13、14）的定义为：平均上网电价＝售电收入／上网电量×1.17，含税。已对两年物理页13渲染核读，表下注释一致；这是一项收入折算指标，不是纯能量报价定义。2016报表附表还列出上一年数据，但其2015值不是既有2015报告同口径值，不能据此倒推此前独立版本的完整定义。

**尚未确定的事项：** 两份报表未在本次核读文本中逐项说明气电容量电费是否计入“售电收入”、各省纳入比例、收付实现方式或应收/实收。原文没有找到容量收入明确排除条款，也没有找到“各地容量电费全部计入”的明确条款。故“NEA 2014—2018气电均价全部含容量费”和“全部不含容量费”均不能作为已证事实。

2013—2014、2015已存网页为删减公开稿，可核定平均上网电价及含税标记，但没有完整附表计算说明；2018 PDF物理页5、8为含税平均上网电价与全国气电584.10元/MWh，物理页15为分省气电表，**该页没有2016/2017的公式注释**，已渲染确认。本次不把前两年的1.17税因子强行套给2018，更不当作任意年份实际税率。

上海2019文说明容量电价在原执行水平上下调，表明已有两部制收入机制，不是2019才首次创设容量收入；但这仍不能证明NEA 2014—2018具体报送企业的记账方式和覆盖率。广东2023文从2024才实施所列机制，不能倒填2014—2018年全国气电容量收入。

因此，本阶段将NEA均价作为收入等价均价开展有限历史对照时，**不在其上另加容量费**。这是一条防止重计的保守使用规则，不等于判定全国实际容量收入为零，也不等于已确认全部容量费都在NEA均价内。

## 2. 三份地方文件与适用边界

### 上海2019：已有两部制，分步调整

原文：[上海市发展改革委关于优化调整本市天然气发电上网电价机制有关事项的通知](https://www.shanghai.gov.cn/nw12344/20200813/0001-12344_59562.html)。落款2019-07-11，网页发布2019-07-16，2019-09-01起执行。

| 项目 | 原文规则，名义含税价 | 适用限制 |
|---|---|---|
| 调峰机组 | 调整到位后容量37.01元/kW·月，电量0.4802元/kWh；9E机组年度300利用小时以内电量加0.15元/kWh | 容量、电量价格均有2019-09至2020-08过渡步骤；37.01及0.4802从2020-09-01达到 |
| 热电联产，含小型背压 | 调整到位后容量36.50元/kW·月；年度前2500小时电量0.5044元/kWh，2500—5000小时区间0.4240元/kWh，超过5000小时区间为本市煤电标杆价 | 容量分步调整；电量直接调整，阶梯按区间计价 |
| 分布式气电 | 单一制0.7870元/kWh | 不能同时自动赋予上述容量费 |

主要范围为现役及已疏导电价矛盾的机组；五个具名项目有明确例外安排。其余新核准/备案及未疏导项目原则上执行煤电标杆价或市场竞价，不能以全部上海气电装机×容量费替代资格识别。发电气价联动另有规定，本次不从网页中符号缺损的联动公式重建数值。

只为单位换算，完整12个月且全额合格的37.01、36.50元/kW·月分别等于444.12、438.00元/kW·年；这是条件年化，不是2019全年或实际到账观测。

### 上海2024：同一价格，改容量计量和考核

原文：[关于优化天然气发电机组容量电价机制的通知，沪发改价管〔2024〕26号](https://fgw.sh.gov.cn/fgw_jggl/20240531/07bce8e660f2421bb5fcfee61413f96a.html)。落款2024-05-30，网页发布2024-05-31，2024-07-01起执行。

范围为已实施两部制的调峰、热电联产等气电机组；容量价仍为37.01及36.50元/kW·月（含税）。2—6月、9—11月按核准容量计，1、7、8、12月按申报最大出力计，申报不高于许可证容量；夏季允许偏差分别为调峰3%、热电5%。

因自身原因未按要求提供能力等情况，峰季月内发生2/3/4/至少5次，容量费分别扣10%/20%/50%/100%。除计划检修、正常停备外，自身原因导致全月无发电原则上容量费为零；电网、供气或其他不可抗力经认定不计入扣减次数。电网每月先按核准容量预结算，峰季结束后依认定出力清算。**预结算不能当作最终应得额或实收；零发电也不必然等于零容量费，须区分正常停备等例外。**

### 广东2023文：2024起容量与电量分开

原文：[广东省发展改革委、广东省能源局、国家能源局南方监管局关于我省煤电气电容量电价机制有关事项的通知](https://www.lufengshi.gov.cn/swlufeng/zdly/jghsf/jgzf/zfdt/content/mpost_999871.html)，陆丰市政府转载并注明来源为省发展改革委网站。粤发改价格函〔2023〕1990号，落款2023-12-27，2024-01-01实施，转载日期2024-01-09。

气电容量价暂定100元/kW·年（含税），适用于合规在运公用气电机组，自备及不合规机组排除。按月申报最大出力，月费率为年费率÷12；新机组投运次月起计费。电量价通过市场形成。容量费纳入系统运行费用，由全省工商业用户按当月用电量比例分摊、滚动清算；电网须把容量费单独归集、单独反映，并报送结算及扣减情况。

月内未达申报最大出力2/3/至少4次，分别扣10%/50%/100%；一个自然年累计3个月全额扣减取消获取容量费资格。应急备用机组另待认定和规定。这是计价和收费规则，不提供全国合格装机、申报能力、扣款、账龄、实收或统一财政补贴比例。

## 3. 收入分账的最低条件

若未来确需模拟两部制，应选用明确的电量价格序列，另算合格容量收益：

`R_energy = exported_MWh × energy_price_CNY_per_MWh`

`R_capacity = Σ_month capacity_rate_CNY_per_kW_month × recognised_kW × applicable_payment_fraction`

其中支付比例需区分政策考核后的应得比例与现金收取比例，不能只用一个“补贴到账率”包办。申报值若用MW，必须乘1000换为kW；上海按月价与广东按年价不能混用。税价和CPI转换应与既有收入账一致。

如果输入是NEA收入等价均价，则新增容量模块前应获得同年度、同地域、同企业边界下的收入拆分，以核对：

`reported_sales_revenue = energy_revenue + capacity_revenue_already_included + other_included_components`

不能简单从全国均价中减去“地方容量价×全国装机÷全国电量”，因为资格、覆盖、收入确认与统计权重均未知。没有该拆分时，维持总均价有限诊断，容量机制只做单列、明确条件的情景。尤其不把全部均价当短期发电边际激励：固定容量收入对发电量的作用与电量收入不同。

容量费是发电企业收入与付费方支出间的转移，不能在已计燃料、运维和建设的资源成本外再自动计为新增实物资源耗用；广东用户分摊与电网转付也不能重复计收入来源。这些地方源不能提供无限中央财政资金。
