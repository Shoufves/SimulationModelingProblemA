# 中国煤电进入行为：项目收益与行业收益的区别

2026-10-20取得NBER工作论文25437原PDF，共38页。封面实际题名为 *Why Has China Overinvested in Coal Power?*，作者Mengjia Ren、Lee G. Branstetter、Brian K. Kovak、Daniel E. Armanios、Jiahai Yuan，2019年1月。检索摘要最初显示了不同题名，现已依据原PDF更正元数据；不能把搜索摘要当作论文原件。

PDF第12—13页（正文第11—12页）讨论在历史平均调度、行政电价和进入限制变化下，新企业可通过取得原有企业的市场份额盈利，而私人投资量可能超过社会最优。其公式使用企业自身预期发电量与投资成本，并非要求整个煤电行业利润上升才允许进入。PDF第7页（正文第6页）说明历史平均利用小时的调度安排；实证主要依据2013—2016年审批记录。

该文支持我们对“统一业主”与“项目竞争”行为假设作区分。它不提供本模型全国逐年容量收入、财政补贴、企业实际资产负债或长期发电保证，也不证明2025年以后仍按相同调度规则运行。本模型在加入候选后的LP中重新计算可售量，比文中投资者忽略自身投资对利用小时的影响这一简化不同，不能宣称完整复现其因果模型。
