# 光伏资格与联合投资审核的一致修正

2026-10-20冻结本轮研究设计。`q2_corrected_factory:build`统一使用已核验光伏支持期限规则与`PortfolioNationalModel`，其他物理、融资、财政、成本与时点机制继承此前实验。

投资审核保留联合调度：只对当轮非正NPV技术减半，再重新计算全部剩余技术的共同市场。达到原有限次数后移除失败项，并重新检查剩余组合；没有未经检验的回退批准。上游全国预算、技术融资、建设能力与有限补贴授权不变；不把缩减所释放额度自动分给另一项。无补贴扩建仍受原政府接口保护，不能替换已验证支持组合为更小结果。

光伏支持期限依据已存2013年1638号原件，适用范围、20年资格与25年设备寿命分离、旧资格边界和未识别分布式收入限制均沿用`q2_solar_entitlement.md`。两项修正均在首次投资前配置。

训练使用2015—2021，2022—2024仍为已接触评估。沿用前次联合搜索范围和顺序，全部候选重新运行；不沿用旧机制的分数。三个未知授权倍数5/25/100均保留，无评估选制度。目标权重、尺度定义、误差门槛均不放松。先保存训练选择再运行评估与机制对照。旧工厂和源文件保持，便于直接复现历史实验。

本次修改不自动解决逐技术建设、收益价格、非电需求和长期财政问题。即使测试通过或某项误差改善，也须报告装机、发电、结构和现金的全部失败项目。后续Q3必须使用这一工厂重建并核对历史路径，不能拿旧工厂结果冒充修正后的情景。
