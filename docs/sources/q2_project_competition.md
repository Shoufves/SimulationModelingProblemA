# 按项目可售量评价投资，并保留旧机组损失

2026-10-20，在本版本全国运行前声明。主方案要求企业依据项目预期收入和成本决策；此前风光审核使用风光总新增销量，煤气审核使用同技术行业总增量利润。后者适用于统一业主，却会把竞争性进入者挤占旧机组的收益全算成进入者的损失。独立核查见 `q2_thermal_investor_scope_independent_review.md`。

本版本统一煤、气、风、光的投资视角：先将候选加入受相同燃料、电网、需求、储能和建设约束的规划LP，再划分LP实际输出。热机按有效运行MW占比分得电量；风光按每时段可用出力占比分得电量，与既有实际队列结算一致。候选售量加既有机组售量严格等于LP总售量，既有机组被挤占的销量与利润保留在其账中，不产生额外需求或重复售电。

项目收益按自己的电量、效率、燃料、可变运维、固定运维和适用ETS核算；候选自身合法电量用于补贴报价，零支持比例依旧为零。新项目NPV仍取学习预期和实际规划项目收益的较小值，保留工期、投产曝光、融资、偿债、年度建设和财政承诺约束。多个技术同时加入后重新审核全部候选；停止新增补贴不阻止自身盈利的无补贴项目。

新增真实运行的逐队列电量、售电、燃料费用、运维和ETS账户，每年按技术核对回原运行总账；该账户是分解，不再向企业现金账户重复支付。补贴仍由原有限基金向项目支付。本版本不把私人投资收益等同于社会收益，过度进入、弃电和旧机盈利下降都是可以出现的结果。

这是代表性部门模型中的竞争性项目筛选，融资仍使用原部门资金池，没有伪称已重建全国逐企业产权、独立信贷、破产或战略博弈。同技术共同利用率也不是高效率机组优先调度。这些限制须随论文披露，并由统一业主对照说明行为假设的影响。

关闭 `project_competition` 必须精确恢复上一热机模型。先固定既有训练参数做两种热效率×三组承诺权限的对照，再按2015—2021训练并报告全部2022—2024已接触评估。保留原目标权重、原误差门槛和失败记录，不用评估选择净55/58效率或财政额度。旧实验原文件及来源哈希保持不变。

当前接口要求开启竞争时煤、气两个项目审核均从首个决策年启用；缺失技术、技术在未来才可用、或关闭全部热机模块的组合明确拒绝，防止仅风光改变决策而仍宣称所有项目均采用竞争视角。逐队列ETS以企业收到为正、支付为负，与原总账同号。
