## 垃圾化石碳研究

新保存Ma、He、Lü、Zhang（2024）[Carbon Research开放获取论文](https://link.springer.com/article/10.1007/s44246-024-00162-9)、PDF和补充DOCX；DOI `10.1007/s44246-024-00162-9`。研究在2022年11月至2023年11月取样，覆盖上海五厂、江苏一厂、河北一厂，共八种工况，包含协同焚烧。

- 正文§3.3、PDF第11页图5：烟气化石CO₂占总CO₂比例，未处理44.64%—53.19%，处理后44.54%—53.12%。
- 补充表S4逐工况`Ave`列已提取为`ma_measured_flue_gas_fractions.csv`；所有原表保存在`ma_supplement_tables.json`。
- 正文§2.5.1公式(3)、PDF第6页解释FCF为**总碳中化石碳的质量份额**，须同时考虑垃圾成分、干物质比例及含碳量。该比例不是垃圾吨数比例、热值比例或发电比例。正文PDF第4页表2还提供不同成分的碳14测量，不能用统一垃圾50%覆盖它们。

研究证明中国垃圾焚烧不能整体设为零化石碳，并提供特定样本的研究范围；**不是2014、2021、2024全国逐年垃圾碳份额观测，也不是整个“生物质发电”组的固定系数**。若用于敏感性，必须明确样本、时点与全国外推假设；不能据此直接把约一半垃圾发电划成化石电，或从全国排放中扣除LCA避免排放。
