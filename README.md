# A题竞赛论文写作与复现指南

题目：**双碳背景下多种能源融合发展系统仿真与优化研究**。

本工作区服务于竞赛论文的三个问题：评价现状，预测双碳目标完成情况，比较能源安全风险与改善措施。本文是唯一的写作指导入口，汇总已有方案、数据说明和已运行结果；不增加数据、模型、实验或研究结论。整理基于提交 `ddb60bc`，问题二模型固定为 PR14 的 `1b8f465783afe7505c8d4e65ec43ada18c311daf`。问题一和问题三采用与它一致的当前版本。

**论文主线：**问题一识别需求增长、煤炭绝对消费、进口暴露、区域差异及融资条件；问题二将这些事实和经审查的补充参数转为主体决策、共享资源约束和2024初态，给出2025—2060条件路径；问题三沿用同一模型、初态和参数，检验退出与替代节奏、配套滞后及复合冲击，比较有预算和工期的改善措施。

三问均已形成可用于写作的代码、数据和结果。但问题二历史总装机、光伏装机误差仍超内部门槛；问题三给定候选集合中没有满足全部硬约束的政策。论文要回答题目并解释这些结果，不能写成“全部验证通过”“找到可行最优方案”。旧模型结果、可选N2研究和评审材料均已归档，不用于替换当前结论。

## 2. 竞赛论文的组织方式

依次写“问题分析与数据”“问题一现状评价”“问题二模型与预测”“问题三安全与对策”“模型评价与结论”，再列参考文献、AI使用声明和附录。摘要要同时回答三问，交代方法、关键数字与结论，篇幅一般不超过一页，不需要英文摘要。

|部分|必须回答的问题|优先使用的现有证据|
|---|---|---|
|问题分析与数据|研究边界、为何采用年度决策和年内运行、资料如何统一|赛题；本指南第3节和来源表|
|问题一|九类能源的规模、四维评价、优势短板和协同方向|Q1历史、指标、分能源与协同评价表|
|问题二|谁作决定、怎样交互、如何校准、2030/2060怎样、参数变化有何影响|主体规则、历史误差、基准与双侧敏感性|
|问题三|至少三个可比较的对照、哪些服务短缺、哪些措施有效及付出什么代价|情景路径、分服务缺供、H01/H02、8组政策|

## 5. 问题二：主体模型与双碳条件预测

### 5.1 主体与年度循环

模型有18个聚合主体：煤、油、气、生物质4类供给商；煤、气、油、生物质、水、核、风、光8类发电商；工业热、交通、建筑热、既有用电4类服务需求代理；政府和电网各1。碳市场表现为价格、覆盖、配额与结算环境。代理不是18家真实企业，部门服务也是聚合代理。

每年依次读取当年信息，处理投运、退役和设备寿命，形成需求并求解运行平衡，结算收入、燃料、补贴、碳交易及偿债，再学习、提出投资并经共同约束审批进入队列。项目完成工期后投运，不能提前发电。主体不读取未来实际观测。

|机制|正文需讲清的规则|代码位置（相对`vendor/q2_pr14/`）|
|---|---|---|
|主体和全国年度过程|设备、资本、需求和信息顺序|`src/energy_model/q2_national.py`、`q2_agents.py`|
|需求与学习|需求按GDP增速、弹性和效率递推；收益预期指数更新|`q2_national.py`及工厂参数|
|投资与竞争|私人项目NPV、可销售电量和共同投资额度；允许挤出存量销售|`q2_project_competition.py`、`q2_portfolio.py`、`q2_finance.py`|
|运行层|各载能体平衡、共享燃料、输送、设备出力、储能连续SOC|`q2_operations.py`、`q2_boundary.py`|
|补贴与财政|资格、应计权利、实际支付、拖欠与现金分开|`q2_revenue.py`、`q2_subsidies.py`、`q2_support_investment.py`|
|分类与排放|油/Other、抽蓄、非能源用途、垃圾化石碳|`q2_statistics.py`、`q2_bioenergy.py`|
|当前初态与未来条件|观测规模、队列与财务重建、未来参数|`scripts/q2_current_factory.py`、`src/energy_model/q2_forward_current.py`|

正文保留以下基本关系即可，符号统一为年度`t`、时段`h`、主体`a`：

- 需求：`D(a,t)=D(a,t−1)×[GDP(t)/GDP(t−1)]^ε(a,t)×(1−g_eff)`；设备存量和替代另入服务约束。
- 预期更新：`E_t=(1−λ)E_(t−1)+λπ_t`；投资评价：`NPV_j=−I_j+Σ CF_(j,τ)/(1+r)^τ`。正NPV仍要通过现金、贷款、抵押、施工和共同资源限制。
- 运行平衡：每载能体每时段的供应、放电和转换输出，等于已供需求、充电、转换输入及损耗；未满足需求单列。
- 储能：`SOC_(h+1)=SOC_h+η_ch P_ch Δh−P_dis Δh/η_dis`，容量与充放电功率受限；代表日首尾循环，事件窗口连续结转，不能每天重置。
- 排放：`P_t=Σ燃料投入×排放因子+过程及其他CO2`；`N_t=P_t−R_t`；中和率`R_t/P_t`。能耗和碳强度分别为`E_t/GDP_t`和`P_t/GDP_t`。

运行求解按既定服务优先、非化石优先及成本/行为规则分配。行为评分不等于实际资源费用。公共转移支付会影响企业现金和投资，但不能在系统费用中重复计入。

### 5.2 历史校准和初态

## 6. 问题三：安全评估与措施比较

### 6.1 情景与可比性

|情景|与共同S0的差异|比较范围|
|---|---|---|
|S0|同一问题二模型和参数|2025—2060年度路径；另有同快照的正常事件对照|
|SP|2027年起碳价×1.5|年度路径|
|ST|2027年起新储能成本×0.7|年度路径|
|SG|假设通道A中断，通道份额0.5、损失率1.0|12天连续事件，不是现实国家概率|
|SW|风/光/水可用出力因子0.35/0.55/0.65|与SG同快照、同窗口|
|SGW|SG和SW联合|用于共同资源压力和交互检验|

事件有2天事前、4天冲击、2天恢复及后续时段；主快照2030，另检2035。各方案共享信息条件：年度只知当时状态、公告路径和已承诺项目，事件每天只知当日24小时。长期路径和事件不能相加，也不能用一个事件窗口代表全年可靠性。

### 6.2 指标、H01与H02

按服务计算`缺供率=未供服务量/请求服务量`，再取案例和年份范围内最大值。恢复定义为连续24小时缺供清零，窗口结束仍未恢复的保留右删失。政策同时检查年度/事件缺供、排放、资源费用、公共预算和工程边界，不用一个加权总分抵消硬约束失败。

H01检验退出速度`vR`、终端电替代速度`vE`与配套滞后`L`：退出速度0/2%/4%，替代份额0/25%/50%，滞后0/1/3年；与固定日程、成本顺序、替代就绪、滚动安全审查四种规则比较。预设额外检验点为3%、37.5%、2年。完整主体组的`L`增加新电网/储能工期，固定项目组的`L`移动同一批已承诺清洁发电项目投运时点，两者不能混称同一干预。退出最多延期3年且不越自然寿命，实际提前退出与到龄退出分列。

H02按每种服务计算联合超额损失`J=U_GW−U_G−U_W+U_0`，并与限制气电向上调整的冻结响应对照。冻结不增加资源、不重置库存、不降低服务；不能仅凭J就声称证明了冲击传播。不同物理服务不相加。

8个政策候选为电网、储能、气源分散三种措施的全部组合（含空方案）。2025决策，公共年度额度0.05% GDP；新增网/储比例2%/1%，气源分散20%，合同2年生效并有成本。排放不超过同条件基准1.05倍，资源费用不超过1.10倍，年度缺供不超过5%、事件不超过15%，公共支出不超额度。所有参数为既定条件设计，不是观测得到的最优政策。
