## 基线方法

只用2015—2021拟合，统一锚定2021实际消费总量。令E为能源消费、G为实际GDP链接指数，T为2021年。

1. 强度不变：`E[t] = E[T] * G[t]/G[T]`。
2. 能源时间趋势：`E[t] = E[T] * exp(b_E * (t-T))`，b_E由训练期log(E)对年份回归。
3. GDP弹性：`E[t] = E[T] * (G[t]/G[T])^beta`，beta由训练期log(E)对log(G)回归。
4. 强度时间趋势：`E[t] = E[T] * G[t]/G[T] * exp(b_I * (t-T))`，b_I由训练期log(E/G)对年份回归。

实际GDP指数由实际增长率链接，2015=100。它是从一位小数增速派生的近似指数，不是官方不变价GDP绝对额。

GDP相关基线使用留出期实际GDP，仅检验给定GDP条件下的需求映射。2025不参与拟合，单独计算误差。JSON中的主metrics只对应2022—2024，独立年metrics另存。

本轮没有根据留出表现选择最优模型或调整训练窗口。强度不变基线在这段留出期的较小误差，不能证明长期强度不会下降，也不能证明某项政策的因果效果。

## 核算函数边界

`src/energy_model/accounting.py`目前只实现四种可复用核算：

- 分载体能量平衡：供给、转换、库存、损失、实际满足需求和显式缺能。
- 容量时点：投运年前不可用，退役年起不可用。
- 储能状态：区分功率与能量，计入充放电效率，禁止同时充放电和能量越界。
- 碳账本：化石能源CCS只扣减一次，碳汇/移除单列，中和率分母为零时返回缺失。

这些核算函数使用统一单位的调用输入。缺失统计输入由fuel_ledger.py明确处理；另有agents.py运行合成主体投资和价格反馈，见docs/09_agent_prototype.md。区域运行及全国排放预测尚未完成。

基础模块测试仍为11项，涵盖上述关键不变量、缺失保留、来源与年份校验、单位转换、基年链接，以及改变留出能源观测不会改变训练参数或预测。连同后续工作流、附件、燃料账本、初评、主体、历史分类、13项连续运行和8项实验台接口测试，标准库入口共88项通过；另有6项Streamlit界面交互测试通过。数量不代表历史模型验证完成。

operations.py已实现独立水核风光煤气连续运行窗口，复用Storage核算，显式限制充放功率、库存、效率、燃料与送出能力。run_prototype.ps1同时生成主体原型与outputs/prototype/operations/的储能对照；两个模块尚未耦合，见docs/10_operation_windows.md。真实校准输入、用途及实施顺序见docs/11_calibration_input_contract.md。

run_workbench.ps1已接入本地交互实验台，复用现有主体/运行模型并现场检查证据；实验在会话中运行和下载，不覆盖正式数据。依赖、操作和边界见docs/12_workbench.md，浏览器验收记录见review_workbench_20261017.md。

## 关键数据处理

2025公报的旧备用路径提取不完整。本轮切换到正式发布路径并核实了消费绝对量，现已填入观测；原始年鉴序列保持独立。

煤炭平衡存在洗选固废口径调整及历史修订。2025年鉴中的原煤产量与平衡表生产量也有差异。因此，煤炭当前只允许分年审计，不用于连续校准。洗选损耗空白不能自动设成0。

旧年电力平衡表未单列太阳能。差额保留“未分配发电量”，不能把差额全部变成太阳能。装机与发电量不能直接用年末存量计算全年容量因子。

统计局年鉴原表图片尚未下载成功。后续已留存S17—S21的官方页面可见文本及S13所用段落/表行/脚注摘录，并按注明字段复核，详见data/evidence_reviews.json和data/attachment_reviews.json；不能将这6份材料的核验扩展到其他来源或整个历史序列。
