# 模型边界与主体规则草案

版本：0.3；日期：2026-10-17。以下为完整目标体系，尚未全部实现或获中国历史验证。

当前已实现能量、储能、容量和碳账本基础函数，以及历史需求统计基线；新增合成主体原型已运行价格、设备替代、调度、投资和滞后投运反馈，说明见docs/09_agent_prototype.md，轨迹见outputs/prototype/。它只支持煤油气/电力的程序机制验证，不能代表下述完整全国模型。尚未实现校准后的全国系统仿真。

## 研究问题与范围

检验：碳约束通过主体投资与用能替代改变能源结构时，建设滞后、灵活性不足和外部冲击是否形成安全短板；哪些政策组合在多个情景中仍然有效。

覆盖煤、油、气、水电、核电、风电、太阳能和生物质；储能与氢能作为转换及储存环节。煤油气终端直接消费必须纳入，不能只做发电排放预测。

实现补充：operations.py已单独验证水核风光煤气细分及连续SOC运行，见docs/10_operation_windows.md；尚未与agents.py的年度抽象步投资耦合，未使用真实全国参数。历史接入按docs/11_calibration_input_contract.md逐模块验收。

氢能消费不计作新增一次能源生产；制氢能源投入及损失单列。抽蓄放电不能作为新生产的非化石能源再次计入。生物质燃烧、土地利用和生命周期边界需明确；不能仅凭“可再生”标签自动设定全生命周期零排放。

第一版为全国、年度步长、代表性企业群和部门主体。后续按数据增加区域与运行模块，不把附件电站样本当作全国完整清单。

历史区间计划2015—2025；候选基年2025。若核心口径不足，则统一退到2024。未来逐年推演至2060。

## 状态与核算

容量按技术、投运年份形成存量队列：

`K[t+1] = K[t] + 本年投运项目 - 本年退役项目`

投资决定进入在建队列，经过技术工期后才投运；投运与退役顺序必须固定。

各能源载体独立平衡：

`国内供给 + 进口 + 转换产出 + 期初库存 = 终端使用 + 转换投入 + 出口 + 损耗 + 期末库存`

供不应求记录未满足需求，不能靠虚构进口或负库存平衡。未满足需求也进入成本与安全指标。

能源相关排放依据燃料在燃烧环节的使用量计算，排除重复计入的转化中间品和非燃烧原料用能；CCS捕集量受可捕集排放、能耗、容量、输送和封存约束。避免同时扣除已在排放因子中净掉的捕集量。

全国净CO2：

`净CO2 = 能源活动CO2 + 工业过程等边界内CO2 - 可核实碳移除及碳汇`

本项目暂定义中和率为`(可核实碳汇+移除)/正排放总量`；正排放含工业过程，能源排放已扣一次CCS，不再把CCS加入移除分子。分母为0时单列说明，负净排放另报。该定义为项目操作定义，必须在论文披露。

能源强度与碳强度以同一不变价GDP序列计算，报告相对于2015基准及政策规定基准的变化时分别标明。

## 主体规则

| 主体 | 属性/异质性 | 决策 | 约束与信息 |
| --- | --- | --- | --- |
| 政府 | 排放、安全、财政目标 | 发布碳价路径、支持政策、备用要求 | 首版外生政策；进阶反馈政策只用当期及过去信息 |
| 能源企业群 | 技术、资产年龄、融资成本、风险偏好 | 投资、退役、改造、生产 | 预算、工期、资源、容量、收益预期 |
| 电网/系统运营者 | 输送能力、调度规则、备用 | 可用资源调度、储能运行、互济 | 功率、能量、效率、网络损耗 |
| 工业用能主体 | 产业活动、设备寿命、替代成本 | 节能、电气化、燃料替代 | 投资预算、设备更新速率、有用能需求 |
| 交通及其他用能主体 | 运输/服务需求、设备结构 | 设备更新、节能与替代 | 寿命、基础设施和技术可行性 |

首版碳价为政策输入，不宣称已经实现碳市场出清。市场成交均价也不能直接替代所有主体的边际履约成本。进阶市场模块须明确配额分配、交易覆盖与出清规则。

企业依据有限信息估计收益：预期售能收入减燃料、运行、碳和投资成本。比较候选项目净现值，在资金、工期与供应链约束内选择。预期由历史价格与需求更新，不允许读取未来冲击。

需求主体先预测有用能源服务需求，再决定技术和燃料配置；电气化改变转换效率，不能按相同终端能源量一比一替代。异质性参数仅在有依据或可识别时增加。

## 年度执行顺序

1. 读取上一年状态，实施本年外生政策和事件。
2. 处理年初投运、计划退役和可用容量。
3. 各部门形成需求，选择当期可行替代。
4. 调度供给、进口、库存和转换，形成供需、成本与排放。
5. 主体更新价格预期及收益，提出进入未来年份的投资。
6. 政府进阶规则根据本年结果制定下一年政策。
7. 保存能量平衡、碳核算、主体决策、事件和参数版本。

同一年度的价格反馈如果采用迭代求解，须定义收敛条件与失败状态；不得静默使用未收敛结果。

## 两种时间尺度

年度层：历史校准、需求变化、投资退役、结构和排放。

运行层：先在2030、2040、2050、2060进行代表时段校验；后续如承担全年可靠性结论则扩展覆盖。成本与年电量采用明确权重；连续极端窗口保持储能和库存状态，不用独立典型日替代持续风险。

储能状态：

`SOC[h+1] = SOC[h] + 充电功率*充电效率*时长 - 放电功率/放电效率*时长`

分别限制功率与能量；充放电互斥或证明不会同时发生；跨时段边界不能凭空恢复SOC。只有少量代表窗口时报告“窗口内缺能”，不宣称全年停电概率。

运行约束反馈到投资时，下一年增加灵活性需求或修正收益；不能直接在结果中补上免费备用。

## 校准与验证

计划：2015—2021校准，2022—2024验证；2025作为独立检查。若改用2015—2022校准和2023—2025验证，需在调参前锁定方案。

先用观察数据固定容量、需求、成本等已知量，再校准少量投资响应、需求弹性与预期更新参数。多个指标归一化误差共同作为校准目标，不只拟合能源总量。

验证报告：总量、煤油气占比、分电源容量/发电、排放，各年误差与趋势。与结构冻结、简单趋势外推等基线比较，检查复杂主体机制带来的增益。

通过验证集挑选参数后，该集合不再是独立最终检验集；需要另留检验或明确报告。

必要的程序检查：能量守恒、SOC边界、容量非负、建设滞后、禁止未来信息、排放无重复扣减。

关键参数无法识别时固定为有来源的区间，给出等效参数组与预测范围，减少不必要的自由参数。

## 首版输出

逐年：能源供需与结构、容量与建设、分主体成本、进口依赖、排放、未满足需求。

关键节点：2030/2060水平、累计排放、达峰候选年份和持续下降情况、中和率与剩余排放。

达峰需报告所用判定窗口；模拟最后一年最大不能视为确认达峰，短期下降后反弹不能掩盖。

缺少工业过程与碳汇数据时只发布能源相关减排结果；全国碳中和率保持未完成。
