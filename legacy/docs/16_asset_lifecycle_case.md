# 题给核电附件与真实许可事件接入

日期：2026-10-17。本轮落实W1的实际附件用途及W4的资产事件状态。范围是秦山基地7台机组的许可记录回放，不是全国容量初始化、经济投资决策或实际退役预测。

## 为何先接这个案例

附件4按厂列出秦山、秦山第二及秦山第三三条记录。国家核安全局2017年通知逐台列明这三厂7台机组的许可期限；2021年又批准秦山1号机组延续至2041年7月30日。浙江能源监管办2021年6月说明秦山1号机组首次并网于1991年12月15日，初始设计寿命30年；当时延续手续仍在评估准备。

因此，投运/并网、设计寿命、许可期限和实际退役必须分别建模。以设计寿命届满自动删去机组，会遗漏真实发生的许可延续；把许可截止视作实际停机日同样没有依据。本模块给后续主体模型提供有来源的事件状态，不替政府审批或企业行为建立无依据的经济规则。

## 数据与文件

三个来源S26—S28在data/sources.json登记，网页正文实际使用段落留存在data/raw/official/；都是明确标注的网页文字摘录，没有取得原始HTML或许可附件PDF。已另次重开逐项复读全部7个原期限、新期限、设计寿命和并网日期。相关文号、日期和使用限制随摘录保留。

数据为data/observations/qinshan_asset_permit_case.json。数值单元统计只计算observations中的30年设计寿命；机组身份、8个许可事件及日期另计，不能把全国目录的数值计数当作事件覆盖率。

源文件中的“秦山第三核电”通过明确的别名绑定对应通知中的秦山第三核电厂，仅限该厂和指定行，不使用模糊匹配推广其他记录。三条厂级原始容量330、2620、1456原样保留在结果中；原附件单位、年份及机组分摊未核实，精确MW仍为null。

## 状态规则

1. 逐机组标识与附件原文件、sheet、行号连接，不把三条厂记录当三台机组。
2. 仅选择在信息截止日前可见的许可事件，并采用最新记录。2017通知使用明确生成日2017-12-20；2021审批落款2021-09-03、生成2021-09-06，按生成日回放。生成日是研究信息时点约定，不能冒称核实了公众首次获知日。
3. 最新记录的截止日按包含当日处理。超过截止只标为“已登记期限已过，需核查”；没有记录则“无可见许可记录”。二者均不自动生成实际退役、零装机或法律结论。
4. 2021年7月31日至新延续事件可见前，不补造停机或许可衔接事实。首次并网日期不代替商业投运日期。
5. 未来节点只检查截至2026-10-17所收集文件的期限，不假定以后不再延续、不代表完整当前许可证普查，也不预测实际发电。

分别运行“全部所选许可事件”和“遗漏2021延续事件”两个诊断对照。它们检验状态规则是否保留重要事实，不是全国能源政策情景或自主主体机制增益。
