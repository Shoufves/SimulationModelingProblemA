# 家庭能源账单与煤炭就业专项补查

核验日期：2026-10-17。原资料目录和旧来源清单未改动。独立来源清单为 `sources_household_employment.json` 和 `01_来源清单.md`；CSV的SHA256见 `derived_files_manifest.json`。

## 实际补到什么

1. 原始论文 Wang et al., *Nature Energy* 8, 251–263 (2023)，DOI 10.1038/s41560-023-01193-z，2023-02-16发表。已保存公开补充说明PDF（20页，约1.1MB）及出版社Source Data Figs.1–6原ZIP（约6.7MB，6个xlsx）。不是仅保存问卷或检索链接。
2. `data/household_energy_median_si_table2.csv`：直接抄录SI表2的36项城乡×6收入组×2013/2015/2017家庭能源账单中位数，元/户/年。SI Note 1明确energy cost为年度能源账单、burden为能源账单/家庭收入；贫困阈值为大于10%。该阈值是论文研究定义，不是中国政府认定标准。
3. `data/household_energy_burden_fig5.csv`：出版社图5的108行地区代码×城乡收入组群体汇总，包含2013/2017负担中位数及能源贫困比例。代码对应SI表4的9个气候/区域组。SECO包括辽宁、吉林、黑龙江和内蒙古；它不是省级数据。
4. `data/coal_employment_census_2023.csv`：两省区五经普煤炭开采和洗选业企业法人单位就业存量，已保存原文和山西表3-2原图。山西2023年末93.27万人、3000企业；内蒙古2023年末19.9万人、1077企业。山西原发2025-04-11；内蒙古原文2025-03-18、玉泉区政府转载2025-05-21。转载内容是全自治区，不是玉泉区就业。
5. 国家林草局2025-10-15发布的古莲河矿业转型原文：实际已种蓝靛果5万余株、修复26公顷。未来百万株、520公顷和3000万元产值属于规划。该文未给实际转岗人数，不能从种植面积推算已安置人数。

## 原始附件与口径风险

- 原ZIP在公开论文页无须登录即可下载，但其中图3/4/6含家庭层面衍生行。本次取得的是出版社图表源数据附件，**不等于取得CFPS完整原始微观数据库**，不具备调查权重、完整变量、全部年度和可直接连接的跨表标识。图3各费用列不能凭行号与图4收入任意拼接。
- 早期检查已生成 `household_energy_source_fig4.csv`（38006条）和 `household_energy_by_author_group_unweighted.csv`（36组未加权汇总）。随后核实CFPS现行AI规定明确禁止云端AI接触家庭/个人微观数据及衍生数据集；公开文档、元数据和不识别个体的群体汇总允许。后续云端工作优先使用SI表2与图5群体汇总；**不得继续让云端AI读取原ZIP/解压的家庭级工作表或图4逐行CSV**。原件保留供用户按适用条款安排本地研究，未上传到外部数据平台。
- 36个图4未加权中位数与SI表2对照，33项一致，3项不一致：2013城镇Extremely poor，SI 2032、图4汇总2040；2013农村Extremely poor，SI 1180、图4汇总1200；2015农村Rich，SI 1960、图4汇总1560。未擅自修改。原因可能涉及作者清洗或汇总流程，未获作者说明，**不能声称复现完全通过**。当前表2CSV严格保留已发表汇总原值。
- 费用列包括电费、LPG/天然气/煤费合计及集中供暖费；不能把合计燃料费用拆成单种燃料实物量，也不自动包含车用燃料、生物质自采机会成本。均为历史名义元，不可直接初始化2024。
- 论文正文为订阅预览，本次没有绕过付费。程序下载论文HTML和Supplementary Data 1 ZIP收到3038字节Client Challenge HTML，已标为 `blocked_response`，不得计作有效原件。SI PDF重试后成功取得并检查了完整相关页。

## 最新就业与访问条件仍缺什么

2024/2025逐省煤炭采洗就业存量、退休、新招聘、关闭/智能化导致的转岗人数、实际吸收率和转岗时滞仍未取得。五经普2023两省区快照可作历史比较，不能冒称最新年度各省完整表。产量、产能、煤电装机或企业数变化均不得直接换算净失业。

已实际检索山西2025统计年鉴/从业人员、山西/内蒙古/陕西/新疆五经普煤炭就业、2025煤矿职工转岗退休招聘、国资委2024/2025转岗安置。山西年鉴搜索主要返回二手目录及产量，未定位可下载的最新分行业从业人数表；陕西结果未找到省级原表；新疆定位到第六号R&D公报，不是就业表，没有用其R&D数冒充就业。转岗检索多为旧案例、政策安置规则或未来规划。故本轮未宣称穷尽全国年鉴。

CFPS官方公开数据申请指南已保存：官方数据平台与北大开放研究数据平台账号不互通；新用户须注册、填信息、提交申请，审核通常3个工作日，北大学生/教职工也须审核。本次未登录、注册、提交申请或取得微观库。已同时保存现行AI管理规定以说明实际使用边界。没有把问卷或论文的data availability声明当作数据已经到手。
