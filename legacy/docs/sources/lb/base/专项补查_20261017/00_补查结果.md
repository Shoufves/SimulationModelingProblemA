## 不可忽略的核验结果

- 家庭收入分组是论文定义的6组，不是国家统计局五等份。SI表2与图4未加权汇总有3处不一致，原值保留，未强行修正。后续使用已发表群体汇总，家庭级原始/衍生行的使用边界按CFPS现行规定核对。
- LNG网页详细Excel标为会员资料，但公开PDF正文已包含矩阵，所以这一缺口已经实质补齐。部分正文/图例份额有差异，优先用矩阵；空白不改零，小计不因四舍五入强行平差。
- 原油手册“前十”的文字实际列11国；CSV按图录入。进口来源不等于运输航线，通道暴露仍需另行定义。
- 全国/地方能源核算存在来源与方法差别，不能无条件要求各省库存变化加总等于全国。

下一步适合进入统一参数表：对每个参数记录“观测／文献估计／历史校准／情景假设”，并注明年份、地域边界、单位、来源文件和不确定区间。当前资料足以推进部分模块的结构设计与历史校准，但不能称所有模型参数已齐全。
