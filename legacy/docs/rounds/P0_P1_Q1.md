## 4. 方法与解释约定

- **保障**：同燃料、同统计期、同单位计算净进口依赖和来源集中度；分子分母不匹配则阻断计算。已知来源组合计只能给有依据的界，不能构造各国点份额或直接换算失供量。
- **低碳**：一次能源、发电、装机分别核算；非化石消费占比不由发电占比替代，天然气不计非化石。能源/碳强度使用可比价 GDP 与匹配排放边界，燃烧、过程、捕集及电力消费侧核对避免重复。
- **经济**：至少给出有来源、同服务、同价格年与一致寿命/融资口径的可比成本分析，并检查可用价格系列的波动；燃料采购、资本建设和 LCOE 的组成不能重复相加。进口金额结构、投资结构只能作背景。
- **协调**：同年同地域的发用电份额差异、弃电、储能功率与能量等按可得范围分别报告。区域空间差异不直接等于不安全，利用率不当容量因子，MW 与 MWh 不混用。
- **缺项**：输出 `null`/明确缺失状态、原因和影响；未知不填零，不将“未提取”写成“没有资料”。不通过人为补残差使能源/碳账闭合。
- **评分**：原始指标和覆盖情况必交，综合分数可选。若评分，参照、方向、权重跨年份固定并做权重检查；不得按某年排名倒调权重，缺维不重新分配权重制造完整总分。

价格波动默认考察 2015—2024 同一系列的年度对数变化，明确使用的相邻年份与缺失导致的有效覆盖；有断点则分段展示，不填补价格后拼接。不另挑对结论有利的窗口。成本缺少可信价格年或折现依据时，该成本结论保持阻断状态，不能用未说明的演示数代替。

**工程门槛和科学覆盖分别核对，测试通过不等于问题一已完成。**

| 编号 | 必需检查 | 通过条件 |
|---|---|---|

| A2 | 四维定量与诊断 | 四维均有适用的定量证据和优势/短板解释；经济性包含同服务成本比较与价格覆盖检查，协调性包含区域与调节约束分析，不能只以既有代理指标声称完整 |
| A3 | 数据可追溯、同源去重 | 任取关键数字能回到原件页表/单元格及换算；同源不当独立观测，冲突/隔离状态随输入保留，新增用途有实质审查 |
