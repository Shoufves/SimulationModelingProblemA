# 统计口径与模型数据接口约束

日期：2026-10-17。依据：S13国家统计局2024年公报及相关脚注、S17能源局电力表、S22能源局公开天然气报告、S23发改委表观消费快报。适用W2、W3及W4接口准备，不代表W4已经实现。

## 当前可使用的事实

S13子集33值、S17子集10值、S22子集20值、S23子集2值，均只支持注明发布版本的2024横截面。S22报告采用部分行业统计，编制与发布身份分开。每项原始观测保留source_id、year、value、unit、locator和scope；核验状态以正式清单为准。数据字典在JSON每条观测内，派生量另列于outputs/current_assessment/，不能反写成原始观测。

|指标组|原始单位/边界|可以派生|不能直接派生|
|---|---|---|---|
|GDP绝对量与增长|现价亿元；不变价同比|同口径增长比较|由现价总额直接计算官方不变价强度|
|一次能源生产与消费|亿吨标准煤；注25洗选固废调整|分别描述供需规模|把二者差额认作净进口或缺电|
|原煤、原油、天然气产量|亿吨、万吨、亿立方米|保留各自物理量|无热值时相加或换标煤|
|能源进口|万吨及亿元，商品组合各异|金额/质量的年度单位价值|现货价格、国产技术成本、无出口库存的净进口依赖|
|发电量|亿千瓦时；火电含生物质等|同表技术发电占比|全体火电CO2、非化石一次能源占比|
|装机|万千瓦，年末存量|同表技术装机占比|与另一版发电量强行拼接容量因子|
|清洁消费占比|包括天然气|独立描述公报定义|当作非化石占比，或与煤炭占比拼出完整结构|
|能耗强度降幅|扣除原料及非化石用能，GDP按2020价格|作为单独历史考核指标|当总能源/GDP强度的同口径校准目标|
|碳强度降幅|万元GDP二氧化碳排放，2020价格|同口径强度比较|无排放基准时求全国CO2绝对量|
|碳市场成交|配额亿吨、亿元|成交额/成交量比值|实际排放总量、期末碳价、未来政策路径|

## 数据进入模型的接口

模型输入必须带以下属性，缺项以null或显式错误处理，不补默认常数：

|接口字段|含义|校验要求|
|---|---|---|
|quantity、unit、carrier|活动量、单位、载体|天然气质量和体积不同；电力/氢作为转换载体不重复算一次能源|
|period、region、vintage|年份、地域、发布版本|跨版衔接必须有桥接记录；区域不能由县名猜测|
|use_type|燃烧、原料、转换、储存、损耗|非燃烧用途单列，转换投入/产出不重复归为终端|
|price_basis、gdp_base_year|价格口径及GDP基年|强度分母采用一致不变价；单位价值不能冒充市场价格|
|source_id、review_id、locator|证据链|必须属于相应用途准入子集|
|status|observed、derived、assumed、calibrated|假设与观测分开，派生量保存公式及输入哈希|
|uncertainty、missing_reason|不确定性和缺项原因|缺值不默认为0，假设标明范围及灵敏度任务|

模型每年分别输出总能源强度、考核口径能源强度、CO2强度，避免用一个字段承载不同含义。考核口径所需扣除项不足时，相关输出为缺失；全国总量输出须完整活动量、因子和过程排放/移除边界，不从本公报强度反推吨数作为观测。

## 已实现的燃料账本接口

src/energy_model/fuel_ledger.py对单载体、单年、统一数量单位建立P+M-X-国内使用-库存增加-损耗-统计差=0。国内使用包括终端燃烧、原料及转换投入，排除另计损耗；库存增加为期末减期初。库存变化和统计差可为负，其余活动量非负。

所有未知项为None，不能自动补0或用残差替代。reference_state记录数量基准，如气体温压；common_boundary_verified明确来源范围已经桥接。缺项或边界不明时closed=None，require_closed拒绝验收。数值齐全仍可能unbalanced，不自动调平。

当前天然气报告产量/进口可读，但缺同边界国内使用、出口、库存、损耗和统计差，体积基准未明确。发改委表观消费不直接当该账本国内使用，因此实际账本保持incomplete。代码检查与实质统计桥接是不同工作。

## 天然气部门与安全指标约束

- 城市燃气34%包含居民、采暖、公福商业和交通等，不是单一居民主体。
- 工业燃料41%、发电18%、化工化肥7%属于报告分类；化工化肥需拆分燃烧/原料。
- 报告消费同比7.3%与快报表观消费同比8%分开；不能用快报总量乘报告份额制造部门量。
- 管道气760、LNG1057与总进口1817是同报告体积，可描述进口结构；不凭它反推吨/立方米通用密度。
- 五来源1477可描述集中性，缺逐国份额不算HHI；新增储气80不是总能力，不算覆盖天数。

## 由本轮证据驱动的主体实现顺序

1. 需求主体：记录工业、交通等服务需求、燃烧与原料用途及设备存量；先补部门数据，不把原油同比当终端燃油需求。
2. 供给与贸易主体：分别处理煤油气的国内生产、进口、出口、库存和热值；国产气/进口气单位转换有官方参数才执行。
3. 转换与电网主体：把一次能源转换为电力、氢等，记录转换损失；生物质火电与化石火电分开；抽蓄能量守恒。
4. 政府/市场机制：分别观察能源、碳与考核强度；历史碳成交只用于市场验证，碳价情景另登记假设和敏感性范围。
5. 企业投资主体：在成本、工期、寿命、资金和可用技术约束下决策；附件只作已标明的项目样本，不构造全国权重。

当前缺部门服务需求与设备存量、热值/因子、成本/工期等输入，因此以上为接口约束和实现顺序，不能宣称真实行为闭环已建立。
