## 实现边界

原 `src/energy_model/q3_*.py`、原Q2/Q3输入、全部历史结果、PR14 vendor和N2代码/证据均保留。新增 `src/q3_pr14/` 继承PR14 `ForwardModel`，保留原187案实验组合、160点H01、8政策、预算、工期、场景强度及选择/检验划分。

政府审批委托给实际工厂绑定方法；Mesa的年度step重新绑定，确保Q3付款与退役真正执行。提前退役写入PR14资产真实退出年，使运行暴露与投资预测读同一状态；自然寿命独立保存，不因延期变长。既有H01固定项目对照、四种规则和有限搜索方向不变，没有引入N2新规则。

事件LP由固定PR14版本派生，仅为电池和独立抽蓄增加显式非周期自由终端SOC。年度运行仍调用原LP。库存跨日连续结转，期末存量按同一价格计入终值调整；回收热/电不重复计碳。循环条件下与原LP结果完全相同。原Q3规则中的L仍有两种不同含义：完整主体组增加新电网/储能工期；固定队列组移动初始风光水核项目投运时点，不混称同一种干预。

## 复算后的结论

| 结论 | 统一版本结果及保留边界 |
|---|---|
| Q1规模与结构 | 原能源增长37.29%、煤份额下降但绝对量上升、贸易/空间/成本判断保留 |
| Q2路径 | 24案通过原参考容差；Q3的36年S0逐字段通过同一参考检查，未改变Q2结果 |
| H01 | 160/160点超过原5%年度服务界；选择集规则为replacement_ready，不等于已找到可行政策或普遍最优 |
| H02 | 40行逐服务结果中J和冻结响应贡献均为0；旧版零交互结论在当前条件下仍成立，不能声称已证实复合放大 |
| 政策筛选 | 8/8候选未过年度服务界，selected=null。原版policy_2储能优选留在旧模型结果，不跨版本挪用 |
| SP/ST | SP与S0在本次物理结果上无差异；ST降低成本并略减国内电力缺供，仍未达到服务门槛 |
| N2 | 原有限条件下的成对不劣及少延退结论原字节保留；它与系统硬可行性是不同命题，不自动赋给本轮Q3 |

三问的缺供必须连同分母报告。以S0为例：2060汇总展示缺供率3.396274%，国内既有电力服务缺供率7.339116%，出口电力服务缺供率50%。后者使全服务最差值为50%，但即使单独披露国内服务，7.339116%也超过原5%界。不能用3.396274%替换逐服务验收值。本次没有为保留旧政策排名而放宽门槛。

S0/SP累计未折现资源费403.548096万亿元，按5%折现为182.855723万亿元；ST分别为401.333611和182.121093万亿元，均为2024不变价。逐年、逐服务分母及三种汇总见 `outputs/q123_alignment/scenario_service_fractions.csv`；各187案共同成本口径见 `annual_common_metrics.csv`。

工程复现通过不代表全国精度验收通过：PR14总装机MAPE约24.90%（门槛20%）、光伏装机约26.77%（门槛25%）的失败继续披露。代表日、单节点、初态重建、政策延续及碳边界等限制均保留。S0自2051出现缺供，不能把受约束导致的能耗下降全部称为效率改善。
