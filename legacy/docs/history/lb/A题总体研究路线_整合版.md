# A题总体研究路线与实施方案

整合日期：2026-10-17。依据赛题原文、《研究设计与讨论记录》及历次资料收集结果。本文区分已经讨论确认的路线、落地顺序建议和待定事项；不代表模型已经实现或实验已经完成。

## 一、总体主线

以中国大陆多能源系统为对象，暂用Python＋Mesa构建多智能体仿真，研究中国现实制度与国际环境共同作用下的能源转型。通过主体投资、生产、用能、替代与政策响应形成系统演化，评估2030年达峰及2060年碳中和目标的完成情况，并检验能源安全、经济成本与社会分配之间的权衡。

三问共用一套数据和模型：历史数据与现状评估 → 主体机制与历史校准 → 基准推演 → 对比情景与不确定性分析 → 对策再仿真。第二问集中建立模型，第三问仍需大量情景仿真、结果比较和对策检验，不另起一套互不关联的模型。

## 二、边界与平台

- 地理边界采用中国大陆，暂不建港澳台模块；这属于队伍的研究选择，不是组委会的正式解释。国际地区通过外部价格、供应、运输、贸易和技术条件影响国内主体。
- 不把台湾政治进程及相关企业能力纳入确定的基准假设，不预设重大地缘事件的时间和结局。
- 覆盖题目要求的煤、油、气、水电、核电、风电、光伏、生物质能、氢能，以及储能、输配和能源转换环节。一次能源、二次能源、终端需求分别核算，避免把发电燃料与电力、制氢电量与氢、储能充放电重复相加。
- 暂按Python＋Mesa执行。题目的多智能体是有属性、约束与行为规则的仿真主体，目前没有确定让大语言模型直接代替这些主体逐步决策。研究辅助子智能体与仿真中的能源主体是两回事。
- 问题一历史序列按题目建议尽量不少于10年。2024完整统计状态为初始化候选，2025数据经核验后用于更新或验证；政策资料目前收集至2026-10-17。最终历史校准期、验证期和未来起点须明确，历史重放不能使用当时尚未生效的政策。
- 全国总量与区域差异均需体现，但省级/区域聚合方式、主体数量、时间步长尚待定。先跑通全国年度平衡，再扩展区域差异，是当前实施建议。年度模型不能直接声称解释逐小时调度和短时停电。

## 三、三问的分工与产出

|问题|确定的研究工作|主要产出|尚待落实|
|---|---|---|---|
|一：现状评估|整理生产、装机、消费、结构、地域、进出口和价格，从供给保障、清洁低碳、经济性、协调性评估|历史数据表、趋势与区域图、短板及协同潜力，模型初始化依据|原表提取、价格年与单位统一、指标公式及权重；未锁定某种综合评价算法|
|二：目标预测|设计智能体、交互与约束，历史校准及验证，运行S0至2030/2060，分析敏感性|能源消费与非化石占比、排放路径、峰值与达峰时间、能源/碳强度、2060碳中和率及剩余排放|行为参数、校准/留出验证期、碳中和率定义、校准与敏感性方法|
|三：能源安全与优化|在同一模型上设置可比情景，定位风险薄弱环节，检验政策与协调措施|情景对比、成本与安全权衡、冲击交互、可操作对策|冲击幅度与恢复期、干预组合、优化搜索方法；不只凭文字提出建议|

碳中和核算必须说明覆盖范围。若仅模拟能源相关CO₂，不能把结果直接称为全国全口径碳中和；非能源排放与碳汇/移除如何衔接，仍需在核算方案中明确。

## 四、智能体与交互

|主体|核心属性与差异|主要决策|
|---|---|---|
|供能企业|技术类型、区域、资产年龄、效率、资金和保供约束|生产、投资、改造、退役；考虑预期收益、融资、建设和设备更新时滞|
|工业及运输用能主体|行业活动规模、能源结构、替代空间、设备更新周期|用能、节能改造、电气化及其他替代|
|居民代表群体|收入、基本用能、能源负担、设备条件和技术接受差异|消费调整、设备购买、清洁能源采用；不逐户模拟|
|电网运营者|区域输送能力、调节资源、扩容条件|跨区输送、扩容与调节服务|
|政府|政策工具、预算、目标和可观测反馈|制定政策、按预设规则调整支持与约束；中央—地方细分深度待定|
|算力中心运营商|位置、容量、利用率、效率、可调任务和建设条件|选址建设、购电、储能及任务调节|

碳市场、电力交易和国际条件可作为机制与环境，不必全部拟人化为独立智能体。企业所有制、保供责任等差异只有在资料支持时才参数化，不能套用刻板行为设定。

交互逻辑：政策与外部条件改变成本、收益及供给约束 → 主体调整生产、用能与投资 → 电网及能源市场在物理约束下协调 → 形成价格、能源平衡、排放、缺供、负担及就业变化 → 下一期主体更新预期和决策。具体调度、交易撮合、决策次序尚需写成正式规则。

机制至少要检查能源平衡、产能与输送上限、设备存量、储能能量/功率/效率、投资资金与工期、减排和移除能力。不得用预设目标反向强制每年排放满足达标路径。

## 五、中国现实、国际环境与社会维度

中国现实通过以煤为主的存量设备、区域资源与需求错配、设备寿命、电网约束、投资和建设时滞、现行政策及市场机制体现。基准碳市场必须按已取得政策原文确定分配规则，不能无说明地改成固定总量统一拍卖。

国际因素通过煤油气价格、进口来源和可用量、航运通道、运费、替代供应、汇率、贸易及技术获取条件传导。中东、欧美等地区的动荡和政策变化映射到这些可计算变量，不写成笼统的政治风险评分。已发生影响进入初态和路径；新增严重冲击在对比情景中设定，不擅自赋予现实发生概率。

AI既有新增用电需求，也有效率提升与潜在需求反弹。区分数据中心总体与AI部分、容量与实际负荷、PUE与IT利用率，不将算力指标直接换成唯一电量；从原有行业需求中拆出算力部分，避免双计。

社会维度保留居民能源支出/可支配收入、基本用能满足、岗位退出与转岗吸收、地区转型成本和政府支持支出。基本制度运行连续不等于居民与地区没有压力，不建立无法校准的笼统“社会稳定指数”。退出岗位不等于净失业，补贴等转移支付也不能重复算作全国资源成本。

## 六、基准S0

名称暂定“现行政策延续下的适应性发展情景”。含义是政策力度和技术趋势合理延续，同时主体持续对价格、约束与需求作出反应，不是全部变量恒定，也不保证双碳目标自动实现。

1. 政策按生效时间进入，既有安排和到期后的延续规则分别说明。目标、措施、仿真结果分开。
2. 经济、人口、城镇化、家庭与产业结构使用分阶段中性路径，需求由活动、结构、效率和替代共同形成。
3. 技术渐进改善，保留成本/效率边界、存量设备与建设时滞。
4. 国际条件延续当前状态下合理的适应和恢复路径，既不忽略现存影响，也不默认极端状态永久维持。
5. AI按中性扩张和效率演进路径，保留反弹的检验空间。
6. 正常天气变化、故障与个体差异保留，多次运行报告结果分布。
7. 社会与制度运行连续，居民负担、转岗和地区成本仍影响主体行为。
8. 碳汇与移除有边界、成本和能力上限，不能自动填平剩余排放。

以上原则已讨论，具体数值尚未敲定。

## 七、对比情景

|编号|相对S0的变化|核心问题|状态|
|---|---|---|---|
|S1 政策强化|调整配额、标准、支持等实际政策工具|减排收益、成本与居民/地区负担如何分配|框架确认，工具幅度待定|
|S2 外部供应与运输受扰|进口可用量下降、运输成本变化、替代上限与恢复期|库存、替代、需求调整和投资能否缓冲风险|框架确认；极端天气可作风险扩展，未与所有冲击一并锁定|
|S3 技术加速进步|储能、氢能、CCUS等成本或效率改善|技术改善能否跨过资金、电网和工期约束形成部署|框架确认，技术组合待校准|
|S4 AI快速发展|提高算力需求，明确效率和反弹假设|新增用电如何影响投资、结构与排放|主要创新实验|
|S5 AI与外部风险叠加|原样叠加S2、S4的单因素设置|联合影响是否具有放大或抵消效应|主要创新实验|
|S6 协调转型干预|在S5或预先选定困难情景加入需求响应、区域协调、社会支持等|相同冲击下哪些措施有效、代价多大|保留扩展，具体措施待薄弱环节识别后设计|

先实现S0—S3，满足基准＋至少三种对比要求，再完成S4—S5创新实验，视结果设计S6。政策强化下有无社会支持可做配对变体，额外财政投入单列；要比较设计优劣，还需同预算实验。

## 八、可比实验、验证与优化

各情景共享初始化、历史校准、核算边界、评价指标与时间窗口，只有情景参数表中列出的因素变化。不能为增强结果任意改变GDP、天气或其他背景条件。

S0/S2/S4/S5使用配对随机种子。对同一指标Y计算交互量：

`I = Y(S5) - Y(S2) - Y(S4) + Y(S0)`。

交互量正负的好坏由指标含义决定，不预设联合冲击必然放大。技术组合还需单技术/消融实验，以识别实际贡献。碳价若由交易内生形成，不能又作为同一期被固定的外生输入。

验证拟按以下顺序落地：检查守恒与极端条件 → 校准历史序列 → 在独立留出时期检验复现能力 → 多次随机运行 → 关键参数敏感性与不同假设稳健性检验。具体算法、误差阈值、样本量尚未确定。拟合好历史不代表长期预测必然准确。

评价保留能源结构与总量、排放与目标指标、系统成本、缺供量/率、进口暴露、居民负担和就业调整。综合评分可辅助，但不覆盖原始指标。政策优化优先比较可执行措施组合，记录预算、工期和能力边界，再用同一模型检验；未确定一定使用某种优化算法，也不预设某一组合必胜。

## 九、数据策略与现状

已有基础资料：多年能源生产/消费与装机、宏观人口经济、排放、成本技术、政策与市场原文等。近期补充了原油/LNG来源、国际通道与库存估计、管道气/煤炭贸易替代、算力资料、居民历史能源负担、9省区＋全国煤炭就业。原件、来源和部分结构化表已入库；报告下载完成不等于参数已经提取校准。

采用权威公开资料，并接受可追溯、信誉较好的行业机构和研究资料。每个参数记录变量名、主体、值/范围、单位、统计年与价格年、地域、来源及页表位置、处理方法、不确定性。数据标签区分统计观测、行业统计、文献估计、历史校准、情景假设。

具体限制：ScienceDB位置CSV/85GB包未取得；煤炭就业并非完整分省，转岗流量仍缺；居民账单主要是历史群体汇总；大陆AI专属电耗和任务迁移率未取得同口径观测；战略库存是外部估计而非官方可用库存。不同年份、地域、热值、煤种或港澳台边界不得无说明混用。

缺口先找替代，仍找不到保留为空、聚合建模或作为有依据的区间参数，不伪造精确值。CFPS审批不是当前模型启动的前提。

## 十、创新点与下一步

目前认可的创新重点是：异质主体的适应与投资时滞；AI需求与国际供应风险交互；转型成本在居民和地区间的分配；在相同冲击下检验协调干预。创新来自机制与可验证实验，不靠增加主体名称和情景数量。

下一步顺序建议：

1. 明确时间与空间粒度、校准/验证期、未来起点、碳核算范围。
2. 制作统一参数字典和S0—S5参数差异表，标明已有值与待校准项。
3. 跑通全国能源平衡、设备存量、排放和成本最小模型。
4. 加入区域及主体决策、AI和社会反馈，校准并验证。
5. 执行S0—S3，再执行S4—S5；据结果设计、检验S6和社会支持变体。
6. 整理论文、3分钟以内仿真视频、可运行代码与说明、原始数据及可复现预处理流程。

目前完成的是研究框架与多轮资料收集，尚未完成模型实现、统一参数校准、情景数值设定或结果验证。
