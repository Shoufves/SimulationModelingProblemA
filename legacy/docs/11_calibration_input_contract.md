# 真实历史输入与校准接入契约

日期：2026-10-17。用途：把已有历史转录接入模型前的工作具体化，避免等待所有数据或把单年核验扩大为全国历史验证。此文是接入方案，不是新的数据准入或校准结果。

## 已有文件如何使用

|模块/目标|已有候选字段|进入正式计算前的检查|可支持与不能支持的结论|
|---|---|---|---|
|总能源需求|energy_consumption_2015_2024：total_energy_consumption及四类结构|S01全表逐值、表头脚注、能源折算和历史修订；登记该用途准入|支持总量与结构目标；不能直接给出部门服务量、燃烧量或设备份额|
|宏观驱动|macro_growth_2015_2024：real_gdp_growth_pct|S06十年增长率与范围核验；2015=100，从2016增速开始链接|只能形成舍入后的近似实际GDP指数；不能当官方不变价GDP绝对额|
|供给存量|power_capacity_2015_2024：技术分项及other|S05原表与十年行核验；保留万千瓦原值，除100转GW；S17另版不覆盖|支持年末容量目标；需要投运/退役年龄与在建初态才能识别主体投资|
|发电/利用|power_generation_2015_2024：各技术|分年来源桥接；旧年solar保留null；年内平均容量另取依据|可核验字段可逐项用；不能用残差补光伏或年末装机拟全年容量因子|
|燃料与部门|煤油平衡候选及天然气2024子集|明确实物量/热值、国产与进出口边界、转换/燃烧/原料、库存和部门|只对完整且共同口径的账本验守恒；气体积不能与进口质量直接相加|
|排放与中和|当前缺少匹配的全边界输入|官方燃料因子及热值、燃烧活动、工业过程、捕集与移除分别准入|单有总能耗和煤占比不能生成全国CO2；缺工业过程或移除则不报全国中和率|
|运行窗口|附件部分项目字段及单年全国子集|负荷时序、技术可用出力、储能MW/MWh、线路和时间覆盖分别核实|项目样本可支持对应案例；不能用890条附件记录反推全国逐时供给|

候选文件路径均位于`data/observations/`；全表未准入时，不在`examples/`里换上候选值再改称真实回算。部分字段可以先提取有原行定位的子集，用对应review登记用途；其他字段仍保留候选状态。

## 分模块开展，不等待全部数据

1. 消费表和宏观表完成核验后，可以先做**给定实际GDP的总量条件回算**；只检验需求映射，不宣称完整ABM或前瞻预测。
2. 容量与发电字段完成核验后，可以另行检验供给存量、技术结构及发电映射；不要求先取得碳汇。无法识别工期、退役或销售预期时，用有依据的区间固定，并报告等效参数，不能由十个年末容量观测同时拟合全部规则。
3. 匹配的燃料活动量和排放参数到位后再增加燃烧排放误差；过程排放与移除补齐后才输出全国净排放和中和率。
4. 连续运行模块先接一个有据窗口。独立小时窗口与年度主体的耦合尚未实现，年权重、容量可用比例和运行约束反馈须另验收。

每个模块分别记录`ready_for`和`blocked_for`的用途。只有数据证据合格、模型覆盖该目标、运行输入齐全三项同时成立，才对相应目标开展正式校准。某一模块缺项不自动阻止其他模块开发。

## 固定训练与检验方法

沿用2015—2021开发/校准、2022—2024已接触的留出评估、2025单独核验。既有基线结果已被查看，不能称最终盲测。增加滚动起点检验时，预先固定起点、参数搜索范围和选择规则，并披露样本少和重复使用数据的限制。

运行前保存配置、目标字段、来源/准入ID、训练/评估年份、参数边界、固定参数依据、目标权重及代码SHA256。模型选择只用校准数据或该期内部检验；不根据2022—2024结果反复修改再称独立验证。使用未来实际GDP/天气/燃料价格的结果标明条件回算。

先拟合少量可识别参数。不同参数集若给出近似训练误差，全部保留为候选区间；报告参数边界命中、目标间冲突及机制关闭后的差异，不能只挑一条漂亮曲线。

## 输出和验收

正式结果保存在`outputs/calibration/`，仅在实际运行后创建；合成运行仍放`outputs/prototype/`。逐年按目标报告模拟值、观测值、单位、绝对误差和适用的相对误差；观测为0时相对误差设缺失，结构用百分点偏差。缺失观测不计入评分，也不插值成真实标签。

报告至少同时给出各目标误差及统一定义的汇总目标，避免仅靠总量拟合掩盖结构偏差。与同训练窗口的结构冻结、现有趋势/GDP映射基线比较，列出新增主体机制在哪些指标上有增益、在哪些指标上失败。

当前六个2024正式子集限各自横截面/口径用途；新增总能源与实际GDP增速两个10值历史子集仅限需求基线条件回算。实际结果见[回算入口](<../outputs/calibration/index.md>)，W5改为in_progress；原80值整表、其他结构/装机字段及全国ABM仍未验收。图片证据为在线原图核读后的明示文字摘录，未取得原图二进制或本地截图，限制随结果披露。

资产接口另有[秦山7台机组许可事件案例](<16_asset_lifecycle_case.md>)，对应附件4三条厂级记录。只解决机组身份和部分期限事件，不能把设计寿命或许可截止当作实际退役，也不能在精确MW缺失时参与容量汇总。该案例不扩大全国供给初态、投运年龄及经济行为的准入范围。
