## 1. 这道题研究什么

题名为“双碳背景下多种能源融合发展系统仿真与优化研究”。

核心任务是：建立能够反映不同主体决策及相互影响的中国多能源系统，用历史数据校准，在不同政策、技术和风险情景下推演至2060年，判断双碳目标完成情况，并比较能源安全和改进措施。

题目的能源范围包括煤炭、石油、天然气、水电、核电、风电、光伏、生物质能、氢能等。系统范围贯穿供给、输配、需求，并包括政策与市场环境。因此，研究边界不能只覆盖发电部门。

### 题面明确提出的要求

| 项目 | 要求及含义 |
| --- | --- |
| 历史数据 | 近年来的分能源生产、装机、消费、结构、区域分布、进出口、价格等，时间跨度建议不少于10年。“不少于10年”是建议措辞 |
| 模型类型 | 问题二明确要求设计多智能体仿真模型，交代主体属性、决策规则、信息交互和环境 |
| 校准与验证 | 使用问题一历史数据校准关键参数，验证能否复现历史演化趋势 |
| 基准推演 | 延续现行政策力度与技术趋势，预测2030年和2060年目标完成情况 |
| 情景数 | 1个基准情景，加至少3个对比情景，即至少4个情景 |
| 不确定性 | 对经济增速、技术成本下降速率、碳价等关键参数做灵敏度分析 |
| 安全与对策 | 建立能源安全评估框架，提出与仿真结论对应的可操作措施 |
| 交付 | 论文、3分钟以内视频、模型源文件或代码及运行说明、原始数据与数据说明 |
| 数据处理 | 来源、年份、统计口径可追溯；缺失处理、单位换算、价格平减等可复现 |

题面示例中的政府、企业、电网、工业、运输、碳市场，以及政策强化、极端风险、技术突破情景，均允许自行调整，并非必须照搬的唯一设计。

评分为论文70分、视频30分。论文中多智能体模型构建20分，仿真实验与结果分析20分，数据与模型验证10分。我们的工作重点应放在机制、数据、验证和实验，而不能只做现状描述与趋势外推。

### 已查实的数据问题

1. **缺少统计年份、数据来源及运行状态字段。** 无法确认装机属于哪个时点，是否在运、在建或规划。文件修改时间不能代替统计年份。
2. **能源类别不完整。** 没有光伏、生物质能、氢能的数据表，也没有煤炭、石油、天然气的生产消费和贸易表。火电名单不能代替煤炭产业数据。
3. **缺少时间序列。** 四个附件没有年度生产消费、发电量、利用小时、价格、排放、投资和退役序列，不能直接支持历史校准及长期预测。
4. **火电存在4组同名记录。** 金山电厂在第354/389行，容量600/660；唐山北郊电厂第438/441行；滦河电厂第439/442行；中电神头电厂第453/472行。后三组的名称、容量、位置相同。需核实是重复抄录、分期机组还是不同实体。
5. **水电存在5组同名记录。** 鲁布革第50/80行；天生桥一级第81/93行；天生桥二级第82/92行；平班第83/99行；天桥第127/193行。其中天桥对应位置不同，不能只按名称删除；跨省边界电站也应建立唯一项目标识，避免两省同时按全容量计入。
6. **常规水电表混入储能项目。** 第88行是蟠龙抽水蓄能电站，应单独分类。抽水蓄能的放电来自此前抽水用电，不能作为新增一次能源供应重复计算。
7. **地理字段需要核查。** 火电、水电和核电缺少省份及经纬度。抽蓄表第28行“张河湾”的location为井陉县而省市写山西省，第29行“潘家口”location为迁西县而省市写山西省，这类记录应查官方项目资料并核对坐标。当前未对原表作纠正。

9. **火电燃料结构未知。** 原表未标明燃煤、燃气、燃油、生物质或混烧，不能一律赋同一个煤电排放因子。
10. **坐标的基准和精度未说明。** 映射前应检查坐标是否落在对应行政区，并统一坐标系统。

### 4.3 未来情景假设

未来GDP增长、碳价路径、技术学习速度、进口中断幅度、极端天气持续时间、CCUS扩张、碳汇变化等，都需要基于公开资料设置假设及区间。它们不能标成已经观测到的“未来数据”。

### 4.4 数据准备安排：先集中收集，适用性检查同步

第4轮确定先形成可追溯的基础数据包，再开展模型实现及正式假设检验；第5轮按此执行，结果见第14节。不把“所有可能需要的数据全部收齐”作为启动后续工作的条件：区域划分、时间精度和部分行为规则尚待资料约束，最终清单会随研究迭代。

应区分两种检查：收集时的适用性检查只判断资料的变量、年份、单位、区域、口径和独立性是否可用；正式假设检验再结合模型、对照及验证评价H01/H02。取得数据只能增加检验条件，不能直接证明假设。收集时记录不符合预期的资料，不能仅挑选支持原方案的证据。

首轮按用途分三批组织，而非无差别下载所有资料：

| 批次 | 优先收集范围 | 应能回答的问题 |
| --- | --- | --- |
| 1. 全国历史与核算基础 | 第4.1节全国能源生产消费、装机发电、贸易、需求驱动、价格及排放；第4.2节主要效率、成本、寿命、建设周期和碳核算参数 | 能否确定共同历史窗口、核对基准年、约束基本投资与需求变化，并预留历史验证资料 |
| 2. 核心机制所需资料 | 省级供需与输送、项目投产和建设周期及延期证据、资产年龄或退出记录、终端替代、储能功率与能量、共同燃料供给、同期负荷和风光来水及风险事件 | 能否检验配套滞后和资源竞争，而非只做年度总量推演 |
| 3. 情景与可选细节 | 政策实施规则、技术发展和碳汇/移除的有来源区间；仅在必要时收集逐机组、逐线路及更细市场资料 | 能否定义可解释的未来条件；哪些细节值得增加，哪些暂不影响核心判断 |

第4.1至4.2节的P0/P1/P2是初步排序，不能理解为收齐P0即可证明核心假设。对H01/H02关键的部分P1及高频资料，应提前检查可得性，发现缺口后尽早调整可支持的结论。同期高频资料不必与全部年度变量覆盖同样十年，但不能用互不同时的序列冒充真实联合事件。

每项资料在本文件登记：变量及用途、关联的假设或核算环节、来源文件/表及版本、实际覆盖年份和区域、单位及边界、取得状态、局限和后续处理。原始文件与结构化数据可单独保存，研究解释继续集中在本文件。状态区分“只找到入口”“已取得原件”“已提取待核对”“可用”“存在冲突”“缺失/不可获取”；暂不可获取的说明已查范围和下一步办法，不直接认定现实中不存在。

历史观测、技术参数、待校准行为参数和未来情景条件分别登记。参数可以有文献区间，但不能把参数估计冒充直接观测；同源能源活动量核算出的排放不能当作完全独立的排放验证。原先优先收集2015-2025，第5轮实际取得的全国核心共同窗口为2014-2024；新年度资料单列，不为凑齐年份机械补值。

首轮完成条件是：基础变量已取得可追溯的原始资料并完成基本可用性检查；共同历史窗口和候选基准年明确；核心机制数据逐项判定可支持什么；剩余缺口均有处理决定。处理决定可以是继续补查、使用有依据的范围并检验影响、降低模型精度或暂缓对应结论。不能用任意假定的点值消除关键缺口。

因此，本阶段的交付是“可用基础数据 + 覆盖与口径检查 + 缺口及处置”。第5轮已实际形成这一交付；未完成的高频、行为、区域细节和净碳核算由缺口决定约束后续范围。

## 6. 建模前必须统一的统计口径

### 时间及政策基准

本轮全国核心年度变量的实际共同窗口为2014-2024，共11年；2024为候选全国基准年，2023用于详细能源平衡和部门数据检查，2025为部分更新核对。三种年份角色分开，不把2023细账或2025储能直接标为2024实测。

2024候选基准目前只覆盖全国主要年度规模，尚非完整可运行的区域初始状态。正式未来情景的起算时点需经2025补充资料和政策生效时间衔接后确定。2026年截至10月17日尚非完整观测年度，月度累计不能冒充全年实绩；2026年新政策不能提前写入2014-2025历史回放，再称其为真实历史验证。

若比较2030碳强度目标，已取得的2005年可比GDP和GCB排放可作核对入口，仍需匹配政策核算边界。前瞻政策信息集截至2026-10-17，文件及生效时间分别记录；政策目标不等于实施力度。

### 能源量与结构

- 装机容量是kW/MW/GW，发电量是kWh/MWh/TWh，二者不能直接互代。统一换算：1GW=1000MW，1TWh=10亿kWh。
- 煤、油、气先保留实物单位，再按来源口径换算为热量或标准煤。天然气要检查“亿立方米”和LNG质量单位。
- 一次能源消费与终端消费分开；煤发电后产生的电力不能再与全部煤耗简单相加，否则重复计算。
- 官方非化石能源消费占比涉及折标口径，应沿用同一统计口径，不能随意拿固定电热当量重算后与政策占比比较。
- 非化石能源消费占比、非化石发电量占比、非化石装机占比，是三个不同指标。
- 官方统计公报中的“清洁能源”包括天然气，不能替代“非化石能源”。例如S2的2025年清洁能源占比30.4%不能直接填入非化石能源占比。
- 火电与煤电分开；常规水电与抽水蓄能分开；“太阳能发电”与“光伏发电”也要检查是否包含光热。
- 容量因子或利用小时要明确分母。用年末装机估算全年利用小时，会受年内新增装机影响，宜核对平均在运容量或直接采用官方利用小时。

### 碳排放与目标

- 主表明确是CO2还是CO2e，是能源活动还是全经济，是毛排放还是净排放；不同口径不直接拼接。
- 能源强度使用能源消费/可比价GDP；碳强度使用同边界CO2/可比价GDP。部分公报节能考核值扣除了原料用能和非化石能源，不能直接等同于模型总能耗/GDP。
- 全国中和判断需包含非能源排放及碳汇/移除模块。若只做能源系统，应明确输出“能源系统净排放”，不能据此单独宣称全国已中和。
- CCUS捕集后若已从排放中扣除，就不能再把同一捕集量计作负排放扣除。生物质、绿氢和森林碳汇也应依据明确边界核算。
- 题面没有给出“碳中和率”公式，我们需自行定义并说明。可采用`碳中和率=同边界净移除量/减排措施实施后的剩余正排放量`，同时报告`净排放=剩余正排放-净移除`；分母为0时单独处理。
- 达峰应根据整条排放路径和后续持续变化判断。某一年下降不能直接判定已经稳定达峰。

### 贸易、价格与区域

- 进口依赖率要说明分母是表观消费还是统计消费。表观消费通常由生产、进口、出口及库存变化构成，不应把库存忽略而不说明。
- 原油、成品油和其他油品分开，LNG与管道气分开后再统一单位。海关“收发货人注册地”不是实际能源最终消费地。
- 进口金额/进口数量是进口平均单价，不等于国际现货价或国内终端价。不同热值煤种的元/吨价格也不可直接比较。
- 成本使用统一基年实际价格，并选适合的平减指数；GDP用可比价。保留美元/人民币转换的汇率年份。
- 分省数据可能有覆盖和分类调整，尤其能源平衡表，需逐版核对；某个数据库只含30省时不能直接标为全国31省。
- “缺失”“零”“不适用”分开存储。政策年份、灾害年份、关键排放值不应机械插值。

## 8. 初步模型：主体决策、实际运行和长期变化相互反馈

### 8.1 第一问：先建立能够解释差异的现状评估

按能源品种整理历史变化和区域分布，分别评价四个方面：

| 方面 | 优先考虑的可解释指标 | 使用边界 |
| --- | --- | --- |
| 供给保障 | 国内供应、进出口依赖、供需差额、可用调节能力 | 石油进口依赖与风电出力波动的含义不同，先分别分析 |
| 清洁低碳 | 同口径排放、非化石占比、单位能源服务排放 | 区分消费结构和发电结构，不把全生命周期与直接排放混在一列 |
| 经济性 | 燃料、设备及运行成本，价格波动 | 明确基年和费用边界，不只比较发电成本而忽略配套 |
| 协调性 | 资源与需求空间差异、弃风弃光、灵活性与输送约束 | 只采用数据能支持的量，未获得的能力不设为零 |

第一问先给出分项证据。若后续确需总分，再采用公开权重和替代权重做稳健性检查；不预先让某套权重决定哪种能源最好。

第7轮将其具体化为第16节的“原始指标、固定参照标准化、四维分数、可选综合分”模型。缺失时不逐年改变指标或权重；各能源角色诊断与全国综合评价分开。

### 8.2 系统范围与粒度

以全国为总体，暂划分为约6个区域，每个区域由相邻省份组成，分组待U02解决。主体按区域和技术/用途聚合，不要求将每一座电站都建成一个主体。附件项目可帮助核对区域结构和代表性属性，全国规模由同年份统计约束。

主要能源转换链保留为：煤油气供给与进口进入发电或直接终端使用；水、核、风、光、生物质形成电力及必要的直接利用；电力/燃料通过设备提供工业、交通、建筑和其他部门的能源服务；储能和制氢消耗上游能源后提供可用输出。石油加工先保留可核对的转换和损失，非能源原料用途单列。

第3轮收紧范围：这些能源都保留在全国核算和情景中，但不要求首版对每一种能源的所有企业各拟合一套行为。行为细化优先服务于共同燃料竞争、发电与配套投资、终端设备替代。水核等长周期项目可先由有依据的在建队列和情景边界描述，后续有资料再细化申请和决策；输出时区分外部路径与内生反应。区域数量由供需关系和数据决定，不能为了地图整齐固定为6区。

氢能暂只进入有技术与数据依据的用途，显式区分化石制氢与电解制氢及其排放。生物质需受原料可获得量约束，不直接赋予无限供应或完全零排放。CCUS计入成本、能耗及净减排，同一捕集量只扣一次。

### 8.3 主体具体怎样做决定

| 主体 | 观察什么 | 暂定的透明决策规则 | 不能省略的限制 |
| --- | --- | --- | --- |
| 煤油气供给主体 | 历史销售、库存、价格、进口条件 | 满足合同和库存目标，依据预期收益安排下一期供给与能力调整 | 国内产能、进口和通道上限、库存可用量 |

| 工业、交通、建筑等用能主体 | 活动需求、服务成本、设备年龄、可用技术 | 节能与能源替代按设备更新和可承受投入逐步进行 | 刚性服务需求、改造上限、技术适用范围；短期缺供显式记录 |
| 电网和储能运营主体 | 区域供需、现有输送能力、连续时段运行条件 | 分配供给、安排充放电和跨区互济；按历史拥塞与缺口提出后续扩容 | 输送容量与损耗、储能功率和能量、运行时可获得的信息 |
| 政府 | 已发布政策、观测到的排放和安全指标 | 基准情景采用有依据的实施规则；改进情景再比较触发式配套和退役政策 | 政策和建设存在时滞，不自动获得2060年的未来信息 |

首版不必额外建立一个复杂碳市场主体。将碳价和适用规则作为环境输入，并如实说明碳价不是模型内生结果。实际碳成本还取决于覆盖范围、配额和交易安排，不把所有主体的排放乘碳价都算作其现金支出。

企业收益还需要明确结算规则。首版电价采用可追溯的价格路径，结合可核对的合同安排和有限成本传导；暂不声称完整复现现货市场。供需与拥塞首先通过销售电量、利用率、弃电和实际成本影响投资，价格反馈在有资料支持的范围内加入。求解器给出的局部边际值只作瓶颈诊断，不能直接充当企业实际收到的电价。

企业之间的差异优先来自地区资源、技术、资产年龄和可核对的费用，而非为制造复杂性任意随机化。投资依据过去和当期信息形成预期，不能把仿真中未来的天气、价格或政策轨迹提前告诉企业。

第3轮补全投资到产能的链条：先根据当时可知价格、合同和可利用小时估计收支并提出项目；再依据资金、建设能力及接入条件筛选；仅通过的项目按支付和建设进度进入队列；投产后才能改变供应。多个主体争用同一接入或建设额度时，要有公开且固定的处理规则，并检验该规则是否影响结论。若项目收益不足，只有明确的补偿、合同或政策义务及其资金来源能够支持其继续实施，不能用未计费的“政府支持”让其自动落地。

退役也不能只由负收益决定。应区分实际停产、备用保留、获准延寿和永久退役，并计入相应成本和可用率。永久退役后不能在下一轮自动恢复。承担供热或工业自备服务的容量退出时，替代服务必须进入同一账本。资产年龄和运行状态未核实时，只能研究聚合或区间情景，不能给附件中的具体电厂下退役结论。T9也说明了不同机组服务和年龄对退役安排的重要性。

### 8.4 每一年的计算顺序

1. 按建设队列和设备年龄，更新当年可用产能、到期资产及期初库存；本年新作的投资决策只在建设完成后生效。
2. 政府和外部环境给出当年已知政策、经济活动、贸易条件及价格信息；用能主体据此形成服务需求和设备使用方案。
3. 供给企业、电网和储能在既有能力内完成各代表时段的供需分配，记录缺供、弃电、燃料、费用和排放。
4. 按代表时段的时间权重汇总年度量，核对能源和碳账目；实际能量统计与政策占比统计各用其适用口径。独立压力检验的损失不直接混入常规年收益；若情景规定该年发生事件，须替换对应时段并核对全年权重，计入后续实际库存、收益和响应。
5. 主体观察收益、服务成本、拥塞和供给缺口，更新下一期预期，并分别决定后续投资、设备替代、扩容与退役申请。
6. 记录每次关键决策的主要原因，以及相关资金、能力和政策限制，进入下一年。

同一阶段的主体先依据同一份旧状态提出决定，再统一更新，防止代码执行顺序让某个主体获得不合理的信息优势。市场分配有共同资源约束，不能让工业和电厂同时重复使用同一份天然气供应。

### 8.5 运行层如何保持可落地

先用四季各一段连续代表周表达常规运行，再单独加入有依据的连续风险事件。代表周应尽量保留同期负荷、风光和来水的共同变化，权重与全年小时数和年度统计量核对；压力事件单独报告，不因缺少概率资料而随意赋年发生概率。

第3轮限定：四个代表周还不是已验证的充分运行样本。正式比较至少对所关注的连续缺供过程进行更长时序复核，数据允许时在选定年份使用完整年度时序。常规周可用于估算年度费用，连续事件用于条件安全评估，两者不能仅靠乘权重相互代替。没有事件概率时，只报告“在该事件下未供多少、持续多久”，不报告概率意义上的期望缺供或把每年都遭遇极端事件作为默认值。T10提示，输入序列平均误差小也不保证模型结果准确。

短时储能记录每小时充放电和存量。代表周首尾状态采用明确约束，避免凭空取得期初能量；风险事件从一致且合理的事前库存开始。季节间储能及大水库跨季节调度暂不据此推断，需要更长连续时序后才能评价。水电至少受对应季节的可发电量约束。

煤油气库存同样需要连续扣减和补给约束；对每个代表周重新给满库存会产生虚假的保供能力。供热需求、煤电可调出力和爬坡近似若可能影响H01，应纳入所研究的运行限制或给出保守范围；缺少这些约束时不能解释为完整灵活性收益。

运行分配优先采用线性约束：供需平衡、发电上限、燃料供应、跨区输送、储能存量和可调需求等。缺供作为明确变量保留，不让模型用不存在的供给强行凑平。先满足预先说明的保供优先级，再比较可行运行方案的费用；优先级本身需要依据和敏感性检查。

求解器只处理给定资产下的短期分配，不能同时替所有企业规划未来35年的最优投资。运行信息窗口也需明确：完美预知天气只能作为调度能力参考上界，正式风险评价应检查短预测窗口或信息延迟下的变化。是否需要滚动调度由U03的数据条件决定。

电网先用区域间可传输量近似，不求完整电气潮流。若出现不合理的同时充放电、循环输送或其他数学可行但物理不合理的行为，先检查费用和约束，必要时增加互斥条件。不能把简化运行模型的结果写成全面电网稳定性结论。

### 8.6 为什么这仍是多智能体模型

电价和燃料条件改变用户与企业的收支；企业投资形成未来产能，影响利用率、拥塞与弃电；这些运行结果再改变下一轮投资、用能替代和配套扩容。各主体目标和约束不同，系统路径由其交互产生。

需保留的解释链是“哪个条件变化，哪个主体因此改变什么决定，形成什么物理变化，最后影响哪个指标”。仅把几组宏观方程分别命名为智能体，或由一个全知规划器统一决定所有长期行为，不足以体现这里要研究的交互。

## 9. 初步特色与可检验实验

### 9.1 收窄后的研究问题：转型与配套速度何时出现不匹配

上一版“研究投运和退役顺序”范围较宽，也不能凭这一表述证明新意。第3轮将H01细化为：在具体能源结构、需求和冲击条件下，终端替代/供给退出速度相对于配套投运滞后，何时使转型的安全表现改善、恶化或无法同时满足成本与减排要求；能否从可观察条件中提早识别这种变化。

拟先用两个可解释的变化方向组织实验：一是替代或退出的速度，二是配套建设的延迟。其余条件逐组固定或作有依据的变化，寻找结果的适用区间，而非强行拟合一条通用阈值。区域燃料依赖、服务需求和输送能力用于解释差异。若边界随合理的参数或行为规则大幅漂移，就报告不确定区域，不能包装成确定的政策阈值。

候选改进规则是：利用当时已知的需求、建设队列和事先规定的压力条件，提前检查配套投运前的缺口；比较缓解措施及其实际完成时间，再评估后续退役与替代节奏。已经发生缺供后才启动多年建设的方案不能被写成事前预防。延期退役需满足设备及许可边界、承担保留费用并显示额外排放；不允许无限延期将风险推到2060年之后。

基准预测不强制达到碳目标。筛选改进措施时，才在明确的政策预算、减排或累计碳边界、相同能源服务要求下比较安全表现。若没有方案同时满足这些条件，输出冲突和可行性不足，而不是放松某个条件后继续宣称方案成功。全国总缺口下降还应检查是否将缺口转移到另一地区或用途。

具体按四步设计：先识别缺供受发电功率、连续可用能量、共同燃料供应还是输送能力限制；再分别小幅增加可建设的储能功率/时长、输送或可调需求，检查缺口实际减少多少；在共同预算和减排边界下比较少量可行措施及必要的两项组合；最后把可落实的投运时间反馈给退役与投资决策。约束恰好达到上限只能作为线索，需通过改变条件后的结果确认其作用。单项措施无效也可能是另一项约束同时存在，不能因此直接排除互补组合。

规则制定与效果检验分开：用一组事前确定的压力条件选择阈值和措施，再用未参与选择的事件、强度及恢复过程检验。主体在当年只能使用当时已有的事件资料或事先规定的压力边界，不能根据未来实际冲击倒推最佳措施。

例如，沿海区域电气化提升后，燃气同时承担工业和调峰需求。如果进口气受限且同期风光偏低，电力替代与燃气调峰可能争用资源。我们希望检验储能、可调需求和跨区互济是否改善该问题，以及改善来自什么条件。这是机制示例，不是对具体地区已经发生情况的断言。

### 9.2 如何避免把投入更多误写成策略更好

设置两类互补实验，不混用解释：

- **固定项目集合的顺序对照。** 固定同一批建设和退出项目、技术参数、初始资产及建设限制，只改变合法时序。按共同基年核算投资、运维、燃料、备用保留及期末剩余资产价值。时序改变本来就可能改变折现成本和期末资产状态，将这些作为结果，不同时强制相同项目、相同投资现值和相同期末状态。该实验隔离给定项目下的顺序作用，投资计划是实验给定值。
- **完整主体响应的政策对照。** 主体按照规则自行投资和调整，在相同政策预算边界、外部冲击和初始状态下比较。此时期末装机可能不同，差异是政策和行为的共同结果，不能全部解释为时序效果。

同时报告累计排放、2030/2060状态、缺供与实际资源成本。碳税、补贴、购电支出等既用于主体收益，也要与全系统资源成本区分，避免内部转移支付重复计入社会总成本。

对照至少包含：固定日程、按费用排序、以及“先核对可用替代服务再退出”的透明保供规则。最后一种对照用于避免只击败一个明显不合理的急退方案。各规则获取相同信息，具有相同候选措施和实际实施限制；阈值选择使用相同的数据范围。候选新规则若无法相对这些对照取得稳定增益，应接受其没有额外价值，而不是不断削弱对照。

### 9.3 联合压力是否暴露被单一情景掩盖的问题

H02采用四组配对实验：无冲击、仅进口受限、仅天气压力、两者共同发生。相同初始条件下检查联合缺口与单独缺口之间的差异，追踪是否经过燃料竞争、输送拥塞、储能耗尽或需求替代传导。

第3轮修正归因：设一个没有跨能源耦合的简化电力系统，备用为10MW，两种冲击各使供给减少6MW。单独冲击时都没有缺供，共同发生时却缺2MW。这一手算反例表明，联合缺口超过单独缺口之和，可能只是跨过供需平衡边界，不能单凭它证明跨能源传播，更不能据此宣称创新。

因此将四组实验的差异先称为“联合效应”。机制解释还需查看共同燃料分配、跨区流量、储能耗尽和用户替代的过程，并设置明确的机制对照。例如冻结事件后的用能替代响应，保留同一事件前资产、服务要求和燃料总供应，比较结果差异。不能通过额外提供无限天然气来“关闭耦合”，因为那同时改变了资源条件。改变机制而同时改变初始条件或服务要求的对照，只能作综合情景比较，不能给出单一机制归因。

风险传播先在同一资产状态上比较，后续投资和政策响应另行打开；否则短期物理影响与长期主体适应混在一起，难以说明是什么造成差异。

天气冲击的时段和幅度尽量来自可同时发生的历史记录或明确的压力边界。不能将各地区各自最极端的独立观测随意拼接，再声称这是具有已知概率的全国事件。若资料不足，结果限定为条件压力测试。

### 9.4 创新性目前能说到哪里

第3轮复核认为：上一版提供了合理的研究框架，但仅凭现有表述，创新性还不够有力。已有研究覆盖以下邻近内容：

| 既有内容 | 核对依据 | 对我们的约束 |
| --- | --- | --- |
| 优化与多智能体解释技术变化 | T6 | 工具组合不能单独当成创新 |
| 条件变化触发后续行动和行动顺序 | T7；其案例为水管理 | 只能说明通用思想已有，不能把触发规则本身声称为新方法，也不能据此认定能源问题已完全解决 |
| 电气系统耦合风险及规划改善 | T8 | “耦合导致风险传播”和“加配套改善风险”不能单独充当新发现 |
| 中国煤电差异化退出、电气化与退煤时间组合、机组退出与改造 | T9、T12、T13 | 退役及转型时间组合已有接近研究，需明确本题不同的变量、机制和可验证结论 |
| 时间聚合、储能连续性与极端事件 | T10 | 代表周加压力事件属于应做好验证的方法选择，不是创新承诺 |

候选贡献收敛到三个可交付对象：转型速度与配套滞后的条件性结果图；由资源流和主体响应支持的解释；使用当时可获得信息、能够与合理保供对照比较的改进规则。提出这三个对象仍不保证原创性或效果。具体文献差异和实验结果支持不足时，应缩小原创主张，不能通过改名或增加技术数量弥补。

创新性下一步的判断依据是：相对最接近的研究，问题和机制差异能否明确说清；相对合理的固定日程和保供对照，是否有可重复的增益或此前未解释的失效条件；在替代参数、行为规则和时序精度下，这个结论是否仍成立。仅绘出一个二维结果图或换一批中国数据，不自动满足这些条件。

可以采用有引用的核算方法、物理约束和求解库。主体规则、区域设定、实验和解释需要自行推导并留下依据，不复制他人的整套模型、参数、图表或结论，也不为追求形式新颖而改写已知物理规律。

## 10. 三问的解题与验证安排

### 10.1 第一问与历史校准

数据准备按第4至6节执行，形成分项现状评价和区域差异解释。模型自由参数先保持少量，例如需求对活动量的反应、投资调整速度、设备替代速度。资产寿命、效率、建设周期等优先由外部资料约束，避免每个地区、每种技术都自由拟合一套参数。

按本轮全国共同窗口，候选划分为2014-2020校准、2021-2024时间留出；2025具备字段另作更新检查。这是尚未执行的验证设计；价格、区域、部门及机制观测不能自动沿用同一覆盖声明。时间留出和来源独立是两件事，同源数据即使按年份留出，也不因此成为独立观测。能源、装机、消费结构和排放同时检查，不能只拟合一条总排放曲线。

如果只有十余年高度相关的年度观测，更多的参数并不意味着更多的信息。对无法识别的参数使用有依据的区间，比较多组同样能解释历史的参数是否支持同一政策结论。长期预测能力不能仅凭历史拟合好宣称已获验证。

第3轮增加结构检查：不仅改变参数，也比较少量同样合理的行为规则，例如收益驱动的项目申请与受到同样融资/接入限制的计划增长规则。若两种规则都能解释历史，却对H01给出相反结论，结果应表述为依赖机制假设，而不是选择更支持预期的一种。历史总量吻合只能约束模型，不能独自证明每个主体的决策机制正确。T11支持把模型用途、结构假设和验证作为贯穿研究的共同问题。

### 10.2 第二问：基准推演和目标评价

在历史验证和账目检查通过后，基准情景从可核对状态逐年推演，输出题面要求的能源总量、非化石占比、CO2路径、峰年及峰值、强度降幅、2060剩余排放和定义清楚的碳中和率。

政策实施规则作为输入，政策目标作为结果比较基准。不能预设2030达峰、2060净零后再判断模型预测达标。若排放仅短暂下降，或峰值出现在仿真终点附近，需说明达峰判断的不确定性。

能源系统排放是模型主要解释对象；全国CO2结果还依赖A07的非能源排放和移除路径。CO2结果不能直接替代全温室气体净排放目标。低、中、高外部路径应给出条件结果；只有具备概率依据时才报告概率意义的区间或达标概率。

### 10.3 第三问：情景、能源安全和措施比较

| 情景 | 相对基准改变什么 | 需要解释什么 |
| --- | --- | --- |
| 基准 | 有依据的既有政策实施与技术趋势 | 当前路径的减排、保供和成本 |
| 政策强化 | 有效碳约束、节能或配套激励 | 收益与成本通过哪些主体传递，是否出现区域差异 |
| 极端风险 | 指定时段的油气供应或天气压力及其持续与恢复 | 缺口出在哪里、是否转移、多久恢复 |
| 技术突破 | 有依据的储能、氢能或CCUS成本/效率改善 | 是否真正改变投资和供给，而非只降低一个账面价格 |

题面至少4个情景；为解释H01/H02，另安排前述顺序对照与单独/联合冲击实验。情景变化有明确参数、年份和来源，比较时共享未改动条件。

安全评估先看硬指标：各类能源服务缺口、缺供持续时间、可用储备、进口依赖、输送约束和恢复情况，再观察成本、排放和结构。电力短缺与燃料短缺先按各自单位报告，只有映射为一致的未满足服务后才合并，不能直接相加MWh与吨油。

优化先比较数量有限且可解释的政策组合，如配套投资比例、需求响应、进口来源分散、储备和退役节奏。剔除明显不可行或在成本、排放、安全各方面都更差的组合，再按目标约束选择。首版不需要把所有参数交给大规模黑盒搜索，也不把单一综合评分最高当作唯一正确方案。

第7轮具体参数化见第19节：主情景为基准、碳约束强化、气源受限、天气压力、气源与天气联合、储能降本；在共同预算与排放边界下，用模型逐个评估有限政策组合，形成成本、排放和缺供之间的可行取舍。正式幅度尚待资料约束。

### 10.4 通过哪些检查才允许形成结论

1. **核算检查。** 能量、库存、转化损耗、建设队列和碳扣减都能对账；缺供不被隐藏，退役设备不再提供出力。
2. **历史留出检查。** 与简单持续趋势等基线比较，并记录历史预测误差及验证数据是否独立。可比指标的容许误差根据来源精度和用途预先确定，不在看到结果后放宽。
3. **机制检查。** 改变一个条件后，能追踪到相关主体与物理状态的反应；不存在利用未来信息或执行顺序制造的收益。
4. **去除机制的对照。** 例如固定投资响应或取消配套触发，看关键结论是否依赖该机制。若去除后结果不变，就不能把效果归因于它。
5. **近似和结构检查。** 改变区域划分、代表时段、预测窗口、期初库存及少量有依据的行为规则，检验策略排序是否稳定。不稳定时结果留在exploratory results，并修改A01/A02/A06等。
6. **不确定性检查。** 对经济、燃料、技术、碳价和行为参数作有依据的变化；各方案使用相同外部样本配对比较，报告无效或反转条件。

某项检查失败，先定位数据、实现、近似或机制中的原因。通过数值求解不等于符合实际，历史拟合通过也不等于2060预测已被证实。

### 14.4 已发现的口径/质量问题与处理

1. 年鉴“原煤产品产量”2023年为47.23亿吨，煤炭平衡表生产项为45.4124亿吨。两个原值和表名均保留；原因待查，不把差异自动记为损耗，也不择一覆盖另一表。平衡表公布的统计残差同样保留。
2. 统计局标准煤核算、OWID一次能源替代法、电量和燃料实物量不可直接拼接；2023行业表中能源转换、嵌套部门及原料用途需单列。一次电力及其他、清洁能源、非化石三种名称不能互换。
3. 原负荷有重复HB表头，已按原表省份顺序及缩写表建立显式河北HE/湖北HB映射；原件不改。该序列由作者重建，地域和形状仍需后续核验。水库CSV年组无年份，未猜年、未插值，也未加载未获取的日来水文件。
4. 输电工作簿HVAC表含可识别的直流通道实例，交直流标签疑似反置。原标签保留，候选全表隔离；不凭此自动交换标签或把名义GW作为同时安全传输能力。
5. 新版世界银行价格工作簿封面含比较/编辑说明，不能仅凭下载域名就认定是干净原版。候选数值保留供版本比对，但禁止直接校准；稳定旧版只到2020，两条替代端点本轮连接失败。国际参考价也不代替中国到厂/合同价。
6. 2025年WDI汇率为7.18984737402171元/美元，统计公报为7.1429元/美元；两者分别保存并登记warning，原因未定。涉及2025价格换算的选择暂缓；本轮未进行币种转换或用CPI平减设备成本。
7. 年鉴转换总效率2019起排除煤炭洗选；发电及供热效率不能赋给纯发电煤/气机组。国家能源局风光“利用率”不是发电容量因子，2024光伏886GW与太阳能约887GW也不是同一类别。
8. 福清资料网页标示2015发布而内容含2022状态，是后续更新页面；不能作2015决策者已知信息。机组完成试运行、具备商运条件和正式商运日期有区别；白鹤滩首机投运也不等于全容量投运。
9. 天然气新增储气能力不是可用库存，表观消费也不自动等于终端消费；氢能分来源数为近似量，绿氢产能不等于产量。2025新型储能不含抽蓄，GW与GWh都不能决定事件开始时可用能量。
10. GCB是化石与工业毛CO2边界，电力平均因子用于消费分摊不重复计入全国排放；森林蓄积目标不是年度碳汇。未取得独立净移除路径前暂缓全国净零和全GHG达标结论。

“隔离”指保留原件及候选提取值，并用status/eligibility标识限制；后续读入时必须按字段筛选。当前processed不是已批准的完整模型参数库。data_quality_checks的0个error只表示已执行项目没有阻断性失败，不能替代上述来源和适用性判断。

## 16. 问题一：四维定量评价的数学模型

### 16.1 先确定评价对象，避免把不同角色混成一个排行榜

评价分两层：全国能源系统按年份给出四维表现；煤油气、各类电源和氢等分别给出自身作用、优势、限制及协同关系。油气进口风险、风光波动、储能移峰能力不是可互换的指标。全国综合分只用于同一系统在可比年份/口径下的比较，不用于宣称某种能源在所有用途下最好。

固定同一组指标、同一参考上下界、同一组权重后再比较。先报告原始数值及变化，再给维度分数；总分为辅助输出。当前经济性和协调性有缺项，不能仅因公式齐全就强算全国四维总分。

### 16.2 候选指标、公式与现有数据能支持的范围

| 维度 | 指标及计算形式 | 解释及数据条件 |
| --- | --- | --- |
| 供给保障 | 分燃料净进口依赖d_f=(M_f-X_f)/C_f | C_f采用同边界公布消费量；净出口可为负，原值保留。只有表观量时需明确生产+进口-出口-库存增加及转换边界。现有平衡检查点可先算对应年份 |
| 供给保障 | 进口来源集中度H_f=sum_o p_{fo}^2 | p为同种燃料各来源国进口份额；来源国数据缺失时暂不计算，不用不同能源消费份额替代 |
| 清洁低碳 | 官方同口径非化石消费占比n_t；碳强度c_t=E_t/GDP_t^real | 非化石占比不等于非化石装机占比；E边界必须一致，GDP用可比价。现有官方统计、宏观及排放清单可支持部分核对 |
| 清洁低碳 | 能源强度i_t=C_t^energy/GDP_t^real | 兼具效率含义，但产业结构也会影响；不把它直接解释成设备效率 |
| 经济性 | 同边界实际能源支出/服务量；同一价格序列的滚动波动v_t=std(log p_tau-log p_{tau-1}) | 先做燃料/服务分项，价格须统一币种与基年；同长度窗口可比。当前国内交付价和干净新版价格不足，此维度不补任意点值 |
| 协调性 | 风、光分项弃电率c_k=弃电量/可发电量 | 只有原来源“利用率”定义确为已利用/可利用电量时才用1-利用率；绝不把容量因子当利用率 |
| 协调性 | 电力区域供需空间差异m_t=0.5 sum_r abs(G_rt/G_t-D_rt/D_t) | G为同年发电量，D为同年用电量；数值越大表示越依赖跨区连接，不直接等于供电不安全。分省同年发电资料未齐时暂缓 |
| 协调性 | 储能功率/峰荷、储能能量/日均用电等诊断量 | 需同年、同区域及明确抽蓄边界；功率和能量分别报告。是否进入评分需先给参考需求，不能默认储能越多越好 |

第一问的保障评价以已观测供应、贸易等为基础。第17节算出的未满足服务和第19节压力事件恢复过程属于问题二/三结果，不能伪装成问题一已观测历史指标。

为避免重复计权，碳强度与能源强度、进口依赖与自给率等高度相关指标不能全都无说明地加满权重。先按含义去重，再用共同历史窗口检查相关性；短样本相关性只作线索。每个维度宜保留少量有独立解释价值的指标。

### 16.3 固定参照标准化与分层加权

设原始指标为x_jt，事先给定参考下界L_j和上界U_j。正向指标越大越好，负向指标越小越好，统一得到z_jt：

$$
z_{jt}=
\begin{cases}
(x_{jt}-L_j)/(U_j-L_j), & \text{正向指标},\\
(U_j-x_{jt})/(U_j-L_j), & \text{负向指标}.
\end{cases}
$$

参照优先采用有解释的物理界、统计标准或政策参照；没有合适外部界时，才使用事先固定历史窗口的最小/最大值，并标明“相对历史评价”。U_j=L_j时该指标没有可比较变化，不除零、不随意赋满分。展示分数可限于0至1，但同时保留未截断值和超出参考范围的标记。

第d个维度和可选总分分别为：

$$
S_{dt}=100\sum_{j\in J_d}w_{jd}z_{jt},\quad
\sum_{j\in J_d}w_{jd}=1;\qquad
S_t=\sum_{d=1}^{4}\alpha_dS_{dt},\quad
\sum_{d=1}^{4}\alpha_d=1.
$$

候选基准为四维等权alpha_d=1/4，同一维度的非重复指标等权。它表示公开、可检查的价值选择，不表示从数据“证明”了各维同样重要。再改变权重并报告短板识别是否稳定。首版不以熵权或TOPSIS作为必须步骤：统计波动大小不自动等于政策重要性，多加算法也不能补齐缺失资料。

若某维指标缺失，保留n.a.并报告覆盖；不把缺失当零，也不逐年对剩余指标重新归一化。允许另建“共同可用指标子集”的固定口径结果，但须标注子集，不能与完整指标分数混比。引用同一来源的不同变量不等于独立证据。

### 16.4 计算示例、权重检查与具体产物

纯算术示例：假设某燃料依赖率参考范围为0至80%，某年为40%，其负向标准化值为0.5；非化石占比参考范围为10%至30%，某年为20%，其正向值也是0.5。两个0.5只表示各自参照位置，不说明二者对社会的重要性相等。示例范围不是本题拟定的正式阈值。

权重检查可以先依次把某一维权重从0.25调到0.40，其余三维各为0.20，再检查原始短板和年份顺序是否变化。这个范围是价值偏好试验，不是统计置信区间。如果排名随合理权重明显改变，结论应以分项差异为主。

实际Python步骤是读取可用数据、按统一口径算原始指标、固定参考与权重、生成分项及维度分数，再批量换权重。问题一产物至少包括指标定义/来源表、历史原值表、四维对比、各能源角色诊断、缺失与口径说明。其结果给出问题二的起始规模和校准目标，但评分权重不会自动变成主体行为参数。

## 17. 问题二：主体状态更新与年内运行的具体方程

### 17.1 数学结构：主体提出动作，运行检验后再更新

用X_t保存期初资产、设备、库存、资金、项目队列和历史信息；xi_t保存外部经济、贸易、天气和技术条件；z保存政策规则。每个主体i只能使用信息集O_it，生成申请a_it：

$$
a_{it}=\pi_i(O_{it};\theta_i,z),\qquad
a_t^{approved}=\mathcal A(\{a_{it}\},X_t,z).
$$

pi_i是我们编写的透明行为规则，A是按公开资金、接入、建设和许可约束进行的审批。年内实际运行量v_t由当年已投产资产和需求确定，年度状态更新为：

$$
v_t=\mathcal D(X_t,\xi_t;\theta,z),\qquad
X_{t+1}=\mathcal T(X_t,v_t,a_t^{approved};\xi_t).
$$

程序顺序不是先把当年申请全部变成容量再运行。先兑现以前年份到期的项目，运行当年系统，按实际结果结算和形成申请，最后把获批动作排入后续队列。上述写法是年度关系的概括，时序以第17.7节为准。

首版主体不包含大模型或强化学习算法。行为有明确计算规则和边界；不同主体因资源、目标、资金、设备和信息不同而产生不同动作。碳价和已实施政策作为外部环境，复杂碳市场形成机制暂不另建。

### 17.2 用能主体：服务需求、设备存量和替代选择

对区域r、服务s，先由活动量A和单位活动服务需求zeta形成年度服务量：

$$
Q_{rst}=A_{rst}\zeta_{rst},\qquad
q_{rsh}=Q_{rst}\phi_{rsh},\qquad
\sum_h w_h\phi_{rsh}=1.
$$

工业可使用产品产量与所需有效热量，交通可使用客货周转量，建筑可使用面积、气候及所需供热制冷服务。GDP和人口仅在缺少更直接活动量时用于有说明的聚合近似；不能把全部服务都按同一GDP增长率机械放大。zeta描述活动与服务的关系，设备效率另由eta表示，避免同一节能效果扣两次。

某技术k输入能源量x_rskh后提供y_rskh服务，满足：

$$
y_{rskh}=\eta_{rsk}x_{rskh},\qquad
\sum_k y_{rskh}+u_{rsh}=q_{rsh},\qquad
0\le y_{rskh}\le N_{rskt}a^{use}_{rskh}\Delta_h.
$$

N是设备的有效服务能力，单位为相应服务量/小时；eta为服务量/输入MWh。供热时eta可理解为效率或性能系数，交通时是每MWh能完成的周转服务，不能混用“效率”数值。不同服务的u分开保留。现有设备能力决定可用能源范围，求解器不能让一台燃油设备瞬间使用氢。

设备按投产年份v保留存量N_rskv；到寿命、确认退出或批准提前更新后才能移除，新增设备按其安装完成日期进入。候选更新策略是比较提供同一单位服务的成本：

$$
LC_{rsk,t}=
\frac{\text{年化设备投入}+\text{固定运维}}{\text{预计年度服务量}}
+\frac{p_{f,t}}{\eta_{rsk}}
+\text{单位服务适用的碳履约成本}.
$$

年化投入使用明确寿命与折现率；燃料、电价和碳成本不能重复计入。先在已可用且适用该服务的技术中找最低LC方案，再在达到更新条件的设备与新增服务能力内逐步采用。一个可校准的简化是：每年仅对可更新规模的rho_s比例重新选择，其余按已有结构延续；rho_s不能超过实际更新、融资和安装能力。计划换设备但尚未完工时，旧设备状态与可用性按真实退出安排处理。

短期需求响应只在已具备能力的设备上移动使用时段，并约束可移动比例、时间窗口、补偿费用及窗口内服务守恒。若研究的服务允许减少消费，需单列其服务损失或效用代价。不能把未满足服务改名为“需求响应收益”。

### 17.3 发电、储能和输送主体：预期、申请与项目队列

对候选项目j，以规模q_j、建设周期L_j和运行寿命H_j计算预期净现值：

$$
V_{jt}=
-\sum_{\tau=0}^{L_j-1}\frac{C_{j\tau}}{(1+d_j)^\tau}
+\sum_{n=L_j}^{L_j+H_j-1}\frac{\widehat{CF}_{j,t,n}}{(1+d_j)^n}
+\frac{\widehat{SV}_{j,t}}{(1+d_j)^{L_j+H_j}}.
$$

C是各建设期投入，CF是预期经营现金流，SV是期末残值；零建设周期项目可把投入单独记为t时点支出，不使用空建设支出和。预计现金流来自可核对合同、电价、预计售电/服务量，减去燃料、运维及实际适用的碳履约费用。免费配额、行业覆盖、补贴和容量补偿分别处理，不能默认全部排放乘碳价等于企业现金支出。

首版可对可利用小时、弃电比例或单位经营收益采用平滑预期：

$$
\widehat m_{i,t+1}=(1-\lambda_i)\widehat m_{it}+\lambda_i m_{it},
\qquad 0\le\lambda_i\le1.
$$

m_it来自已完成的实际运行与结算。新技术可使用同区域可比技术或外部参考，必须标记依据；不能让企业读到模型已经存好的未来实际天气与价格。CF中的未来合同或已发布规则允许进入预期，但不等于预知未来兑现结果。

候选基本申请条件为V_jt>0；另有明确公共服务义务和资金来源的项目单独记录。每主体年度申请规模受调整速度gamma_i限制，获批项目进一步满足：

$$
\sum_{j\in approved}\text{当期资金需求}_j\le B^{finance}_t,\qquad
\sum_{j\in approved}\text{建设占用}_{jkt}\le H^{build}_{kt},
$$

以及区域接入、许可、资源和后续年度已承诺资金边界。不能只审查今年首付款而忽略未来已承诺支出。多个主体竞争同一额度时，按预先固定的项目排序/审批规则统一处理；改变该规则作结构检验，不能由遍历顺序决定谁先占用资源。

每个获批项目记录owner、region、technology、capacity、approval_year、scheduled_commission_year、actual_commission_year、支出计划和状态。仅状态确认为投运后才增加实有设备。固定建设周期的实有容量简化账为：

$$
K^{book}_{rkt}=K^{book}_{rk,t-1}+I^{approved}_{rk,t-L_k}-R^{permanent}_{rkt}.
$$

K_book是仍然存在的设备容量，运行约束中的K及a还需从在运、备用、检修、延寿等状态映射；备用设备的可用率、启用时间和费用明确。年末装机校准目标与全年平均可用能力分别记录，已知月度投产的项目按相应时段生效；只有年度日期时注明生效约定并检查其影响，不能把年末新装机当全年可用。永久退役设备不能下一年自动回来。水核等长周期项目若缺乏申请行为资料，可先按有来源在建队列推进，并标明这部分是外部给定，而不是主体自主预测。

输电与储能项目采用同样的建设与资金逻辑，收入规则按合同/服务补偿分别说明。政府诊断“加储能能减少缺口”只产生政策候选，不能让一个无收入、无财政安排的储能项目自动落地。

### 17.4 燃料供给、库存及政府的规则

燃料供给主体观察合同、销售、生产上限、进口限制和库存目标，提出下一期供给/采购计划。长期产能变化同样通过投资队列进入。短期库存满足：

$$
I_{rf,h+1}=I_{rfh}+P_{rfh}+M_{rfh}
+\sum_{r'}F_{r'rfh}-\sum_{r'}F_{rr'fh}
-B^{conversion}_{rfh}-B^{final}_{rfh}-B^{feedstock}_{rfh}-L^{fuel}_{rfh}.
$$

所有量均为该时段能量；P、M分别是国内供给与进口，B分别是转换、终端和非能源原料消耗。还要限制库存容量、进口/生产速率、库存提取速率和输送能力。年度进口上限不能直接当作任何一小时可无限提取的供应。数据不足时，只支持相应粒度的年度核算或给定库存条件实验。

政府基准规则读取已经实施的政策路径，不以强制达标为默认行为。候选改进规则先使用当年可知的需求、资产、在建队列及事先规定的压力集合，评估未来H年的服务缺口；当缺口超过明示容许水平eps时提出配套或节奏调整。H、eps及可用压力集合均是政策规则的组成部分，需要依据或敏感性检验。

政府不能通过超寿命运行或无限延期退役维持保供。若技术、预算、供给和排放条件不能同时满足，程序应输出不可行及冲突来源。

### 17.5 运行层：多能源与服务平衡的线性规划

给定已投产资产、设备结构、外部条件及当期可知预测窗口，决策向量v包含各机组发电量g、转换能源输入b、终端设备用能x、跨区流量F、储能充放电c/d、库存S/I、服务缺口u及必要的弃能。参数和资产在本次求解中固定，约束写成A_eq v=b_eq、A_ub v<=b_ub及变量上下界。

以电力为例，发电、储能放电和计损后的输入等于终端设备实际用电、转换用电、充电与输出：

$$
\sum_k g_{rkh}+d_{rh}+\sum_{r'}(1-\ell_{r'r})F_{r'reh}
=\sum_{s,k:f(k)=e}x_{rskh}+b^{conversion,e}_{rh}+c_{rh}
+\sum_{r'}F_{rr'eh}.
$$

终端服务通过第17.2节的u允许未满足，因此本式不再重复增加一份“缺电”。若另有不展开设备的固定电需求，需在右端写D_fixed-u_fixed，并把其u_fixed纳入缺供目标。不能既减去未满足服务对应耗电，又再次添加相同缺电补偿。

发电、燃料消耗、储能与线路约束的例子为：

$$
0\le g_{rkh}\le a_{rkh}K_{rkt}\Delta_h,\qquad
b^{fuel}_{rkh}=g_{rkh}/\eta_k,
$$

$$
S_{r,h+1}=S_{rh}+\eta_c c_{rh}-d_{rh}/\eta_d,\qquad
0\le c_{rh}\le P^c_{rt}\Delta_h,\quad
0\le d_{rh}\le P^d_{rt}\Delta_h,\quad
0\le S_{rh}\le E^{storage}_{rt},
$$

$$
0\le F_{rr'fh}\le \bar F^{power}_{rr'ft}\Delta_h.
$$

同一共享通道有双向变量时，应加合计使用上限；有双向同时流或循环套利时检查损耗、费用和约束，必要时加互斥。储能也须检查同时充放电；不能仅因LP可行就认定物理可行。必要的离散互斥、启停约束会把局部问题扩展为混合整数形式，不应继续宣称整个问题都是纯LP。

风光a来自同期出力条件，未发出的可用电量单列弃电。水电除了功率还受时段水量/可发电量限制；核电、煤气电需要适用可用率及研究所需的最小出力/爬坡近似。是否加入这些限制由其对结论的影响和数据支持决定。

油品加工、化石/电解制氢、供热等用明确输入输出系数连接；生物质受原料上限约束；碳捕集增加用电/燃料并受捕集与封存能力限制。天然气共同竞争由同一个燃料库存/供给平衡产生，不能为工业和电厂各复制一份同额供应。

求解目标采用分层形式：

1. 按事先说明的关键服务优先级最小化未满足量；同一层如含不同服务，使用固定参考需求归一化并公开权重。
2. 把上一层最优缺供值在数值容差内固定，再最小化次级缺供，必要时逐层重复。
3. 在最低缺供条件下最小化实际运行资源费用，包括燃料获取、可变运维、损耗及有依据的调节代价；碳价等政策边际信号单列并注明其性质。

各层结果需检查求解成功、等式残差、不等式违反量和变量界；失败不能当作零缺供。资源成本、政策支付和企业现金流分账保存。调度目标中的碳价格信号不直接等于社会消耗，也不自动等于企业实际履约支出。

### 17.6 一个可手算的共享燃料例子

以下是讲解方程的人工例子，不是中国某年数据。一个小时电需求100MWh，风电可用30MWh，煤电最多50MWh；可用天然气60MWh低位热值，其中工业必须用20，气电效率0.5，气电设备功率足够。设v=(煤电g_c,气电g_g,未供电u)，则：

$$
g_c+g_g+u=70,\quad 2g_g\le40,\quad
0\le g_c\le50,\quad 0\le g_g\le30,\quad 0\le u\le100.
$$

第一层目标c=(0,0,1)，先求最小u；第二层固定这个u，再用示例费用c=(300,500,0)求最低费用。手算得到(50,20,0)。气源降到40时，工业用气保持20，气电最多10，缺电为10；风电单独降到10时缺20；两者共同发生缺30。这个例子联合额外效应为30-10-20+0=0，说明联合冲击不必然产生超加和效果。

对应SciPy输入为A_eq=[[1,1,1]]、b_eq=[70]、A_ub=[[0,2,0]]、b_ub=[40]及上述bounds。完整模型只是增加地区、时间、设备和服务对应的行列，不能漏掉共同燃料、存量及服务限制。

### 17.7 年度执行与年内信息窗口

年度执行依次为：兑现到期项目与已批准退出；冻结当期可用状态及已知外部信息；主体提交运行条件和需求；求解年内运行；核算实物、排放和现金；冻结结算后共同信息；主体提出后续动作；统一审批并入队；保存结果并进入下一年。

四季代表周用于常规年度量近似，不能将每周库存恢复为满值。短储能首尾连接和燃料库存处理需与第8.5节一致；跨季节储能结论须连续长时序支持。独立压力测试从同一事前资产和库存复制运行，其结果不混入基准年常规收益。只有情景明确让事件在某年实际发生时，才替换相应时段并将损失、库存和收益带入下一年。

年内完全预知整个事件会高估调度能力。先用该假设检查程序和计算上界，再比较滚动预测窗口与误差条件；正式保供结论写明信息条件。历史回放中的主体只能接触该历史时点可知信息，不能读入后来发布政策。

## 18. 问题二：历史校准、双碳推演及灵敏度分析

### 18.1 哪些参数校准，怎样校准

优先校准少量能由历史变化约束的行为参数，例如需求活动响应、年度设备更新比例rho、企业投资调整速度gamma、收益预期更新权重lambda。寿命、建设期、效率和实际成本优先使用观测或有依据的范围；不能让它们任意变化来吸收统计口径差异。

设可比历史指标为y_jt，模型输出为yhat_jt(theta)，预先确定每类指标的误差尺度s_j和权重omega_j：

$$
\min_{\theta\in\Theta}J(\theta)=
\sum_j\frac{\omega_j}{|T_j|}
\sum_{t\in T_j}
\left[\frac{\widehat y_{jt}(\theta)-y_{jt}}{s_j}\right]^2.
$$

T_j只包含该指标真正可比且有观测的校准年份；s_j可取独立说明的测量容差或只由校准期确定的固定尺度，不因某系列数值大就支配目标。s_j、omega_j和可接受误差均在看留出结果前冻结，不使用留出期调整。按系列平均可避免年份较多的指标自动占更大权重。容量、生产消费、结构和排放分别检查，不能只追求总排放拟合好。

候选时间划分保持2014-2020校准、2021-2024留出；2025仅对已有可比字段做补充检查。对价格、部门和区域字段另查实际窗口。历史政策与价格按当时实际值进入，不能提前插入2026年政策或未来冲击。

首版以有界网格和少量参数搜索为起点；规模需要时可用SciPy differential_evolution作无梯度有界搜索。它只是寻找较小误差的数值工具，不保证辨识出真实行为或找到全局最优。主体模型含项目审批和退役等跳变，不默认适合直接用梯度最小二乘。保留多组接近最优且通过核算的参数，检验它们是否支持相同政策结论。

至少保留四组检验：单位/守恒/边界检查，留出年份误差，与简单持续趋势基线对比，替代行为规则对比。若模型拟合依赖不可核实的大量参数，应减少自由度或缩小结论；不能通过增加主体数量掩盖资料不足。

### 18.2 从年度运行量计算双碳指标

校准通过后，从可核对的初始状态执行第17节年度循环。2024仍是候选全国基准，不代表区域初始状态已齐；需衔接2025补充资料与2026政策生效时间，再确定正式前瞻起点。

年度能源量采用sum_h w_h乘各时段实物量，再按第6节核算。一次能源、终端能源和发电量分别保存；煤发出的电、抽蓄放出的电、用电制出的氢不能再次被记为凭空增加的一次能源。官方非化石占比用其对应统计口径，不能直接用风光核水发电量占比替代。

对燃烧活动的CO2核算为：

$$
E_t^{energy,gross}=\sum_{r,f,h}w_h EF_f B^{burn}_{rfh},\qquad
E_t^{energy,post}=E_t^{energy,gross}-C_t^{captured,stored}.
$$

燃料EF的单位必须与MWh低位热值等输入一致；捕集量须确实储存并受能力约束，其额外能耗已进入B。上式用于相应化石燃烧边界，生物质及其他过程按单独核算规则记录，不默认全为零。电、氢的上游排放已在发电/制氢燃料处计入，不再按终端用电量重复加一次。

全国CO2条件结果还需要：

$$
E_t^{national,net}=E_t^{energy,post}
+E_t^{nonenergy,post}-R_t^{net}.
$$

三项边界不能重叠；非能源排放及净移除按独立外部路径表示。现有资料尚不完整，所以能源部分可以先建，完整全国中和率和全国净零判断必须等待G12处置。设剩余正排放P_t为前两项之和，可定义中和率nu_t=R_t^net/P_t，同时报告净排放；P_t=0时单列，不能除零，也不能把同一捕集量同时作为减排与移除扣两遍。

输出指标包括能源总量、非化石占比、CO2年序列、峰年与峰值、能源强度C_energy/GDP_real、碳强度E/GDP_real及相对政策基年的降幅。达峰检查包含历史和未来整段路径，并说明峰后持续性；若峰值在仿真终点或只有短暂下降，标记无法确认。排放强度下降不自动意味着绝对排放达峰。

各参数/外部路径组合会产生一条完整结果路径。没有概率依据时，路径范围叫“所检验条件下的范围”，不能叫置信区间或现实达标概率。

### 18.3 灵敏度、情景和优化各改变什么

| 名称 | 改变的对象 | 回答的问题 |
| --- | --- | --- |
| 灵敏度分析 | 不确定输入theta/xi在合理范围内变化 | 结论最受什么影响，原结论是否稳定 |
| 情景分析 | 有解释的一组外部条件，如进口限制及其持续时间 | 在这个具体外部世界中会发生什么 |
| 政策优化 | 决策者能控制的规则和投入z | 面对给定外部条件和边界，怎样行动较好 |

例：储能造价未来降多少是外部不确定条件；财政把多少预算用于储能补助是政策变量。不能把“技术成本自动降至零”作为政府免费可选择的优化动作。碳价在第二问是给定政策路径，在第三问若研究政策调整则明确成为z的一部分；同一次实验中不重复作为互相独立的外部变量。

### 18.4 具体执行：先单因素检查，再筛选，再联合检验

先建立参数字典：名称、单位、基准、上下界、来源、影响的规则、是否可校准、是否为决策变量、与其他输入的关系。重点候选为经济活动增长、设备节能速度、技术成本下降、燃料价格、碳价、投资响应和设备替代速度；建设延迟等离散变量另作分组实验。缺少区间依据的参数先不用于正式概率抽样。

第一步是局部变化检查。每次仅改变一个输入，在有依据的上下点重跑，观察排放、非化石占比、成本与缺供的方向及幅度。对非零且连续的指标，可计算：

$$
e_j=\frac{Y(\theta_j^+)-Y(\theta_j^-)}
{\theta_j^+-\theta_j^-}\frac{\theta_j^0}{Y(\theta^0)}.
$$

基准缺供为零时不用这个弹性，直接报告变化量；峰年、是否达标等离散结果采用逐情形变化，不强求导数。任意正负10%只可作为程序方向检查示例，不能自动冒充可信不确定范围。

第二步用Morris方法筛选连续不确定参数：将有界输入缩放到0至1，在多条路径上每次移动一个参数，计算基本效应：

$$
EE_j^{(m)}=
\frac{Y(\boldsymbol x^{(m)}+\Delta \boldsymbol e_j)
-Y(\boldsymbol x^{(m)})}{\Delta},\qquad
\mu_j^\ast=\frac1M\sum_m|EE_j^{(m)}|.
$$

mu_star大表示该输入在所测范围内影响大；EE的标准差sigma较大提示影响随位置变化，可能来自非线性、跳变或交互，不能单凭sigma证明某条因果机制。SALib可承担抽样和mu_star/sigma统计，模型仍由我们运行。

一个初始计算设计是8个未分组连续参数、10条轨迹，每个固定情景/规则需要10*(8+1)=90次完整模型运行；若含多个情景或随机重复，再乘相应次数。这是工作量示例，不是精度保证。先做小规模计时，再决定轨迹数并检查排序稳定性。输入有强相关或物理约束时，应按可行的基本驱动重参数化/分组，不让独立扰动生成不可能的组合。

第三步对重要输入做联合检验：用SciPy stats.qmc.LatinHypercube等在给定区间覆盖取样，例如先200组，再独立扩充设计检查结果范围和策略排序。样本量由计算预算及稳定性决定，不先承诺200组足够。每组样本要同时运行所有候选策略，使用相同外部条件；按因果/物理关系生成相关输入，而不是把所有量独立乱抽。

联合结果报告各输入组合下的排放、费用和缺供范围，哪些条件导致策略失效或反转。均匀覆盖只是实验设计，不代表现实服从均匀概率；“样本中多少比例达标”只能称样本覆盖下的比例。无可靠概率时，第三问的优化采用指定条件集合内最坏表现，避免把抽样频率当现实概率。

### 18.5 结构、信息与价值判断也必须检验

参数检验之外，还比较区域划分、代表周与长时序、库存初值、调度预测窗口、不同可解释投资规则、审批顺序以及问题一权重。每种变化都标明是结构、信息还是价值判断，不与随机参数混成一个区间。

正式策略阈值使用一组预先确定的压力条件选择，另留事件强度、持续时间、恢复过程和参数组检验。历史时间留出、政策设计条件留出与来源独立是不同检查。若只有某一行为规则或某种时间近似下方案有效，应明确条件，不取平均后隐藏差异。

## 19. 问题三：明确情景参数，并在约束下优化政策

### 19.1 六组主情景及其参数差异

首轮采用六组主情景，覆盖题面要求并直接支撑H02四组对照。S0、SG、SW、SGW用于同一资产状态上的短期配对；SP、ST用于长期政策和技术路径比较。所有情景还可在明确事件日历下进入完整年度演变，但必须与独立压力测试结果分开。

设基准碳价为pC_0(t)，按来源分解的进口可用率为m_0(r,o,h)，风光可用比例为a_0(r,k,h)，水电可发能量上限为W_0(r,b)，储能功率与能量投资成本分别为cP_0(t)、cE_0(t)。b为水电预算时段。建设队列、初始资产、需求、未改变的价格等保持相同。

| 代码及名称 | 明确改变的输入 | 首轮如何实施 | 解释范围 |
| --- | --- | --- | --- |
| S0 基准 | 经来源约束的既有政策与经济、技术趋势 | 使用基准输入路径；不强制2030达峰或2060净零 | 回答现有路径会怎样 |
| SP 碳约束强化 | pC_SP(t)=pC_0(t)[1+delta_C r(t)] | r(t)从政策起始年逐步升至1；首轮固定其他政策，只改变碳价格路径，并保留真实覆盖与配额规则 | 解释价格信号通过主体收支影响投资/替代；若改覆盖或补贴则另开子情景 |
| SG 气源受限 | m_SG(r,o,h)=m_0(r,o,h)[1-delta_g(r,o)e(h)] | 限制指定来源/通道的进口能力，国内生产不同时削减；写明起始、持续、恢复 | 对应油气供应风险中的天然气主实验；石油中断可作为独立扩展 |
| SW 天气压力 | 风/光a_SW=a_0(1-delta_k e_k(h))；水电W_SW=W_0(1-delta_H e_H(b)) | 对指定地区采用可共同发生的同期事件或明确条件边界；首轮不叠加高温需求增长，以隔离供给侧影响 | 不把独立最极端值拼接成有已知概率的现实事件 |
| SGW 联合压力 | 同时施加SG与SW的原参数 | 同一事件前资产、库存、服务要求和恢复定义；不偷偷加大单项冲击幅度 | 识别联合效应及可能传播机制 |
| ST 储能技术降本 | cP_ST=cP_0(1-delta_P r(t))；cE_ST=cE_0(1-delta_E r(t)) | 首轮只改变新项目功率/能量投资成本，效率和寿命不自动改善，已有资产不追溯重算投入 | 让企业/政策规则实际选择是否增建；氢能、CCUS突破另作有数据的子情景 |

上述SP首轮聚焦碳价格，有助于知道变化来自哪里；增加可再生能源激励、合同保障、节能要求时逐项设子情景并记录预算。ST首轮聚焦储能，避免把数项技术同时任意变好后无法归因。所有技术仍保留在系统边界中，首轮情景聚焦不等于删去其他能源。

事件函数e(h)在事件前为0，持续期为1，恢复期按明确曲线降回0；渐进政策函数可定义r(t)=clip((t-t_start)/T_ramp,0,1)。t_start、T_ramp及事件范围属于参数。最终参数表必须写基准值/路径、改动量、年份、单位、来源、状态和只影响哪些输入。

### 19.3 能源安全结果：用硬指标定位薄弱处

对区域r、服务s、年度或事件范围，记录未满足量U_rs=sum_h u_rsh、未满足比例l_rs=U_rs/Q_rs、最大连续缺供时长、事件后恢复至规定服务水平所需时间、库存最低值、进口依赖和通道受限过程。代表时段汇总年度未满足量时使用w_h，事件实际量不重复加权。

没有发生概率资料时，U是本次条件事件中的未满足量，不称为期望未供能。恢复阈值和需连续维持的时间提前定义；某时刻恢复后立刻再次失供不能算稳定恢复。

为比较多种服务，先分别报告原单位，再用固定需求归一化；可定义L=max_{r,s:Q_rs>0}l_rs检查最差地区/服务。关键服务还设单独上限。全国平均改善不能掩盖某区域或关键服务变差。

### 19.5 优化形式：有限政策组合的受约束仿真筛选

设Xi_design为事先确定的外部条件集合。运行完整模型得到C(z,xi)、E_cum(z,xi)、L(z,xi)和各区域/服务指标。C是统一基年折现的实际资源成本，包含投资、运行、保留、燃料和适用期末资产残值；政府预算支出另列。税、补贴等国内内部支付不重复加到社会资源成本中。

在没有可靠情景概率的情况下，采用指定集合内的最坏表现。一个可执行的候选优化问题是：

$$
\min_{z\in\mathcal Z}\ \max_{\xi\in\Xi_{design}}L(z,\xi)
$$

$$
\text{s.t.}\quad
\max_{\xi\in\Xi_{design}}C(z,\xi)\le\varepsilon_C,\quad
\max_{\xi\in\Xi_{design}}E_{cum}(z,\xi)\le\varepsilon_E,
$$

$$
B_t^{public}(z,\xi)\le\bar B_t,\quad
l_{rs}^{critical}(z,\xi)\le\bar l_{rs},\quad
z\text{及其实际项目满足资金、寿命、建设、库存和许可边界}.
$$

所有情景下的预算与关键服务条件逐项检查。累计排放边界需明确是能源CO2还是全国CO2；全国净移除未齐时只能使用可核对的能源边界，不把它冒充全国中和约束。若政策要求比较2030或2060单年目标，还应加相应约束/报告，累计上限不替代单年目标。

epsilon_C、epsilon_E表示允许的资源成本和累计排放，不是要凭空拍定的最优权重。先用有来源的预算/政策界或明确的研究取舍给定，再逐步改变两者，得到“多花多少、少排多少、能减少多少缺供”的方案集合。若一个方案在费用、排放、安全上都不优且至少一项更差，则被另一方案支配，可以剔除；剩余方案展示取舍。没有用户/政策偏好时不声称存在唯一最佳方案。

具体实现先构造少量有解释的组合并逐个调用模型。例如四个可调整维度各设三档，至多81个组合，再按预算和工程边界提前剔除；这个数字是计算设计示例，不是正式变量已定。瓶颈诊断先试单项与必要的两项组合，以降低无效搜索量；单项无效可能因为另一限制同时存在，不能据此删除所有组合。

完整主体模型含离散投运、审批和退役，C/E/L未必是线性光滑函数，因此外层不直接用linprog包办。SciPy主要求解每次运行层；候选组合过多时再根据性能证据考虑有界搜索或近似模型，并单独验证，首版没有必要预先加入复杂多目标算法。

### 19.6 公平比较、不可行及留出检验

基准预测允许不达标；优化措施才受明确的预算、排放和服务约束。政策情景SP可能提高企业碳支出，它与S0的差异属于情景结果；候选新规则的优势则必须在共同财政边界、候选措施、信息、起始状态和服务要求下比较。

固定项目的顺序实验只隔离时序；完整政策实验允许主体产生不同项目，其效果包括资产变化，不能全部称作时序效应。新增投资、备用保留和延寿成本全部记录，不允许无限延期把排放与退役问题推到2060年之后。

先在Xi_design筛政策和阈值，再在Xi_test的未参与选择事件/参数上评估。各政策使用配对的外部样本；报告最差条件、受损地区和失效范围。若可行集为空，输出缺哪类能力、超多少预算或排放，以及需放宽什么约束，不静默放松限制后宣称成功。

## 20. 两个创新点怎样嵌入，以及Python实施接口

### 20.1 创新点一H01：转型速度与配套延迟，以及可提前执行的规则

这个创新点贯穿三问，不是最后另加一幅图。第一问寻找供给、配套和区域错配线索；第二问必须真的保留设备替代、项目队列、退役状态和投资反馈；第三问才有条件研究它们的速度关系并筛选改进规则。

数学上区分终端设备替代速度v_E、供给设备获准退出速度v_R和配套额外延迟L。三者不合并成一个含义不清的“转型速度”。主实验可画v_R与L的结果面并固定v_E，再画v_E与L并固定v_R，最后检查必要的三者组合。各速度只能在寿命、许可、服务和建设能力允许的范围内改变。

对每个组合运行模型，得到L_loss(v_R,L)、C(v_R,L)、E_cum(v_R,L)及分区服务结果。图中标出满足共同费用/排放/保供边界的区域、失败区域及对参数敏感的区域；不预设单调性、唯一阈值或全国通用边界。

候选触发规则可以写成：

$$
\text{trigger}_t=
\mathbf 1\left\{
\max_{\xi\in\Xi_t^{known}}
\max_{\tau=t+1,\ldots,t+H}
L^{forecast}_{\tau}(X_t,\text{已知队列},z;\xi)>\epsilon
\right\}.
$$

该检查只使用当时信息及事先规定的压力边界。触发后，先辨认缺的是功率、连续能量、燃料、输送还是可调整服务；再比较能赶在缺口前完成的项目、合同和合法延寿措施；最后按共同资金与碳边界选择并排入队列。若措施赶不上，显式报告剩余风险，不能把多年后才投运的项目视为已预防眼前缺供。

对照至少包括固定日程、按费用排序以及确认替代服务可用后再退出的合理保供规则。固定项目时序实验和完整主体响应实验分别报告；阈值选择与验证条件分开。H01的候选贡献是有解释的适用条件和额外有效的提前决策规则，能否成立由公平对照及留出检验决定。

### 20.2 创新点二H02：联合压力的传播过程与归因

第一问提供共同燃料用途和区域连接线索；第二问通过共同燃料账、转换设备、输送、库存和主体响应产生传播可能；第三问用S0/SG/SW/SGW识别现象并检验解释。

对同一地区、同一种服务或同一固定定义的缺供指标U，定义：

$$
J=U_{SGW}-U_{SG}-U_{SW}+U_{S0}.
$$

J>0表示在此定义下联合影响超过单独增量之和，J=0表示相加，J<0可能反映重叠、替代或边界等作用。J不是跨能源传播的充分证据；第9.3节备用越界反例仍然适用。不同服务的原单位不能直接放入同一个J。

每次实验保存随时间变化的气源、工业/电厂用气、区域流量、储能存量、设备运行和服务缺口。根据过程提出一条具体解释，再设置对应对照。例如冻结事件发生后的某类需求替代响应，保持同一事件前资产、服务需求和燃料总供给，让运行层继续满足物理约束，比较：

$$
\Delta J_{\mathrm{response}}=J_{\mathrm{normal}}-J_{\mathrm{frozen}}.
$$

这个差异表示在所选模型和干预定义下，该响应对联合效应的贡献；它不是自动成立的现实因果证明。冻结不能破坏能量守恒，也不能额外给气、降低服务要求或重置库存。若冻结导致服务无法满足，就显式记录缺口。短期资产固定的机制实验与长期投资适应实验分别进行。

最后将查实的瓶颈送回第19节政策候选：燃料竞争可能对应储备、来源分散或减少事件中争气；连续能量不足可能对应储能时长、长事件需求安排；输送受限可能对应通道建设。措施是否有效仍由同预算和排放边界下的运行结果决定。

| 年度核算 | 实物运行和现金/项目记录 | 能源、碳、服务、企业收益、公共预算和社会成本分账 |
| 年度主循环 | 初始状态、theta、xi、z | run_model，返回逐年状态及必要时序 |
| 参数校准与实验 | 历史目标、参数界、情景与规则集合 | calibrate、run_sensitivity、run_scenarios、compare_mechanisms |
| 政策筛选 | 候选z、共同边界、设计及留出条件 | evaluate_policy、filter_feasible、filter_dominated |

年度循环示意如下。方法体仍需根据第17节实现，不能直接执行这段就得到能源模型：

~~~python
class EnergyModel(mesa.Model):
    def step(self):
        self.apply_due_projects_and_approved_exits()
        before = self.freeze_current_information()
        self.agents.do("prepare", before)
        result = self.solve_dispatch_from_prepared_inputs()
        self.check_physical_balances(result)
        self.agents.do("settle", result)
        after = self.freeze_post_settlement_information()
        self.agents.do("propose", after)
        self.approve_and_commit_proposals()
        self.record_year(result)
        self.sim_year += 1
~~~

构造函数需要调用Mesa模型初始化、创建各类主体及初始资产、保存sim_year，并配置结果收集。prepare/propose只写主体申请，不直接抢占共享资源；统一审批后才修改共享队列。settle按事先计算好的交易结果记账，不能由先后调用改变交易量。

运行层的核心接口为：

~~~python
result = scipy.optimize.linprog(
    c=objective,
    A_ub=inequality_matrix,
    b_ub=inequality_limits,
    A_eq=balance_matrix,
    b_eq=balance_targets,
    bounds=variable_bounds,
    method="highs",
)
~~~

每个矩阵行都保存region、carrier/service、time、constraint_name，便于解释是哪项限制导致缺供。先检查result.success，再读取result.x；计算约束残差和核算账。分层求解在下一层加入上一层目标值上限加明确容差，不能随意固定上一层每个变量而剥夺后续成本优化空间。

校准、灵敏度与政策比较调用同一run_model(theta, scenario, policy, seed)，防止各问另写一套不一致规则。没有随机行为时不需要人为引入随机种子；有随机天气/行为时各政策使用相同样本和种子，并记录重复运行波动。

### 20.6 实施顺序和完成标准

1. 固定问题一可比指标和输入视图，完成一个年份的能源/碳静态对账；缺失项保持不可用。
2. 写单区域短时运行模型，先复现第17.6节手算；再检查燃料不够、储能耗尽、零容量、退役后零出力等边界。
3. 接入主体状态、现金、设备更新和项目队列，验证本年申请不提前投产、不同执行顺序不改变共同约束。
4. 扩展到有数据支持的区域与多能源，做历史校准、留出检验和替代规则对照。
5. 运行S0及各情景，做局部/Morris/联合敏感性检查，再开展H01/H02实验与政策筛选。
6. 在留出事件和参数上复验候选政策，生成论文图、决策原因记录及演示。形成结论须同时满足第10.4节检查。

这次文档更新只完成数学与实施规格。Mesa/SciPy依赖安装、模型代码、历史误差、预测结果和优化效果尚未完成。无需等待所有可选资料齐全，但直接决定所选机制可运行性和可信度的缺口必须先处置；不以任意点值替代。
