# 工作区只读声明

## 1. 目的

本声明用于明确当前工作区的访问与使用规则，确保工作区内容保持原始状态，避免任何非预期变更。

## 2. 只读范围

当前工作区内的所有内容均为只读，包括但不限于：

- 所有文件；
- 所有目录及其子目录；
- 所有文档、配置、数据、脚本、资源文件；
- 工作区内已有内容的名称、路径、结构和属性。

## 3. 禁止操作

在当前工作区内，不允许执行以下任何操作：

1. 修改、编辑、覆盖、追加或格式化任何文件；
2. 重命名、移动、复制覆盖或重新组织任何文件或目录；
3. 删除任何文件或目录；
4. 新增任何文件或目录；
5. 通过命令、脚本、工具、程序或其他间接方式改变工作区内容；
6. 以任何形式将生成内容、临时内容或外部内容写入工作区。

## 4. 允许操作

在不改变工作区内容的前提下，允许：

- 读取、查看、检索和引用工作区内文档；
- 基于工作区内容进行分析、总结和回答；
- 将工作区内容作为参考依据，但不得回写或修改工作区。

## 5. 冲突处理原则

当文档内容发生冲突时，均以该工作区内的文档为主要参考和优先依据。

具体包括：

1. 外部说明、记忆、推断或生成内容与工作区文档冲突时，以工作区内文档为准；
2. 不得为了消除冲突而修改、新增或删除工作区内的任何文件；
3. 若工作区内文档之间存在冲突，应保留原文状态，并明确提示冲突内容，不得擅自修改文件进行裁决。

## 6. 执行要求

所有对当前工作区的操作均应默认遵循只读原则。任何可能改变工作区内容的请求，均不应执行；任何分析、输出和说明均不得写回工作区。

本声明仅用于说明只读规则，不构成对工作区的任何写入操作。
