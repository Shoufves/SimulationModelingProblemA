# A题协作约定

- 仅处理A题，不将B/C题数据或方法混入本工程。
- 开始新工作时先读README、只读工作区/final.md、docs/IMPLEMENTATION_ROADMAP.md；gemini_final_idea.md仅作基础主线完成后的可选创新。
- 只读工作区目录的三个原文件保持原字节和路径，禁止回写。需要导航修正时更新docs中的阅读副本。
- yx并不是缺失的第四个目录，其原数学稿在docs/design，数据在data，脚本已并入scripts。不要再次创建三个并行工作区。
- 用data/catalog的统一目录和path_aliases定位已有材料，先检查已有原件，避免重复下载或将同源值算作独立观测。
- data/sources.json、evidence_reviews.json和workflow/model_inputs.json保留原用途准入契约。新来源或新用途必须做真实核验，不能只更新哈希来让检查通过。
- data/restricted不纳入默认读取。居民模块使用公开群体汇总；不同收入分组、地域、年份与单位不得静默合并。
- 先实现final的年度主体与连续运行闭环及H01/H02；不得将合成原型、许可事件或条件需求回算称为全国校准/2030与2060预测。
- 正式窗口为2015—2021训练、2022—2024已接触留出。情景顺序S0/SP/SG/ST，其后SW/SGW；旧资料的其他编号仅供追溯。
- 改动对应模块后执行适当的既有测试及复现入口。新增数据需要更新统一目录；迁移文件需要更新别名、文档导航和保留记录。
- 保存必要原件、处理代码及结果证据。缓存、临时图和虚拟环境不进入研究交付；有效历史结果不能因日期较早而删除。
