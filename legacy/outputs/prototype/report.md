# 主体决策原型：合成机制验证

**全部数值为合成案例，不是中国观测、历史验证或2030/2060预测。**
第1—8步代表抽象决策步；EU/SU/CU和排放均为抽象单位。参数来自examples/synthetic_agents.json，实际官方数据未接入此原型。

## 已运行的交互

工业和交通主体比较已观察到的电力/燃料服务成本，在预算、设备替代速度与回收期内决策；燃料供应者根据上一期利用率报价；运营者执行含碳成本排序和能力/网络约束调度；发电企业根据当期售电价和销售比例预期投资，建设滞后后投运。政府碳价是外生输入，不宣称碳市场内生出清。

## 可见局限

年度服务与报价顺序不做同一步均衡迭代，可能出现设备份额往返变化；预期销售下限是明确的合成乐观预期，未校准，可能过度投资。燃料直接用途优先、配给规则、外生预算均是研究实现假设。退役按寿命外生处理，无完整资产负债表；尚无氢、生物质、水核风光细分、储能或完整网络。
另有operations/中的独立连续运行模块，细分水核风光煤气和储能；它尚未接入本年度主体投资反馈，不能称两个时间尺度已经耦合。
只计算合成燃烧排放，没有全国工业过程、碳汇和中和率。不能把附件电站或单年统计直接填进配置后改称中国预测。
