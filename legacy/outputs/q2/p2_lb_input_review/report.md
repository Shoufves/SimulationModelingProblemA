# Q2 既有公开资料复核

复核 19 个候选/原件文件；GCB 2005—2024 共 140 个转录值逐一与原CSV行列一致；形成 80 组2015—2024覆盖记录。

这解决文件身份和GCB转录准确性，不代表这些资料已适用于全部模型用途。NBS一次电力及其他不能直接当非化石消费占比；GCB化石与工业排放不是全国净排放。

2015—2021训练、2022—2024已接触留出。工程夹具有损失/搜索/灵敏度功能，正式参数和数据仍需单独审查。

| 缺口 | 可用部分 | 后续动作 |
|---|---|---|
| G01_history_initial_state | 2015全国规模和装机、GDP序列已存 | 2015部门设备/燃料用途/库存/在建资产、同口径主体现金与政策初态；不能倒用2024 |
| G02_current_initial_state | 2024全国规模、2021—2024新型储能功率能量、471条Q1交接 | 2024实际可用设备、期初SOC/库存、年龄及在建队列；功率能量不自动提供SOC |
| G03_cost_efficiency | 风光CAPEX和部分IPCC默认因子；其他技术报告原文 | 逐技术统一价年CAPEX/OPEX、效率、寿命、融资；热值及用途匹配；不是继续增加LCOE表 |
| G04_chronology | 2018重建负荷和年度燃料/发电统计 | 明确代表窗口/同期供需/来水与进口提取约束的研究假设；年度进口量不能直接改小时能力 |
