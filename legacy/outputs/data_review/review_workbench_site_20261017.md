# 2026年10月17日本地网站操作验收与修改记录

测试地址：http://127.0.0.1:8501。范围为本地研究实验台的操作、显示、导出和数据核对入口。测试不构成科研模型校准或全国预测验收。

## 结论

主体实验、储能对照、证据检查及下载流程可正常操作。本轮复现并修正参数与结果显示不一致、机制选择口径不一致的问题；补上失败后的旧结果清理、参数解释和目录可读性调整。99项程序测试通过，另有9组真实浏览器检查通过；未发现阻止当前本地演示的操作问题。

## 发现与处理

| 优先级 | 发现及复现方式 | 本轮处理 |
| --- | --- | --- |
| 高 | 主体碳价设0并运行，切到储能再返回；参数框变回1，但结果仍为0对应结果。储能窗口和参数同样会被清理 | 分别保存已运行参数，返回工作区时恢复；结果上方持续显示实际使用参数。新增两项导航回归 |
| 高 | 碳价为0时，选择冻结设备替代，顶部缺供仍为完整反馈的20.866，实际所选机制为0；冻结发电投资实际约61.946 | 展示机制提升到全页，统一控制指标、轨迹和主体日志；机制对照和导出保留全部三组。新增指标和日志回归 |
| 中 | 运行抛出异常时，旧结果仍留在会话中，后续可能继续显示 | 开始新计算前清除旧结果；失败时仅显示错误。对两种实验分别注入失败，验证无旧指标并可恢复默认 |
| 中 | 修改参数何时生效不够直观，倍数和MW/MWh含义不够明确 | 增加表单操作说明、结果参数摘要、输入帮助及操作手册 |
| 低 | 十年年份列表在数据目录中被截断，默认表格未完整展示12个文件 | 连续年份显示为起止年和年数，非连续年份保持逐项列出；加高表格，在详情展示完整文件路径 |

本轮未改变模型算法、合成配置、官方数据、证据登记或科研阶段状态。
