# 问题二：全国聚合条件模型候选结果

本次使用真实历史观测进行有限多目标校准，并从独立2024年规模与重建资产初态推演至2060年。结果是附带明确假设的研究候选；未获团队批准，不是官方预测。

## 任务一：主体、决策与交互

Mesa组织煤油气及生物质供给商、八类发电主体、工业热/交通/建筑热服务代理、存量电力服务、电网储能和政府。设备逐批到龄退出并更新；企业按滞后利润预期和NPV申请，政府按共同融资限额批准，项目分期支出并在建设期后投产。

供给商报送有限国产/进口交付能力；运营者在连续24小时代表窗口中统一分配共享燃料和电力，保持储能与燃料库存递推；结算后再产生未来动作。碳市场采用免费产出基准下的净买卖额，与清算对手方抵消，不作政府碳税收入。

## 任务四：灵敏度与稳健性

GDP增长率±1个百分点、风光成本降幅±1个百分点、碳价0.5/1.5倍分别实际运行；同时运行等效参数、碳汇/工业过程/原料比例/成本/风光出力/统计桥接/初始年龄/建设能力边界、6条Morris轨迹以及12点三因素联合Latin Hypercube。全部条件及与S0的差值见 `sensitivity.csv`，Morris逐步效应及μ*/σ见同名表。样本仅用于首轮有界筛选，没有宣称数值精度已收敛。

试验求解失败0项，原样登记于 `sensitivity_failures.json`。样本代表所检验假设范围，不能解读为达标概率。

## 必须随结果保留的限制

- 历史资料版本、价格及技术参数是事后重建；只有经济活动驱动按年输入，不能称实时可预测检验。未把2024物理规模回填2015。
- 设备年龄、初始建设队列、细分火电和部门服务是聚合重建，非逐厂/逐户普查。发电总量和年末装机衔接存在年内投产平均量误差。
- 代表日采用24小时完美信息和循环边界；没有全年气象概率、跨省网络瓶颈、季节储能及完整启停机。水电含抽蓄的统计口径是桥接近似，不能作实际水库/抽蓄能力结论。
- 2021—2025碳配额和历史支持电价为明示代理；2026基准仅用于其发布后的大型煤电/燃气类别，未模拟所有供热、负荷修正和工业扩围企业。
- BTR工业过程及净碳汇以条件路径外推；没有假定无限免费CCUS或负排放。中和率是本项目定义R/P，非全温室气体中和认证。
- 社会分配、就业、AI专项及国际冲击需要问题三的配对情景；本次S0不把军事、贸易或技术跃迁事件当作确定事实。

复现：`python -B -X utf8 scripts/build_q2_national_inputs.py`，然后 `python -B -X utf8 scripts/run_q2_national.py`。假设全表见 `frozen_design.json`，原件、转换与排除项见问题二输入审查；Q1原契约不变。
