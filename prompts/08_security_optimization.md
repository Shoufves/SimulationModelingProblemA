# W7 能源安全与优化对策

执行总控提示词。基于已运行情景，评价供能缺口、进口依赖、备用与储备、运行灵活性、成本及恢复能力，覆盖非电能源。各情景使用同一定义与归一化基准，原始指标优先。

按模型实际时间分辨率解释可靠性：只有年度模型时不能声称测出了小时停电风险；若研究连续低出力与储能耗尽，需要连续状态和对应时段。

提出可计算的决策组合，如碳价路径、储能/备用、需求响应、跨区互济、储备与应急。所有新增能力计入成本、工期和资源约束。比较成本、累计排放和安全的权衡，输出可解释的折中方案与不同风险下的表现。

用机制拆除和样本外风险集合检验策略增益，避免在用于优化的同一组冲击上宣布普遍稳健。每条建议写清目标主体、实施时点、投入代价、效果范围及失败条件。

输出outputs/optimization/政策组合、约束与结果，以及outputs/q3/安全评价和建议。创新必须由相对基线的实验证据支持。
